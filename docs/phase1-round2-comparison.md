# 第一階段 · 第二輪：Switch 風格參考的三套方案（D / E / F）

> 依需求重新設計三套方案：參考 Nintendo Switch 世代的美術與視覺設計（《薩爾達傳說 曠野之息》、《集合啦！動物森友會》、《Tomodachi Life: Living the Dream》），
> **維持與第一輪相同的斜俯視 2.5D 視角**，全部為 2D 繪製（無 3D 模型／場景）。
> 只吸收「設計原則」（資訊層級、HUD 節制、觸感回饋、喜劇節奏、色彩策略），**沒有使用任何原作的角色、Logo、介面圖形、地圖或素材**。

## 從參考作品吸收了什麼（原則，而非外觀）

| 參考作品 | 吸收的設計原則 | 落在哪個方案 |
|---|---|---|
| 曠野之息 | HUD 幾乎隱形、資訊只在需要時出現；世界本身是主角（風、光、天氣有生命）；選單是半透明「石板」疊在模糊世界上；區域進入時的標題卡 | **D 為主**，E/F 的 HUD 數量控制 |
| 動物森友會 | 觸感十足的「玩具」按鈕；圓潤、厚實、友善；手機 App 式選單把功能收納起來；對話逐字彈出、名牌傾斜；明亮平塗與草皮條紋 | **E 為主**，F 的按鈕手感 |
| Tomodachi Life: Living the Dream | 角色個性就是內容：可調參數的臉部製作、誇張表情、喜劇節奏；居民用「心願泡泡」主動表達需求；白色乾淨 UI＋彩色分類 | **F 為主**，D/E 的特殊反應 |

## 三套方案

| | D · 風語原野 Windsong Fields | E · 晴日島嶼 Sunny Isle | F · 奇趣鎮 Quirkville |
|---|---|---|---|
| 一句話 | 雲海上的風之高原，安靜而遼闊 | 陽光小島，像玩具一樣好摸 | 一棟公寓、一群怪可愛的居民 |
| 美術 | 賽璐珞雙色＋有色線稿、暖色邊光、層疊岩壁、雲海 | 平塗無描邊、草皮條紋、土崖草唇、果樹與棕櫚 | 亮面塑膠高光、細描邊、磚面廣場、公寓立面 |
| 角色 | 虹膜大眼、風中飄動的長圍巾 | 大圓頭、點點眼、大腮紅、條紋 T 恤 | 幾何五官（眼睛大小／間距／角度可調）、彩色上衣 |
| 世界主角 | 風：草叢波浪、風車、風線、夜晚發光的古代符文 | 生活：河、橋、瀑布、果樹、市集帳篷 | 人：窗戶裡揮手的居民、噴水池、咖啡座 |
| HUD | 白線圖示＋陰影、無面板；愛心心情、時間／溫度／風、圓形小地圖 | 大字時鐘、奶油色金幣膠囊、黃色手機鈕＋背包鈕 | 上方白色狀態列＋下方按鈕托盤（地圖／背包／選單） |
| 選單 | 深色半透明石板＋金色角括號 | 奶油色厚面板＋傾斜彩色名牌 | 白卡＋彩色標題列＋光澤按鈕 |
| 創角 | 石台展示＋選項旋轉木馬＋色相滑桿 | 魔鏡＋分類玩具鈕＋卡片格 | **臉部製作室：大小／間距／角度／高度滑桿＋骰子隨機** |
| 檔案 | 環狀分段量表＋旅人稱號 | 島民卡（證件風）＋膠囊量表 | 性格座標圖＋需求列＋人際關係圖 |
| 對話 | 下方石板字幕＋選項括號 | 大泡泡＋逐字彈出＋「哇！」 | 漫畫氣球＋集中線＋「！？」「好耶～！」 |
| 地圖 | 等高線地圖、準星、光點溶接、區域標題卡 | 手機 App → 插畫地圖 → 圈形 iris 轉場 | 城鎮地圖 → 彩色斜條擦除 → 電視字幕條 |
| 工坊 | 羊皮紙畫布 | 木畫架 | 電視「ON AIR」＋底片影格 |
| 動畫節奏 | 平穩、電影感（60fps） | 彈跳、俐落、玩具感 | 喜劇時機：預備→大反應→停頓 |
| 字體 | Noto Serif TC＋Cinzel／Noto Sans TC | 粉圓＋Nunito Black | Noto Sans TC Black＋Nunito Black |
| 效能成本 | 中高（草叢逐葉擺動） | **低**（平塗、少漸層） | 中（高光與描邊，可預烘） |

### D · 風語原野
- **優點**：最成熟、最有「大作」質感；探索與天氣光影表現最好；擴充新地點時氛圍最一致。
- **限制**：深色 UI 略嚴肅，療癒感與可愛度不如 E/F；草地動態較吃效能（省電模式改為成組擺動）。

### E · 晴日島嶼
- **優點**：最療癒、最親切、最容易被大眾喜歡；平塗風格**玩家最容易自己畫出相容的素材**；效能最低，最適合常駐的懸浮桌寵。
- **限制**：整體氣質與知名島嶼生活遊戲接近，必須靠原創角色、地點與獨特系統（OC、動畫工坊、桌寵）建立辨識度。

### F · 奇趣鎮
- **優點**：最貼近「OC」核心——臉部參數化讓每個玩家的角色真的不一樣；心願泡泡讓自主生活一眼看懂；喜劇反應最有趣、最適合社群分享。
- **限制**：城鎮題材的自然探索感較少；白色 UI 需要嚴謹的層次設計，否則容易單調。

## 建議（僅供參考，最終由你決定）

**最推薦：E · 晴日島嶼為主體，並借用 F 的兩個系統。** 一是「臉部製作滑桿＋骰子」，二是「居民心願泡泡」。

理由：
1. **最符合你設定的關鍵字**：療癒、可愛、舒適、有趣，同時具備成熟商業手遊的完成度。
2. **玩家創作最友善**：平塗、無描邊、色塊清楚，玩家在繪畫工坊與動畫工作室畫的東西最容易和官方美術一致。
3. **效能最低**：懸浮桌寵會長時間在其他 App 上方運作，E 的平塗角色最省電。
4. F 的臉部滑桿與心願泡泡是「系統」而非「畫風」，可以直接套進 E 的視覺語言（奶油面板＋玩具按鈕），兩者相容。

其他組合：
- 想要更高級、更有冒險感 → **D**，或 **D 的世界＋E 的 UI**。
- 想要最強的角色個性與喜劇感 → **F**，可把 F 的城鎮換成 E 的小島。
- 也可以和第一輪混合，例如 **E 的世界＋C 的手帳 UI**。
