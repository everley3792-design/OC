## 一、你回報的六個問題

### 1. 操控中／跟隨中的角色自己換地點時，畫面沒有跟過去 ✅
- **原因**：操控中的角色被硬性排除在「自己去別的地方」之外（12.0 之前牠是手動的，所以合理）；12.0 預設改成半自動後，牠會「想去」卻永遠走不出去。另外，「觀察」中的角色離開時，鏡頭留在原地。
- **修正**：半自動／全自動的操控角色可以自己走到出口，**整個畫面跟著換到那個地點**，到了之後接著做牠原本想做的事；剛到會先待一陣子。只在你單純看著世界時發生（開著選單、對話、佈置、小遊戲、教學時不會）。「觀察」中的角色離開時也會跟過去並繼續觀察。手動模式永遠不會自己離開。生活設定新增開關「操控中的角色也可以自己換地點」。
- **驗證**：`tests/v13` 1a–1c。

### 2. 匯入圖片要能翻轉、裁切、縮放、上下左右移動 ✅
- 圖片角色的外觀頁新增「調整圖片」：左右翻轉、走路時跟著左右轉向、放大縮小、水平／垂直位置、四邊裁切、全部重設。**繪製時才套用，原圖不會被改動**，所以都可以復原；裁掉下方時腳仍然踩在地上。
- **驗證**：v13 2e、2f。

### 3. 圖片角色要有預設動畫與特效、左右朝向要正確 ✅
- **原因**：只有一張圖時，所有動作都退回同一張靜止圖；而且「任何方向共用的一張圖」從來不會鏡像。
- **修正**（`js/char/puppet13.js`，`OC.Puppet`）：沒畫過的動作由圖片自己表演——沿用骨架角色全部動作的身體動態（傾斜、彈跳、壓扁、晃動），再加上圖片專用的幅度與特效（Zzz、星星、音符、青筋、眼淚、汗、驚嘆號、碎屑、臉紅線、書、釣竿…）。你在動畫工作室畫了某個動作，就改播你畫的（不再疊加）。往左走時整張圖鏡像；正面的圖可以關掉轉向。桌寵輸出的影格也因此是會動的。
- **驗證**：v13 2a–2d、2g（12 個動作逐一檢查「會隨時間變化」「和站著不同」「特效畫在圖片外」）。

### 4. 特質、喜歡的物品、口味要能隨機；大量擴展特質；選了之後提示衝突 ✅
- 特質從 32 個擴充到 **79 個**（`js/char/traits13.js`）。新特質全部是資料驅動、**每一個都有量得到的效果**（需求下降速度、偏好的活動與社交、情緒敏感度、走路速度、接受邀請的機率）與自己的台詞。
- 衝突關係是雙向的；選了一個特質後，互相矛盾的格子會變暗並標示「和『○○』衝突」，上方列出不能選的；硬點會被拒絕並說明。
- 「隨機」按鈕：特質（3–5 個、保證不矛盾）、喜歡／討厭的東西、興趣、習慣、物品喜好、口味。你親手鎖定的食物喜好不會被改掉。
- **驗證**：v13 3a–3e。

### 5. 全面重構新手教學 ✅
- 改成四個短章節：相遇（走路、看四周、點角色、撫摸、抱起）／照顧（狀態、操控模式、時間、背包）／一起玩（搖樹、玩一局）／出門（地圖、前往地點、分頁、桌寵）。每一步由真實動作完成；有章節進度點；可略過單步、跳過全部、重新觀看。**完成（不是跳過）才有紀念獎勵 60 星幣，只給一次**。
- **驗證**：v13 7a–7d。

### 6. 全面重構桌寵系統 ◐（做了可以驗證的部分）
- **做了**：新增原生的「生活作息」層（`core/pet/PetRoutine.kt`，純 Kotlin）：11 種資料驅動的連續動作，依時間、心情、個性挑選（早上伸懶腰、無聊踱步、難過躲到角落、想睡打哈欠找地方坐下、開心表演、暴衝…），被抓起、掉落、和別隻互動時自動讓位；寵物中心有開關。加上本版圖片角色的桌面影格會動。
- **沒做**：原生層（視窗、觸控、服務）沒有整個重寫，寵物中心頁面也沒有重新設計。原因是**我無法在實機驗證**——把你手機上目前能跑的程式整個換成沒測過的新程式，風險大於好處。如果你告訴我桌寵在你手機上具體哪裡不好（動作太少？反應遲鈍？位置怪？泡泡？），我可以針對性地重做。
- **驗證**：Kotlin `PetRoutineTest`（4 項）；APK 建置與 `verifyDebugApk`。📱 實機表現未驗證。

## 二、重新設計

### 介面 ✅（好不好看請你判斷）
你說上一版太醜，所以整個重做。新的預設風格：
- **世界裡沒有框**：頭像、時間、任務都是白色字與圖示直接浮在畫面上（柔和陰影），畫面留給世界。
- **選單依主題**：淺色＝暖色紙感、奶油底、棕色字、大圓角、薄荷色與太陽黃；深色＝石板玻璃、細線邊框、寬字距、小圓角、一個冷色光暈表示「選取」。
- **對話永遠是溫暖的**：奶油色圓潤對話框、深棕字、斜斜的角色名牌（每個角色固定一個鮮明顏色）、會跳動的黃色小箭頭、圓角長條選項；文字逐字出現並配上角色自己的聲線。
- 常駐元件不使用背景模糊（每一幀都要算，低階手機會掉幀）。
- 「雅緻」（12.0）與「玩具」（10.0）仍可在設定切換。舊存檔會自動換到新風格一次。
- **驗證**：v13 6a–6c；畫面：`deliverables/v13/6-default-look.png`、`6-dark-menu.png`、`5-visit.png`。

### 玩法與內容 ✅
- **猜拳**（點角色 → 玩耍 → 猜拳）：先贏兩次；對手出拳依個性（固執的愛重複、好勝的會針對你上一拳）。
- **躲貓貓**：角色真的躲到場景裡的某棵樹或草叢後面，你去搖出來；有倒數，搖錯幾次牠會偷笑露出破綻。
- **搖樹掉東西**：星幣或果子；每棵每天只決定一次（再搖不會再掉，不能刷）。
- 第一次得到新物品時，角色會把它舉起來。
- 獎勵都走固定 key（每個角色每天一次）；每玩一局只送一次進度事件。
- **驗證**：v13 4a–4e。

### 更聰明、更有個性 ✅
- **角色會主動來找你**（在場、非手動、有空、和你關係不錯的那個；我行我素的很少來，黏人的常來）：邀你玩、帶小禮物、**問你問題並記住答案**、告訴你牠注意到另一個角色的近況、**約你明天在某地見面**——你真的去了牠會很開心並記成重要回憶，沒去牠會失落也會記得。
- 79 個特質各自影響行為與說話；「想法」面板會寫出是哪個特質讓牠想做這件事。
- **驗證**：v13 5a–5h。

## 三、12.0 的收尾
12.0 的完整回歸在這一輪跑完，過程中找到並修掉：操控中的半自動角色在啟動後 40 秒內不會自己行動（計時基準錯誤）；兩個測試檔被行內 `//` 註解吃掉後半行（其中 `tests/play/run.js` 因此整個無法執行）；測試工具把所有角色都設成手動，導致需要同伴自主行動的舊情境失敗（改成只有操控中的角色是手動）。12.0 沒有另外出 APK——它的內容都包含在 0.13.0 裡。

**怎麼讀這張表**：沒有任何一次是「九個套件在同一輪全部通過」。一共跑了三輪完整回歸，每一輪失敗的項目都不同，上表是最後一輪的數字加上失敗項目的單獨重跑。v12 10a、pet 16c、life 2b 沒有改任何程式就在重跑時通過，判斷是軟體渲染（約 2 fps）下的時序問題，但**沒有逐一查明原因**。

回歸過程中找到並修掉的實際問題（不是測試問題）：
- 角色主動來訪沒有開機緩衝，一進遊戲就可能來打斷，佔住角色並開對話——這也是第一輪舊套件大量失敗的原因。現在開啟後 4 分鐘內不會來訪，生活設定新增「角色會主動來找你」開關；測試 harness 預設關閉來訪。
- 躲貓貓有三種情況點樹沒反應：鏡頭拉太近畫面上沒有樹（現在會暫時拉遠、結束後還原）、藏身的樹長在菜園等可互動物件上（尋找期間搖樹優先）、樹前站著別的角色（不選這種樹）。提示改為依當下鏡頭位置。
- 教學：短時間內連做兩個符合條件的動作會跳過下一步。
- `android/gradle.properties` 的版本仍寫 0.11.0，APK 檔名因此是錯的（已改為 0.13.0-alpha／17）。

## 五、沒做與已知問題
- 📱 所有原生功能（桌寵、作息、音效、雙人動作、小工具、觸覺）仍未在實機驗證。
- ◐ 桌寵「全面重構」只做了作息層（見上）。
- ◐ 「徹底重新設計整個遊戲」：這一輪重做了介面風格、對話、教學，新增了兩個小遊戲、搖樹、主動來訪與約定、大量特質；**沒有**重做各個頁面的版面配置（背包、商店、工坊、圖鑑仍是原本的結構，只是換了新風格）、沒有新增地點、沒有重做 3D 的房屋與樹木。
- 圖片角色的「調整圖片」用滑桿操作，沒有做用手指直接拖曳／雙指縮放的裁切框。
- 躲貓貓需要場景裡有至少三個可以搖的樹或草叢（室內不能玩）。
- 軟體渲染下測試偶爾因為時間不夠而失敗（同一情境單獨重跑會過）；不代表手機上的表現。
- 本輪 APK 是 **Debug 簽章**，不是正式發行版。
