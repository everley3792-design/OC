# 17.3（0.17.3-alpha）關係每天結算

依據：`docs/v17-roadmap.md` 第三節（玩家已同意全部建議）。

參考作品只取玩法原則（「關係會累積，到了某一天才變」），沒有用它的文字、介面圖形或素材；年齡界線用我們自己的、更嚴的規則（未滿 18 歲不涉戀愛）。

## 做了什麼

### 1. 關係的名稱每天結算一次（`OC.Bond17`，`js/life/bond17.js`）

**以前**：一個數字一跨過門檻，名稱就立刻改變。聊得開心一次就成了「朋友」，吵一次又變回去。

**現在**：
- 數字（熟悉、好感、信任、心動、衝突）照樣跟著每件事改變；
- **名稱**在每個遊戲日開始時結算一次（離開時也會，在背景生活裡）；
- 要**連續兩天**都指向同一個名稱才會改變；
- 往下掉要多掉一截（8 分）才算，不會在門檻附近來回跳。

**友情的階段**（有方向，各自結算）：

| 階段 | 條件（好感／信任／熟悉） |
|---|---|
| 陌生 | — |
| 認識 | 熟悉 6 以上（認識了就不會再變回陌生） |
| 朋友 | 好感 35、熟悉 25 |
| 好友（原本叫「摯友」） | 好感 70、信任 55、熟悉 50 |
| **知己**（新的） | 好感 85、信任 75、熟悉 75 |
| 對手 | 衝突 45 以上而且好感低於 25 |

**也會往回走**：
- **淡了**：四天以上沒有一起做任何事，熟悉每天 −1、好感每天 −0.5，掉到門檻以下就退一階；
- **釋懷**：對手之間的衝突降到 30 以下，兩天後變回「認識」；
- 冷戰、疏遠仍然是 12.0 的 `OC.Arcs`（沒有另寫一套）。

**不會被自動改變的**：
- 玩家設定的（`fixed`）；
- 「鎖定關係」（`lockRel`）；
- 家人、自訂、戀人、未婚伴侶、伴侶、前任（只由玩家或要玩家同意的事件改變）。

**改變的那天**：
- 兩個人都在畫面上：各說一句（升級、疏遠、變成對手、釋懷各有台詞），互相看一眼；
- 一張卡片「麻糬和栗子：認識 → 朋友」；
- 不在畫面上：卡片照樣有；離開時只寫進時間線（「你不在的時候」看得到）；
- 每次改變都記在 `life.bond17.log`（最多 400 條），好感度頁看得到。

### 2. 心動與戀愛線

- 原本的「親密」改名為**心動**（同一個數字 `intim`，不需要轉換存檔）。
- **單戀**：一方的心動 40 以上、好感 50 以上，對方沒有；
- **曖昧**：雙方都是；
- 也要連續兩天；
- **只在兩個人都成年、戀愛功能打開、「可以發展戀情」沒有關掉時**（`OC.Mind.romanceOK`）；未滿 18 歲不論數字和設定都不會有。

**在一起、訂婚、結婚、分手、復合都是事件，而且都要你按「同意」**：

| 事件 | 條件 | 同意後 |
|---|---|---|
| 告白（9.0 就有） | 好感 75、心動 55 | 戀人 |
| 求婚（新的） | 戀人 14 天以上、好感 80、心動 75 | 未婚伴侶 |
| 婚禮（新的） | 未婚伴侶 7 天以上 | 伴侶 |
| 分手（新的） | 戀人或未婚伴侶，衝突 60 以上、好感 30 以下 | 前任（拒絕＝牠們再好好談談） |
| 復合（新的） | 前任，好感 70、心動 60 | 戀人 |

每天的結算**不會**自己讓兩個人在一起或分開（v17 22 檢查）。

事件條件多了一個 `stageDays`（現在這個關係維持幾天了），記在 `r.st17`（設定關係或事件同意時寫入）。

### 3. 紀念日

- 在一起、訂婚、結婚、成為知己的**第 7、30、100 天**和**每一週年**（遊戲曆一年 112 天；實時曆 365 天）；
- 兩個人都記得（回憶，固定的 key，不會重複）；
- 紀錄裡一條「在一起第 7 天」；
- 在島上時有一段小劇場（`OC.Theatre`，兩個人各說一句；錯過了在「回放」看）；離開時只有回憶與時間線。
- 9.0 的「認識紀念日」照舊。

### 4. 關係的三層設定

角色檔案 › 關係 › 「設定」的下面多了「相處設定」，好感度頁的「設定」也是同一個：

| 層 | 選項 | 實際效果 |
|---|---|---|
| 關係 | 家人、朋友、好友、**知己**、對手、伴侶、戀人、自訂…（原本就有） | 固定那個名稱 |
| 身分 | 室友、同學、同事、鄰居、青梅竹馬、師徒、社團夥伴、筆友 | 見面的日子熟悉多 0.5 |
| 相處標籤（最多 3 個） | 愛拌嘴、互相照顧、良性競爭、不說話也自在、愛捉弄、互相依靠、有點尷尬、崇拜 | 各自改變數字怎麼動（例如愛拌嘴：衝突只算一半；互相照顧：見面的日子信任 +1；不說話也自在：不會淡掉） |
| 合拍度 | 很不合…非常合拍（−2…+2） | 好感與心動的增加 ×0.6…×1.4 |
| 可以發展戀情 | 開／關 | 關＝`romanceOK` 為假（用原本戀愛設定裡的 forbid 清單） |
| 固定 | 開／關 | 開＝不會自動改變（就是原本的 `fixed`） |

全部兩個方向一起套用。

### 5. 好感度頁（頁面 `bond17`）

- 口袋手機的「好感度」、角色檔案關係分頁最下面的按鈕；
- 上面選一個人；
- 每個其他人一張卡：
  - 關係名稱、單戀／曖昧；
  - **好感**（牠對對方，旁邊是對方對牠）；
  - **心動**（只在可以發展戀情時顯示）；
  - 身分、相處標籤、合拍度；
  - 快要改變時寫「再一天沒變，就會成為『朋友』」；
- 下面是**最近的變化**：日期、誰、從什麼變成什麼、是不是你不在的時候。

### 6. 其他

- 「好友」「知己」「未婚伴侶」也算進成就與島民的關係分數；住處（同床、住在一起）、感知（親近的人）、冷戰把「未婚伴侶」當成一對。
- 9.0 的「最好的朋友」事件仍然在關係升到好友那天觸發（經 `life:relUp`）。

### 17.2 的修正（觀察模式）

- 自動鏡頭已經對著正在說話的人時，上方的說明沒有寫「誰和誰在聊天」→ 改成照樣寫；兩個說話的人都算熱點。
- 這兩項在 0.17.2 的 APK 裡沒有，在 0.17.3 的 APK 裡。

## 沒有做／還不完整

- **台詞不多**：改變那天、紀念日、四個新事件的台詞共約 30 句；不同個性還沒有各自的說法。
- 好感度頁沒有圖表（只有長條與最近 15 條變化）。
- 「身分」只是名稱加上一點熟悉，沒有接到職業與學校（同事、同學不會因為一起上班上學自動出現）。
- 「改變的那天」的小動作只有各說一句與互看，沒有走到對方身邊；兩個人不在同一個畫面時只有卡片。
- 紀念日只有在一起、訂婚、結婚、知己；朋友、好友的紀念日仍是 9.0 的「認識紀念日」。
- 單戀、曖昧只是狀態與標示，還沒有影響 AI 的行為（例如多找對方說話）。
- 手機上沒有驗證。
