# 美術素材規範（第二階段：精緻 3D 場景 + 2D Sprite 角色）

> 第一階段的「純 2D」規範已由第三輪的選擇（做法 ①）取代：**世界是 3D、角色是 2D**。舊版保留在 git 歷史中。

## 0. 鐵則
1. **世界 3D、角色 2D**：地形、建築、樹木、道具、家具是 3D；角色（玩家 OC、居民）、UI、繪畫工坊、逐格動畫、玩家匯入素材、桌寵一律 2D。
2. **鏡頭固定**：正交、俯角 50°，只平移／縮放，不旋轉。所以模型只需要好看的「正面＋上方」，背面可以簡化。
3. **對齊公式**：`X = x, Z = (y + 層·24)/sin50°, Y = 層·24/cos50°`。版面以設計座標 (x, y, 層) 撰寫，點擊座標＝設計座標，不用射線。
4. **原創**：參考作品只取原則（柔和比例、玩具感、清楚層級）；不得使用其角色、Logo、介面圖形、地圖或素材。
5. **手機預算**：整島 ≤ 約 250 draw calls、≤ 6 萬三角形（目前實測 ~220 calls / 4.4–5.7 萬三角形）；點光源 ≤ 3；材質與幾何快取共用。

## 1. 3D 模型（`game/js/world/models.js`，程式建模）

| 項目 | 規範 |
|---|---|
| 單位 | 1 = 1dp 設計單位；模型原點在地面中心，+Z 朝鏡頭 |
| 比例 | 角色螢幕高 ≈ 30；門高 33（角色頭約到門楣，動森式大頭比例）；房屋牆高 40–46、屋頂再 +30；果樹總高 ≈ 60 |
| 柔邊 | 一律用倒角擠出（`rbox`）、車床（`lathe`）、細分二十面體；不用硬直角方塊 |
| 細節層次 | 房屋：石基座、角柱、雙斜屋頂＋瓦片帶＋屋脊、山牆圓窗、煙囪、門框＋門把＋台階＋門燈、窗框＋十字窗格＋百葉＋花箱；樹：根部外擴的樹幹、7 團樹冠、果實 |
| 材質 | 預設 `MeshLambertMaterial`（便宜、柔和）；水面／天空相關用 Basic + 捲動貼圖；顏色取自 `OC.Style.P` 色盤 |
| 夜晚 | 會發光的部件把材質登記到 `Models.night.windows / lamps`，由光照系統驅動 emissive |
| 不穿模 | 每個物件呼叫 `ctx.block(x, y, w, h)` 登記碰撞區；放在地面上（y=0 基準 + 地面高度），不可懸空 |
| 擺動 | 樹冠、花、灌木用 `ctx.sway()`（JS 旋轉）；草葉用 GPU 頂點著色器（`env.windMaterial`） |

## 2. 地形
- 島＝沙層 + 草皮層（倒角擠出、條紋草皮貼圖），高台＝岩層斷崖（地層貼圖）+ 草皮蓋 + 前緣柵欄，石階坡道連接層級。
- 河流（帶狀網格 + 捲動水紋）、瀑布、木橋、碼頭、廣場石磚、石板小徑（Instanced）。
- 可行走性、層級、地面高度都是解析函式（`OC.Areas.*.walk/level/ground`），導航網格、3D 地形、點擊判定一定一致。

## 3. 2D 角色（`game/js/art/vchar.js` rig + `OC.Style`）
- 參數化角色：耳型 6 種、尾巴 2 種、毛色/眼睛/腮紅/內耳色、上衣顏色/圖案、配件（圍巾/毛帽/兜帽）、髮夾；臉部表情（眼型、嘴型、腮紅、眨眼）。
- **四方向**：`face`（−1…1 左右轉）與 `back`（0…1 背面）連續數值，由移動方向平滑趨近（τ≈0.15s），不會瞬間翻轉；背面時五官淡出。
- 在世界中是**垂直看板**（高度 ×1/cos50° 補償，螢幕上不變形），腳底對齊地面，圓形接觸陰影；被建築遮住時顯示紫色剪影（x-ray）。
- 紋理只在「量化姿勢」改變時重畫（走路 8 格、轉身 9 級、眨眼）；呼吸與彈跳是網格變換，不重傳紋理。

## 4. 玩家素材（匯入圖片／逐格動畫）
| 項目 | 規範 |
|---|---|
| 畫布 | 256×256 PNG（透明背景），腳底對齊到畫布 90% 高度（匯入時自動處理） |
| 影格 | 最多 24 格，4/6/8/12 fps |
| 方向 | **單向素材**：島上以左右鏡像（經過 0 的平滑縮放，不是瞬間翻面）＋走路搖擺與彈跳呈現；不顯示背面 |
| 走路動畫 | 若作品之後支援「走路」影格組，會自動切換；目前同一組影格循環 |
| 去背 | 匯入時可選「以左上角顏色去背」 |
| 儲存 | dataURL 存在存檔（localStorage + 原生備份）；容量不足時會提示刪除作品 |

## 5. 桌寵輸出
遊戲把目前外觀輸出成 192×192 PNG 影格：idle 4、walk 8、drag 2、sit 2、sleep 2、happy 4（`OCNative.savePetSprites`），
原生端存到 `filesDir/pet/` + `manifest.json`，`PetView` 以 Canvas 繪製並加上陰影、鏡像、落地壓扁、拖曳擺盪。
