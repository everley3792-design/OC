# 角色與場景美術規範

## 鐵則
1. **純 2D**：所有角色、建築、地圖、家具、物品都是 2D 圖（向量或點陣）。禁止 3D 模型與 3D 場景。
2. **可編輯**：角色必須拆成部件（身體、頭、耳、眼、眉、嘴、腮、花紋、尾巴、服裝、手持物），每個部件獨立圖層與錨點；禁止把角色畫成無法拆解的單張合成圖。
3. **原創**：參考圖只取方向（比例、配色、構圖、氛圍），不得描摹或複製任何既有遊戲的角色、地圖、素材。
4. **一致的光源**：左上方主光；陰影落向右下。

## 角色比例（共通）
- 頭身比 ≈ 1:1（大頭小身）；頭寬 ≈ 身寬 × 1.55。
- 臉部：眼睛位於頭部垂直中線略下；眼距 ≈ 頭寬 0.42；嘴在眼下方 0.4 頭高。
- 3/4 轉身：五官整組平移 ≤ 頭寬 0.2；近側眼縮窄 40%。背面：隱藏五官，顯示後腦小髮旋。
- 耳型（至少）：貓耳、兔耳、熊耳、折耳、嫩芽；每種都必須支援 front / side / back。
- 預設 OC：麻糬（奶白貓耳、紅/桃色領巾、星星髮夾）、栗子（栗色兔耳、綠/青色圍巾、葉子髮夾）、蘇拉（薰衣草熊耳、毛帽、愛睏）。

| 方案 | 世界中角色高度 | 描邊 | 著色 |
|---|---|---|---|
| A | 46–50dp | 無 | 徑向漸層體積 + 暖色邊緣光 + 接觸陰影 |
| B | 26 原生 px（世界 ×4） | 自動 1px 深色描邊 | 2–3 階平塗，左上 1px 高光 |
| C | 50–52dp | 墨線 1.5–1.9 單位，boil ±0.55 | 平塗＋錯版 0.9 + 右下排線 |

## 場景
- 視角：斜俯視約 35°；地面以俯視繪製，垂直物（樹、屋、角色）以正面略俯視繪製。
- 高度：每層斷崖高度 A 22–30dp、B 12–14px、C 34–40dp；斷崖面必須比頂面暗且有材質（地層線 / 石條 / 排線）。
- 物件比例：房子 ≈ 角色 1.4–1.8 倍高；樹 ≈ 角色 1.2–2 倍；門 ≈ 角色 0.8 倍。
- 生命感：每個畫面至少 3 種環境動態（樹搖、水波、雲影、煙、花瓣、螢火蟲、雨）。
- 密度：可互動物件周圍保留 1 個角色寬的空地；HUD 下方不要放重要物件。

## 色彩
- A：高明度低彩度；陰影用帶紫的暖灰，不用純黑。
- B：只能使用調色盤中的顏色（`themes/pixel/kit.js` → `P`），光影結果必須經過量化。
- C：紙色底；墨色 #3B2A25（不是黑）；強調色每畫面 ≤ 2 種。

## 玩家自製素材
- 自畫部件需落在對應錨點範圍內（創角時顯示虛線輪廓指引）。
- A：匯入時自動套用「柔化」濾鏡（模糊邊緣 + 漸層光）以融入。
- B：匯入時量化到調色盤並對齊像素網格。
- C：匯入時可選「墨線化」（描邊加粗 + boil 預烘 3 幀）。
