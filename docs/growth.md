# 技能、人生目標、稱號、成就與收藏（第六階段）

## 1. 技能（`OC.Mind` 經驗值 ＋ `OC.Growth` 解鎖，資料在 `OC.PlayData.SKILLS`）
- 經驗：活動結束時依時間累積（`record → skill`）；小遊戲、採集、收成、觀察也會給。等級 `floor(sqrt(xp/15))`，上限 10（Lv.1 = 15、Lv.2 = 60、Lv.3 = 135 …）——正常遊玩會進步，不可能點一下就升滿。
- 個性影響喜好與練習意願（特質讓相關活動更常被選），但不會禁止學習其他技能。
- **每個技能都有實際效果**（系統用 `OC.Growth.has(c, id)` 判斷）：

| 技能 | 等級 → 解鎖 |
|---|---|
| 閱讀 | Lv1 讀書（書桌）／Lv2 聊天時教朋友（對方閱讀經驗、回憶）／Lv4 讀書時心情更好 |
| 園藝 | Lv1 收成多 1 個／Lv3 菜園長得快 25%／Lv5 照顧花草時偶爾帶回向日葵種子 |
| 運動 | Lv1 玩耍時翻跟斗（新動作）／Lv3 精力下降變慢 |
| 料理 | Lv1 鬆餅、布丁／Lv2 咖哩、水果塔／Lv3 烤魚／Lv4 刀子變慢、火候區變寬 |
| 社交 | Lv2 邀請更容易被接受／Lv4 共同活動時大家更開心 |
| 釣魚 | Lv1 收線區變寬／Lv3 稀有魚機率提升／Lv5 偶爾一次兩條 |
| 探索 | Lv1 採集偶爾多一個／Lv3 小生物比較不會警覺 |
| 藝術 | Lv1 新活動「畫素描」／Lv3 偶爾把作品送給你（畫） |
| 音樂 | Lv1 新活動「唱歌」／Lv3 唱歌時附近的 OC 心情變好 |

- 升級：演出（得意／歡呼依個性）、音效、卡片列出解鎖內容；記錄在角色的生活紀錄與回憶。
- 永久的個性改變仍然只經過 `OC.Mind.suggest` → 玩家同意。

## 2. 人生目標（aspiration，`OC.Growth`，資料在 `OC.PlayData.ASPIRATIONS`）
- 7 種：綠手指、家常料理人、釣魚達人、書蟲、人氣王、小小探險家、生活藝術家。每種 3 步，每步一個目標（同 `docs/quests.md` 格式，`oc:'self'` 指這隻 OC）。
- OC 沒有目標時會依個性（`fit(c)`）自己找一個（短暫空檔後），並說出來；玩家可在角色檔案「成長」**更換、鎖定（不自動換）、先不要**。
- 影響生活：目標相關的活動在 Utility AI 裡加分（`actBonus`）。
- 完成：星幣＋紀念品＋稱號（`OC.Tx` key `asp:<oc>:<id>`，一次）、里程碑回憶、情緒；並**提議**相關特質／興趣（需同意）。
- 和第四階段的「願望」不同：願望是短期小事（自然出現、自己消失），人生目標是長期方向；兩者共用進度事件。

## 3. 稱號
全島共用（`S.play.titles`），來自長期挑戰、人生目標、部分成就與隱藏任務。每隻 OC 可以戴一個（角色檔案「成長」），顯示在名字下方；也提供給桌寵狀態（`petState().title`）。

## 4. 成就（`OC.Achieve`，資料在 `OC.PlayData.ACH`）
- 37 個，分類：生活、社交、探索、收藏、技能、創作、特別；包含初次、累積、探索、特殊條件、隱藏、長期。
- 條件來自真實紀錄：`OC.Progress.count(ev, filter)`／`distinct(ev, field)`（第一次被問到時開始統計）、舊的統計 `S.stats`、圖鑑、關係、技能。
- 達成自動解鎖（卡片＋音效）；**獎勵由玩家在「日常 › 成就」領取**，`OC.Tx` key `ach:<id>` → 不會重複發放（舊存檔在第五階段已自動入帳的，會顯示為已領取）。
- 隱藏成就顯示提示，不洩漏內容；沒有每日登入、點擊次數之類的成就。

## 5. 收藏圖鑑（`game/js/ui/p6pages.js`）
- 統一記錄：魚、小生物、海洋收藏、植物與作物、料理與飲料、家具與紀念品、服飾、禮物玩具材料，以及**地點、活動、特殊事件**。
- 狀態：**未發現**（剪影＋取得提示）／**看過**（在商店看過，`S.play.spotted`）／**持有中**／**曾經持有**（發現紀錄永遠保留，`S.seen`）。
- 搜尋、分類、狀態篩選、稀有度、排序、★ 收藏標記；食物詳情顯示每隻 OC 吃過幾次、喜好與是否玩家設定。
- 第一次發現：小卡片（名稱、類別、稀有度、+10 星幣）＋閃亮音效，不跳出大面板。

## 6. 生活日誌與回憶卡片（角色檔案「日誌」）
- 資料就是角色的回憶（`c.life.mem`），只整理重要的（重要度 ≥ 0.38，或被珍藏）；不會把走路、普通吃飯記成流水帳（可開「小事」看全部）。
- 分類（重要、初次、成長、社交、和你、發現、事件、★珍藏）、人物、地點篩選；人生故事時間軸。
- 回憶卡片：日期、地點、參與者頭像、情緒、重要度、「共同回憶」標記（多人事件用同一個 key 系列，兩邊的紀錄一致）。
- 「回顧」只重播事件對話，不會再給獎勵、改變關係或寫入回憶。
- 技能、人生目標、稱號、日誌、回憶、關係、生活都集中在角色檔案，不另開入口。
