# 第五階段完成紀錄與測試報告（世界、地點、物品與經濟）

版本 **0.5.0-alpha（versionCode 8）**　APK：`deliverables/apk/oc-shimeji-0.5.0-alpha-debug.apk`（簽章與 0.2.x–0.4.0 相同，可直接覆蓋安裝；存檔自動升級到 v4）
標示：✅ 已實作並在本環境自動測試　🟡 已實作，需實機確認　⚠ 已知限制　🔒 依規劃標示為未開放

核心原則：**地點提供活動、活動影響角色、角色累積記憶、記憶改變未來生活。**
- 地點 → 活動：每個地點登記 AI 可做的活動與可互動設施（`OC.Places.P[*].acts`、`OC.Areas`）。
- 活動 → 角色：活動改變需求、情緒、技能、飲食喜好（品嚐紀錄）。
- 角色 → 記憶：第一次造訪、釣到稀有魚、料理三星、吃到最愛／討厭的食物、地點事件都寫成回憶（有 key 不重複）。
- 記憶 → 未來：回憶的地點感受回饋到 `Places.affinity()`（更常去喜歡的地方）；喜好影響下一次的反應與效果。
