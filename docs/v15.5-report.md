# 15.5（0.15.5-alpha）剩下的內容

把 15.2 計畫裡還沒做的內容做完：夢、宣言、連續劇、願望與恐懼、人生階段、季節活動。全部跑在遊戲時鐘與唯一的進度事件流上；離線補算不給任何東西；台詞與名稱都是原創。程式：`js/life/life15.js`（`OC.Life15`）、`js/life/events15.js`（資料）。

| 內容 | 怎麼運作 |
|---|---|
| **夢** | 角色好好睡一晚（60 遊戲分鐘以上）之後，大約四次有三次會記得一個夢。夢是從牠自己的生活組出來的：最近的回憶、朋友、去過的地方、願望、怕的東西（＝噩夢），或一些奇怪的夢。存最近 12 個、記進回憶；下次牠醒著又在你附近時會跟你說一次。角色檔案和島報（「昨晚的夢」）看得到 |
| **宣言** | 每天早上，有幹勁的角色（勤奮、好勝的比較常，懶散的比較少）可能宣布一個三天內的小目標：釣 3 條魚、做 2 道料理、採集 4 次、和大家聊 3 次天、上台表演、打工、種 2 樣東西（遊樂園沒開就不會要上台）。進度從唯一的進度事件流算；做到時入帳一次（key `decl:<角色>:<宣言時間>`）、得意、留下回憶；三天沒做到會有點失落，也會記得。檔案顯示進度，島報有「宣言進行中」 |
| **願望與恐懼** | 願望在第四階段就有（`Mind` 的 wishes）。這次加上**恐懼**：每個角色 0–2 個（勇敢的沒有、膽小或敏感的多一個），由角色 id 決定：打雷的雨天、黑漆漆的夜晚、高的地方、深深的海、人很多的地方、蟲子。遇到時會緊張、說出來；**那時候摸摸牠或抱抱牠**，三次之後就不怕了（留下回憶「因為有你陪著，不再怕…了」）。檔案顯示每個恐懼還剩幾格 |
| **人生階段** | 依你在角色資料寫的年齡：童年（<13）、少年、青年（18+）、成年（30+）、長者（60+）。**年齡是你的設定，不會自己改**；生日那天檔案會出現「生日快樂：長大一歲」，按了才加一歲（一年一次），跨階段時記進回憶。沒寫年齡就沒有階段 |
| **連續劇「說不出口的話」** | 三段、跨天、用旗標串起來：(一) 角色想跟某個朋友道謝卻說不出口；(二) 牠來問你，你選「直接說出來」「寫一封信」或「再等等」；(三) 依你的選擇，鼓起勇氣當面道謝（關係大幅變好、兩人都記住）或過幾天才慢慢說出口。和 0.9 的「秘密基地」一樣經事件引擎，事件不給獎勵 |
| **季節活動** | 每個季節的週末是節日：春「花之祭」、夏「夏夜煙火」、秋「豐收祭」、冬「燈之祭」。節日當天送一份禮物（花瓣餅乾／仙女棒／南瓜派／星星可可，key `fest:<節日>:<日期>`，一天一次）；夏夜煙火晚上在戶外會看到煙火（特效開著時；一個 InstancedMesh）；豐收祭收成多一個。島報頭版寫今天的節日 |

## 修正（開發時）
- 季節活動的日期判斷：「今天」會套用你選的季節（以及預覽參數），但查「某一天是不是節日」只看日曆——之前兩者混在一起，預覽模式下每一天都被當成節日。

## 還沒做的

- 連續劇只有這一部（加上之前的「秘密基地」與冷戰／和解）。
