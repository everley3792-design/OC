# UI 元件規格

所有尺寸以 **dp**（設計基準 360×640）表示；B 方案在 UI 網格 540×960 上以「UI px」表示（1 UI px = 2 螢幕 px，等於 0.667dp）。

## 共通規則
| 項目 | 規格 |
|---|---|
| 最小觸控熱區 | 48×48dp（視覺可小，熱區不可小） |
| 邊距 / 間距 | 16dp 邊距；間距 4/8/12/16/24 |
| 安全區 | 上方用 `WindowInsets.statusBars`，下方 `navigationBars`；HUD 不得進入手勢區 |
| 文字 | 內文 ≥ 12sp（B：16 UI px）；數字用等寬或 tabular |
| 主要按鈕 | 每頁 1 個，放右上（頁面）或底部（表單） |
| 長按 | 450ms，期間顯示環形進度 |
| 拖曳 | 位移 > 8dp 才開始；被拖物件跟隨並落後 1–2 幀以顯得有重量 |
| 動畫時長 | 快 160ms（按壓）、標準 260ms（切換）、慢 420ms（頁面） |
| 減少動態 | 系統「移除動畫」開啟時：轉場改淡入淡出，不做縮放、不做抖動線條 |
| 不同手機尺寸 | 寬度 320–480dp 皆測試；寬度 > 400dp 時網格增加一欄而非放大元件；平板以中央 480dp 欄位呈現 |

| ink | #6E5A64 | #F3E9EE | #3A2A33 | #3B2A25 |
| inkMuted | #9C8892 | #B9A9B2 | #6A5560 | #7A6355 |
| accent | #F5A893 | #F3A08B | #E06F5B | #E8B64C |
| positive | #8FCAA9 | #8FCAA9 | #5C9B4C | #86AE5F |
深色模式：A/C 反轉 surface/ink 並降低漸層亮度；B 改用 `dark` 框樣式（已在 HUD 使用）。世界層不受系統深色模式影響。

## 效能模式在 UI 上的差異
- 省電：關閉 HUD 浮現動畫、背景散景、紙紋（C 改用靜態紙紋貼圖）、毛玻璃（A 改不透明）。
