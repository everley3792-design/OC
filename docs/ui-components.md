## 手勢分工（避免衝突）

| 手勢 | 目標 | 判定 |
|---|---|---|
| 點擊 | 世界：移動 / 互動 | 位移 < 9px 且未達長按 |
| 長按 480ms | 世界：查看資訊 | 期間未移動 |
| 單指拖曳 | 世界：平移鏡頭（不會讓角色走路） | 位移 > 9px |
| 雙指 | 世界：縮放（1.15–3.2×），中點平移 | 第二指按下即切換 |
| 拖曳物品 | 快速背包 → 世界 | 垂直拖 > 12px，或按住 220ms 後水平拖（避免和托盤水平捲動衝突） |
| 捲動 | 頁面（`touch-action: pan-y`） | 頁面打開時世界不接收事件 |
| 拖曳家具 | 佈置模式的幽靈家具 | 從家具上開始拖曳；點地面則移到該處 |

以上在 Playwright 觸控模擬中逐項測試過（見 `docs/phase2-report.md`）。
