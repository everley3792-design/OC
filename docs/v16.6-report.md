# 16.6（0.16.6-alpha）對話引擎

計畫（`docs/v16-plan.md`，原本的 16.3，因插隊的四項順延）：話題引擎＋對話行為＋對話記憶（每句回應上一句）；自主閒聊＝表情＋關鍵字泡泡、可偷聽；沒話題時來問玩家（選或打字，離線關鍵字字典）；八卦；台詞第一批。

## 原本的狀況

| 項目 | 原本 |
|---|---|
| 聊天內容 | 「聊天」＝`talk` 一句＋`talk_r` 一句（熟的話再一輪）；兩句之間沒有關係，常常各說各的 |
| 話題 | 沒有。台詞偶爾帶到共同興趣或回憶，但沒有「我們在聊什麼」 |
| 立場 | 沒有：角色對任何事都沒有看法，不會附和也不會反對 |
| 記憶 | 只記得「和某某聊天」；不知道對方喜歡什麼 |
| 別人的對話 | 每一句都以完整泡泡顯示在畫面上，人多時很吵 |
| 八卦 | 沒有 |

## 做了什麼（`js/life/topic16.js`、資料 `js/life/topics16d.js`）

| 項目 | 做法 | 驗證 |
|---|---|---|
| 話題 | 從角色身邊的事挑：剛做的事、共同興趣、自己的興趣、一起的回憶、天氣、季節、這個地點、最近吃過的東西、朋友（八卦）、記得對方喜歡的事、昨晚的夢、60 個日常話題（星星、小時候、雨聲、工作、秘密…）。剛聊過的（一天內）不太會再聊 | v16 31a |
| 立場 | 每個角色對每個話題有看法（−1…1）：吃的看口味（玩家設定的喜好也算）、活動看特質與個性、興趣／喜歡／討厭寫在檔案裡的一定明確、人看關係、再加一點固定的個人傾向（不會每次變） | v16 31a |
| 對話是一串回應 | 提起 →（附和／反對／追問／分享／開玩笑／沒興趣）；追問 → 解釋；附和 → 延伸／分享；反對 → 堅持／讓步；玩笑 → 笑／冷場；沒興趣 → 換話題（對方提自己的話題）…… → 結束。由兩個人的立場與個性決定（固執的會堅持、溫和的讓步、好奇的追問、外向的開玩笑） | v16 31b（60 段對話，每一句都是對上一句的合理反應、輪流說） |
| 台詞 | 約 260 句新台詞（分類 `t16_<行為>`），依話題種類、立場、說話方式（四種聲線）、特質選；含「{topic}」的通用句只用在「東西」類話題，回憶、夢、人有自己的說法；對著當事人說回憶時把名字換成「我們／你」 | v16 31b（每一種情況都找得到台詞） |
| 對話記憶 | 聊完雙方記得對方對每個話題的立場（`c.life.t16.know`），下次會提「你上次說你喜歡…」；回憶寫成「和小空聊了釣魚」 | v16 32a |
| 結果 | 很聊得來（附和兩次以上）→ 好感 +1；意見不合又沒人讓步 → 一點摩擦（衝突 +2，兩個都溫和就沒有）；有人讓步 → 信任 +1。**不改關係類型** | v16 32a |
| 八卦 | 說的人對第三個人有明顯看法、聽的人信任他（信任 ≥ 25）→ 聽的人對第三個人好感 ±1；同一對一天一次；玩家固定的關係、「鎖定關係」時都不受影響 | v16 33 |
| 關鍵字泡泡與偷聽 | 你沒參與的對話只顯示「🎣 釣魚？」「👍」「❓」「🤝」這類關鍵字泡泡（短、不擋畫面）；點正在聊天的角色 →「偷聽」就看到真的話；你操控的角色在對話裡、你安排的對話，或生活設定打開「別人聊天時顯示完整的話」時都顯示全文 | v16 32b |
| 最近的對話 | 角色選單「更多 → 最近的對話」：最近 20 段（話題、誰和誰）；聽過的看得到內容，沒聽到的只寫話題 | 截圖檢查 |
| 沒話題時來問你 | 同一個地點、有點無聊又想聊天的角色，偶爾來問你（經打擾預算 `OC.Budget`、一天一個角色一次、可以在生活設定關）：選一個話題，或打字（「今天吃了咖哩」→ 用離線字典認出「晴日咖哩」）；角色依自己的立場回應、記得你說過的、對你的好感 +1。問的時候角色停下來，關掉就放開 | v16 34、31c |
| 生活設定 | 新增「角色自己下廚、端上桌」（16.5 報告寫了可以關，**但當時沒有開關——這次補上**）、「別人聊天時顯示完整的話」、「沒話題時來找你聊天」 | — |

## 未完成／未驗證（誠實標示）

- **台詞數量沒有達到計畫的 1500 句**：這一版約 260 句（加上原本的台詞庫）。對話的結構（話題、立場、回應鏈）已經完整，之後加台詞只要加資料。
- 只有兩個人的對話用話題；三人以上的聚會（`OC.Arcs`）、桌寵台詞仍是原本的方式。
- 「聽到八卦」只改好感，不會讓角色記得是誰說的，也不會傳到第三個人（沒有連鎖傳播）。
- 打字回答的字典是關鍵字比對，不懂句子的意思（「我不喜歡咖哩」也會被當成聊咖哩）；角色對你回應的是牠自己對話題的看法。
- 偷聽只能在角色選單裡按；點泡泡本身沒有作用。
- 手機上沒有實測（泡泡大小、打字時鍵盤擋住畫面的情況）。
