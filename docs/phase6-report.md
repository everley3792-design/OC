## 測試中發現並修正的問題（遊戲本身）
- 請求泡泡綁了兩個點擊處理 → 一次點擊開兩個視窗。
- `Growth.onSkillUp` 沒有接上 → 升級演出與卡片不會出現。
- 新活動（素描、唱歌）用了沒有地方提供的動作類型 → OC 永遠不會做。
- 演出佇列在兩個演出之間的空檔可能同時跑兩個 → 例外錯誤；鏡頭在演出中被重設時沒有恢復原本的縮放。
- 剛接受請求（演出中）就餵食會被判定成「被打斷」。
- 慶祝演出（升級、新夢想）會打斷 OC 正在進行的對話 → 改成只顯示卡片。
