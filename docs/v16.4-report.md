# 16.4（0.16.4-alpha）互動選單重做＋安排活動（模擬市民式的動作清單）

玩家的要求：全面重構點角色、物品、設施時的互動選單（精緻、直覺、方便）；除了開啟特定進階功能，不要跳出不必要的二次確認或彈出視窗；更多互動選項；「安排活動」問題很多，參考《模擬市民》的動作佇列整個重寫。（參考作品只取設計原則，不使用任何素材。）

## 先重現、列出原本的問題

| # | 問題 | 位置 |
|---|---|---|
| 1 | 點角色要經過三層才做得到很多事：環狀選單 →「親近」或「玩耍」再開一個環 →「更多」開一張表單 → 表單裡「安排活動」再開一張表單 | `app.js menuFor`、`lifeui.interact`、`lifeui.schedule` |
| 2 | 「安排活動」是一張平鋪的表單：所有活動一字排開、沒有分類、不知道這裡能不能做；按一個就關掉，要排第二個得再走一次三層 | `lifeui.schedule` |
| 3 | 清單裡只有「活動名稱」：從長椅、書架安排的事，交給引擎時就變成「找最近的那一個」，不是你點的那一個 | `queue15.js` |
| 4 | 清單最多 4 個；不能調順序、不能插隊、不能循環；看不到進度 | `queue15.js` |
| 5 | 交給引擎失敗（附近沒有那種設施、被保留）時，那一項就默默消失，沒有原因 | `queue15.step`（`command` 的結果被忽略） |
| 6 | 要去別的地方做的事不能排；跟別人做的事不能排 | `queue15.js` |
| 7 | 角色不想做（例如吃飽了還叫牠吃）時沒有任何回應，照做或沒做都不知道為什麼 | — |
| 8 | 點清單的一項就直接取消（容易誤觸），沒有別的操作 | `app.js` HUD |
| 9 | 餵食、送禮、邀請一起都另外跳一張選擇表單 | `lifeui.itemPicker`、`inviteSheet` |
| 10 | 物品／設施的卡片只有一個主要動作（坐下、看書…），同一張長椅不能選「打盹」「發呆」 | `app.js describe` |

## 做了什麼

| 項目 | 做法 | 驗證 |
|---|---|---|
| 一層分類、一層項目 | 角色的環保留常用動作（一點就做）；「親近、互動、餵食、送禮、玩耍、安排、更多」是分類，按了在**同一個選單**下方展開項目面板（必要時有分頁），不再開第二個環或表單 | v16 23a |
| 不跳確認 | 項目一按就做；下方提示「已安排…　復原」可以撤回。只有刪除／清除類（例如清除動畫）才會確認 | v16 23b |
| 長按＝立刻做 | 面板裡長按一項：插到最前面、馬上開始，原本在做的換掉，排在後面的保留 | v16 23c |
| 動作清單（`OC.Queue` 重寫，`life/queue16.js`） | 每一項都帶著目標：這張長椅（某個位子；那位子有人就坐同一張的另一邊）、某個地點、某個人、地上的某一點。最多 8 個等候；拖曳排序；「立刻做」；「循環」；進度條；存在角色身上（`c.life.q16`，舊的 `q15` 自動轉過來） | v16 22a、22c |
| 不想做會說原因 | 吃飽了不吃、白天看不到星星、太累不運動、餓到不想玩……清單裡標 ⚠ 和原因，**不會擋住後面的**；「強迫」照做（之後有點不高興）；20 秒後自動移除 | v16 22b |
| 跨地點 | 「安排 → 去別處」：這裡沒有的活動，列出可以做的地方；角色會自己走出去、到那裡做 | v16 25 |
| 和別人一起 | 互動選單的項目也進清單；對方忙就「等…有空」（最多 30 遊戲分鐘），一直沒空就說明 | — |
| 清單的操作 | 點一項 → 在原地展開「立刻做・循環・強迫（被拒絕時）・取消」，不跳視窗；長按拖曳排序 | v15 2b（更新） |
| 東西會說自己能做什麼 | 長椅：休息、打盹、看書、發呆、寫日記；樹：看書、看風景、照顧、抱抱樹、拍照；花圃：照顧、看風景、聞花香…（依設施的可供性自動列出），每個在場的人一顆「邀…一起」（附反應提示） | v16 24a |
| 在地上做 | 長按地面 →「在這裡做」：跳舞、轉圈圈、伸展、運動、發呆、冥想、寫日記、拍照、看星星、看雲、打掃 → 走到那裡再做 | v16 24b |
| 新的互動與活動 | 11 個新活動（跳舞、看星星、看雲、冥想、抱抱樹、聞花香、寫日記、轉圈圈、打掃、拍照留念、運動；`life/acts16.js`）；新的照顧動作：梳毛、打氣、蓋被子（睡覺時）；「更多」裡：在想什麼、觀察、陪伴、改操控牠、編輯角色、清空清單 | v16 23a、24 |
| 餵食／送禮／邀請 | 直接在面板裡列出背包裡的東西或在場的人，按一下就做 | — |

## 未完成／未驗證（誠實標示）

- **手機上沒有實測**：長按（0.52 秒）立刻做、清單的長按拖曳排序、面板的捲動只在 Chromium 手機模擬中驗證。
- 不在你身邊（在別的地點、抽象生活中）的角色，清單會等到你們在同一個地點才開始。
- 跨地點只支援活動；和別的地點的人互動不能排。
- 「強迫」只有一種後果（輕微不高興），沒有依個性不同。
- 物品卡片仍是 15.0 的卡片（加大、兩欄），不是環狀選單；只有角色、家具、地面用環狀選單。
