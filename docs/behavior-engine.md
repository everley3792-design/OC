# 行為引擎（第四階段）

核心原則：**性格影響行為、行為累積經驗、經驗形成記憶、記憶改變未來選擇。**

## 模組與資料流
```
OC.Sim (sim.js)      唯一的排程器：固定步長 0.2 現實秒；每步推進「遊戲分鐘」= rate × 0.2
   ├─ onStep  → Brain.lifeStep：每個 OC 的需求／情緒（Mind.tick）→ 看得到的 OC 做決策（stepBrain）→ 社交（Social.update）→ 路過打招呼
   ├─ onDay   → Mind.dayStart：回憶整理、願望、習慣檢查；Events 'dayStart'（紀念日）
   └─ catchUp → 離線／背景：抽象模擬（不移動、不觸發事件、不發獎勵）
OC.Mind (mind.js)    需求、情緒、回憶、紀錄、關係、願望、技能、作息、成長建議（純資料邏輯）
OC.Brain (brain.js)  Utility AI + 活動狀態機 + 可供性（affordance）+ 預約 + 社交編排
OC.Talk (talk.js)    資料驅動對話
OC.Events (events.js) 事件生命週期
OC.LifeUI (ui/lifeui.js) 互動選單、通知、檔案分頁、設定、對話編輯器、診斷
```
`app.js` 的主迴圈把「現實經過的秒數」交給 `OC.Sim.update()`（不受 fps 上限影響）；
世界被頁面蓋住時用 `World.tickActors()` 繼續移動角色（不繪圖）。

## 時間
| 模式 | 遊戲時間 | 離開 App 時 |
|---|---|---|
| 現實 `real` | 等於手機時間 | 補算經過的時間（最多 8 小時） |
| 循環 `cycle` | 每現實秒 = 速度 ×1/×2/×5/×10 遊戲分鐘（×1 一天約 24 分鐘） | 時間暫停 |
| 固定（早／午／昏／夜） | 天空固定，生活以現實速度進行 | 同現實 |

需求、活動長度、冷卻全部用**遊戲分鐘**；走路效果依**移動距離**（`WALK_FX`），因此改變速度或幀率不改變結果
（測試 9a：一次 120 分鐘 vs 1200 次 0.1 分鐘，差異 < 0.01；9b：30/60 fps、×5/×10 的時間比例都正確）。

## 需求（9 種，每遊戲小時）
飽足 10、精力 6、睡眠 5.5、娛樂 7、社交 5、舒適 4、好奇 3、活動 4；心情由其他需求＋情緒＋氣質慢慢趨近（τ≈90 分）。
互相影響：睡眠 < 25 → 精力下降 ×1.6；飽足 < 15 → 精力 ×1.3；下雨在室外 → 舒適 ×2；一直做同樣的事 → 好奇 ×1.5；坐著 → 活動 ×1.5。
個性影響：貪吃、懶散、夜貓子、愛睡、好奇、害羞／外向、活力／社交滑桿……（`Mind.decayMult`、`gainMult`）。
不會死亡、不會永久損失：線上最低 3、離線最低 15；需求低只會影響情緒與選擇。

## 決策（Utility AI）
每個候選 = 活動（含目標位置）或社交（含對象）。分數 = Σ 需求缺口^1.6 × 權重 × 活動效果
＋ 作息（睡覺時段、用餐時間）＋ 特質 ＋ 活力滑桿 ＋ 天氣 ＋ 時段 ＋ 情緒 ＋ 後天習慣 ＋ 願望 ＋ 地點（距離、回憶中的感受、最愛的地方）
－ 剛做過（新鮮感）＋ 小幅隨機。
選擇：前 4 名做 softmax，溫度由「思考方式」決定（理性的 OC 幾乎總是選最好的，感性的 OC 偶爾給驚喜）。
每次決策保存前 8 名候選、分數與原因（開發者診斷、觀察模式的「想法」）。

## 活動流程
`think` → 決策 → **預約位置** → `go`（A* 尋路）→ 抵達後短距離**對齊**到座位／床位（不瞬移）→ 設定座高、朝向 → `do`（動作、需求變化、偶爾自言自語）
→ 時間到／需求滿足／急需別的（非鎖定活動）→ `finish`：釋放位置、生活紀錄、回憶（第一次、很久、或偶爾）、情緒、技能、願望進度 → 下一次思考（延遲依「行動節奏」）。
鎖定活動（睡覺、吃飯、打盹）不會被一般決策打斷；玩家的拖曳／呼叫／編輯／對話可以。
室內活動（回家睡覺、吃飯）看板會隱藏，仍然在模擬。

## 可供性（affordance）
| 物件 | 動作 | 位子 |
|---|---|---|
| 長椅 ×2 | 坐、閱讀、打盹 | 2（座高 7） |
| 家 | 睡覺、吃飯（室內） | 6 |
| 雜貨攤 | 吃點心、喝飲料 | 2 |
| 果樹 ×7 | 照顧、樹下閱讀、看風景 | 1 |
| 花圃 ×3 | 照顧、欣賞 | 2 |
| 家具：椅子／靠墊 | 坐、閱讀、打盹、整理 | 1 |
| 家具：星星小床（新） | 睡覺、打盹 | 1（躺） |
| 家具：野餐圓桌 | 吃東西、喝飲料、整理 | 2 |
| 家具：盆栽／地毯／檯燈 | 照顧／玩耍／整理 | 1–2 |
| 景點（`area.spots`） | 廣場（玩、看）、碼頭、小橋、高台、沙灘、瀑布、森林池塘與空地 | 2–4 |
預約表 `Brain.res`：一個位子只給一個 OC；站立點也會檢查其他 OC 位置，避免重疊（測試 6：6 個 OC 30 秒，無瞬移、無卡住、無無限活動）。
新地點、商店、經濟、釣魚、種田、旅行在第五階段之後：只要在區域定義加入 `spots` 或可互動物件，引擎自動使用。

## 操控中的角色
預設由玩家控制：只有你 40 秒沒操作時才做原地的小事；但如果餓壞、睏壞、累壞，會自己去吃飯／睡覺。
「生活設定 → 操控中的角色也自己生活」可讓牠完全自主（你一操作就停下）。切換操控角色不會影響其他 OC。

## 社交編排
發起者走到對方身旁（左右 22 單位、可走、無人佔用）→ 雙方面對面 → 打招呼（240 分鐘內見過就略過）→ 邀請／話題
→ 對方依個性、關係、心情、需求、正在做的事回答「好／不要／晚點」→ 一次只有一個人說話（每句等前一個泡泡結束）
→ 結果：雙方關係（有方向）、需求、情緒、共同回憶、技能、願望 → 道別。
種類：打招呼、聊天、分享興趣、稱讚、安慰、開玩笑、惡作劇、分享食物、送小禮物、爭執、道歉／和好；
共同活動（2 人以上）：一起休息（長椅兩個位子）、一起玩（廣場）、一起看星星（景點）。
餓壞或睏壞時不會主動社交，也會婉拒邀請；剛聊過會先去做別的事。

## 分層模擬
| 層級 | 對象 | 方式 |
|---|---|---|
| 看得到 | 目前區域的 OC（玩家 + 最多 5 位） | 完整：移動、預約、動作、社交、事件 |
| 其他區域 | 在島上但玩家在森林 | 同樣的評分，不移動；每 2 遊戲分鐘一次，寫入生活紀錄 |
| 不在島上 | 「休息中」的 OC | 只有需求緩慢變化（有下限） |
| 離線／背景 | 全部 | 每 10 遊戲分鐘一段，最多 8 小時；不觸發事件、不給物品；結束後寫一則摘要回憶（有 key，不重複） |

## 打斷與恢復
`Brain.hold(id, reason)`：call、drag、editor（換裝）、dialogue、event、pet、feed、play。
暫停時已做的部分照樣記錄；`unhold` 後如果原本的活動還有意義（剩餘時間 > 3 分鐘、位子還空著）就**繼續**，否則重新決策。
玩家「安排活動」：正在睡覺／吃飯時排在後面，其他情況立即開始。

## 自主程度
完整／少社交／少事件／限制（只做基本生活）／暫停（玩家安排的仍會執行），以及「不做的活動」清單、鎖定關係自動變化、關閉成長建議、關閉自言自語泡泡。

## 12.0：操控模式與 `OC.Arcs`

**操控模式**：`c.life.control` ∈ `manual`／`semi`（預設）／`auto`；`Brain.setControl(id, mode)` 是唯一入口，`Brain.manualMode(b)` 為真時 AI 不挑活動（只處理急迫需求）、不被邀請、不參加聚會。半自動：自己生活，玩家下指令或碰牠時先聽玩家的（有讓步時間窗，之後自己接手）；全自動：只有玩家親手帶牠走時才停。

**`OC.Arcs`**（`js/life/arcs12.js`，全部跑在 `Sim.onStep`）
- 情緒感染：每 12 遊戲分鐘，強度 ≥ 0.45 的情緒傳給 120 px 內的人（親近度、個性、對方本來的情緒加權；每種情緒每對冷卻 45 分鐘）。
- 冷戰：每 30 遊戲分鐘檢查；衝突 ≥ 38 且熟悉 ≥ 18、不是對手／戀人／伴侶／自訂、沒有 `fixed`、不在 `lockRel` → 進入 `cold`（2–4 天）：`Arcs.shape` 把對方的社交候選分數 ×0.08（道歉除外）、`Brain.Social.respond` 拒絕邀請、擦身而過尷尬；時間到 → `thaw`；之後經道歉（`Arcs.onSocial`）、共同朋友調解（聚會 `mediation`）、玩家（`Arcs.mediate`，4 遊戲小時冷卻）、或時間（1 天後依個性機率）→ `reconciled`（衝突 −30、信任 +8、好感 +8、有回憶）；三次沒成功 → `drifted`（好感 −6、親密 −3）。和好後 3 天內不再開始新的冷戰。
- 聚會 `Arcs.gather(kind, ids)`：`circle`、`meal`、`photo`、`mediation`；3–4 人，每人 `Brain.hold(id, 'group')`；走到位置 → 輪流說話與反應；結束／有人離開畫面／超過 80 秒都 `unhold` 全部；`MAX_AGE.group = 120 s` 是看門狗。自動聚會只在「全自主」、且每次 20 遊戲分鐘 20% 機率、聚會後冷卻 240 遊戲分鐘。沒有獎勵、不送進度事件。
- 資料：`life.arcs = { rifts, cd, gcd, n }`；台詞分類 `rift_cold`、`rift_sorry`、`rift_forgive`、`rift_refuse`、`med_open`、`group_open`、`group_talk`、`group_react`、`meal_open`、`meal_talk`、`photo_count`、`photo_done`（`lines12.js`）。
