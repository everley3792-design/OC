# 16.x 計畫（玩家確認版）

> 這是玩家在 2026-11 確認的 16.0–16.8 施工藍圖。每一版：先給 APK、跑完整回歸、寫報告（`docs/v16.N-report.md`）。
> 參考《Tomodachi Life》（互動節奏）與《The Sims 4》（自主、需求、人生階段）——只取設計原則，不用任何素材。
> 全部離線、規則式，不接外部 AI。未完成的部分必須在報告中標示。

## 玩家的決定（不要再問）

| 題目 | 決定 |
|---|---|
| 互動門檻 | **沒有鎖**。任何互動都能做，由對方的「意願模型」決定反應（可能被拒絕、降好感、各種反應）。只保留保護性硬規則：戀愛類＝戀愛開啟＋雙方為玩家標示的成年；未成年不涉及親密類。 |
| 關係大事 | 友情升降自動（只通知）；成為戀人、分手、絕交、同居要玩家同意；**但角色有小機率（約 5–8%，依個性／心情）不照玩家意願**，每次有可讀原因；設定可調／關。 |
| 「我的家」 | 珊瑚屋頂直接變成**大家庭宅（4–6 人）**，家具保留。黃屋＝小屋（2 人）；紫屋＝雙層連棟屋（3–4 人）。每棟最少 2 人。 |
| 撿到的東西 | 角色（或玩家）**當場就能使用**；不用就進背包。不做個人物品欄（庫存只有 `save.inv`）。 |
| 日曆 | 設定可選：**遊戲曆**（預設；四季、每季 28 天、一年 112 天）／**實時曆**（12 個月、照現實日期；年齡成長很慢——要寫明）。 |
| 學生 | 就學狀態：在學／**休學**／**自學**（有自學成績，不排名）。 |
| 開場 | 開場流程：建立多名角色（1–6）→ 關係圖 → **選房子** → 進遊戲。 |
| 嬰兒 | 做（簡單：睡、吃、哭、玩、被照顧、學走路說話）。 |
| 職業 | 受僱（兔子洞、固定時段）＋**自由業**（插畫師等：接案、自排時間、收入不固定、作品集、可上架——沿用工坊商品規則）。舊打工重做成職業第一級（兼職）。 |
| 其他地點模擬 | 設定三選一：完整（預設）／聰明／精簡；卡頓時自動降一級。 |
| 死亡 | **預設關閉**（免疫）；每個角色可單獨設定年齡增長（會長大／固定／玩家按才長大）與死亡。呈現溫和、可反悔。 |
| 離線 | 保留現有規則（最多補算 8 小時、不給獎勵），其餘只記摘要。 |
| 熱鬧程度 | 安靜／普通（預設）／熱鬧。 |

## 設計要點（摘要）

- **意願模型**：關係（熟悉／好感／信任／親密／衝突、階段只描述不鎖）× 互動的親密度與性質 × 對方個性／物種／年齡 × 心情／需求／正在做的事 × 情境（地點、旁人、時間）× 歷史（剛被拒絕、剛吵架、做太多次）＋隨機。反應光譜：熱情、接受、勉強、害羞閃躲、愣住、尷尬、婉拒、不耐煩、推開、反捉弄、跑走、哭。太快太親近會扣分並留下回憶。可顯示意願提示（😊／😐／🙁，可關）。
- **對話**：同一段固定話題；行為＝提起／附和／反對／追問／分享／玩笑／轉話題／結束；態度依對話題的喜好。
- **打擾預算** `OC.Budget`：請求、提問、劇場、通知共用上限、依優先排隊、不急的進信箱；請求同時最多 1 個、只在真的需要玩家時；習慣靜默觀察、每週摘要。
- **切換操控**：不傳送；「玩家看著的地點」與「角色所在地點」分開；別的地點用雲朵轉場。
- **介面直接操作**：玩家買東西、撿東西、用道具不強制走過去；角色自主生活時仍親自去。
- **名牌卡**：頭像＋心情色環＋操控模式；名字＋一行近況（地點・在做什麼）；需求低落才浮出；後面疊其他角色小頭像（點或滑切換）；長按切模式。
- **圖片角色**：畫布貼合角色外框、解析度依螢幕大小（最高 1024，操控／特寫／拍照 1536）、原圖分段縮小快取、「角色畫質：自動／最高」、寬高分開 20–400%、不裁切、編輯器拉框。
- **小劇場**：資料先定好再演；錯過的進日誌／島報可回放。
- **硬規則保留**：`OC.Tx` 固定 key、`OC.Progress` 單一進度流、hold 一定有 unhold、不做假功能、原創素材、CLAUDE.md 其餘規則。
