# 事件規則（第四階段）

程式：`game/js/life/events.js`；內建事件在 `game/js/life/data.js` 的 `EVENTS`；玩家可匯入自訂事件（`docs/life-format.md`）。

## 生命週期
1. **觸發**：`tick`（每 4 秒檢查看得到的 OC）、`relUp`（關係升級）、`dayStart`（新的一天）、`wake`（起床）、`wxChange`（天氣變化）、`meet`（兩個陌生 OC 擦身而過）、`actStart` / `actEnd`（活動開始／結束）。
2. **條件**：`when`（時段、天氣、關係升到哪一級、活動）、`c`（主角條件，與對話條件同一套）、`b` + `bc`（需要對象時，對象條件；`days: [7, 30, 100, 365]` 等）、`chance`。
3. **優先與互斥**：同一時間只有一個事件演出；優先級高的先檢查。
4. **頻率**：全域間隔（完整 2 分鐘、少事件 8 分鐘、暫停＝不演出）；每個事件對每個 OC 有冷卻 `cd`（遊戲分鐘）；`once: 'pair' | 'pairDays' | 'global'` 一生只發生一次（已發生的鍵存在存檔）。
5. **不打擾玩家**：玩家在對話、編輯、佈置、測試動畫、拖曳角色、看其他頁面時不開始演出；離線補算期間不觸發。
6. **演出**：鎖定參與者（`Brain.hold('event')`），依序執行步驟：
   | 步驟 | 說明 |
   |---|---|
   | `['go', 'a', 'b'|'player']` | 走到對方身旁 |
   | `['face', 'a', 'b']` | 面向 |
   | `['say', 'a', '台詞分類']` | 依對話引擎挑選（每個 OC 說法不同），等泡泡結束 |
   | `['anim', 'a', '動作', 秒]` | 任何動作鍵：有玩家自製動畫就用玩家的，沒有就沿備用鏈（`OC.Chars.ACTIONS`）用內建骨架 |
   | `['emote', 'a', '♪']` | 表情符號 |
   | `['cam', 'a']` | 玩家點了「看看」時，鏡頭跟隨並加上電影黑邊 |
   | `['sound', 'id']` | 只記錄（遊戲尚無音訊系統，見報告） |
   | `['choice', '問題', [{ label, fx, say }]]` | 玩家觀看時顯示選項；沒觀看時選第一個 |
   | `['fx', {...}]` | 中途結果 |
7. **結果** `fx`：`rel`（ab / ba 有方向）、`emo`、`need`、`mem`（a / b / both；有 key，不會重複）、`flag`、`wish`、`item`（給玩家物品，每天最多一次）。
8. **重大變化需要同意**：`confirm`（例如告白 → 成為戀人）只會產生通知，玩家按「同意」才改變關係；拒絕的話維持原狀。
9. **無法演出時**：里程碑類（`relUp`、`meet`、優先級 ≥ 4）會安靜地套用結果並記錄，避免漏掉；其他事件這次略過。
10. **記錄**：`save.life.ev.log`（最近 60 筆）；開發者診斷顯示每個事件的條件是否成立與原因。

## 內建事件（全部原創）
初次見面、成為朋友、最好的朋友（可觀看）、認識紀念日（7/30/100/365 天）、下雨了、雨天的閱讀時光、一起看星星（共同活動）、
早晨的元氣、沒睡好、小發現、送你的禮物（可觀看，每天最多一次）、想起從前、一個人的時候、告白（戀愛設定開啟且雙方被標示為成年才可能發生，必須同意）。

## 回顧
回憶頁的「回顧」只重播該事件的台詞（重新挑選說法），**不會**寫入冷卻、旗標、關係或回憶。
