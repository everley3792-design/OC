# 16.1（0.16.1-alpha）開局與人生

計畫：`docs/v16-plan.md` 的 16.1。這一版做：開局建立多位島民、島民名冊（年齡／物種／長大方式）、關係圖、選房子、七個人生階段（含嬰兒）、約 20 種物種＋自訂物種、生日長大。

## 做了什麼

| 項目 | 做法 | 驗證 |
|---|---|---|
| 開局多位島民 | 第一位角色建好後進入「建立你的島民」（`ui/opening16.js`）：最多 6 位，每位用平常的創角流程；一位也可以直接下一步 | v16 9a（真實點擊三位） |
| 島民名冊 | 每位：年齡（數字）→ 人生階段、物種（晶片選擇，含自訂）、長大方式 | v16 9b |
| 關係圖 | 所有人排成一圈，兩兩之間有線（依家人／愛情／朋友／其他上色）；點一組 → 選關係：父母與孩子、兄弟姊妹、祖孫、親戚、伴侶、戀人、前任、好友、朋友、同學、同事、鄰居、陌生人、競爭對手、仇人。**有方向**（A 是 B 的爸媽 → B 看 A＝爸媽、A 看 B＝孩子），每種有起始數值，可以**鎖定**（家人、伴侶預設鎖），可以寫一句背景故事（兩人都記成回憶）。戀愛類只能選兩個 18 歲以上的人，選了會為兩人打開戀愛功能 | v16 9c、9d |
| 選房子 | 大家庭宅（4–6，原本的「我的家」）、雙層連棟屋（3–4）、小屋（2）；超過上限搬不進去。住處記在 `c.life.home16`（`OC.Homes`） | v16 9e |
| 物種 | `OC.People`（`life/people16.js`）：20 種內建（人類、貓、兔、熊、狗、狐、鳥、鼠、鹿、狼、羊、貓頭鷹、魚、龍、史萊姆、機器人、幽靈、植物系、小精靈、其他），每種有真的效果（需求下降速度、活動偏好、走路速度、情緒），跟特質走同一條路（`Traits13` 的 decay／act／speed／sens）；**自訂物種**：取名、選基礎物種、滑桿（餓、睡、想找人、累、速度、壽命） | v16 10a |
| 人生階段 | 嬰兒 0–1、幼兒 2–3、兒童 4–12、青少年 13–17、成人 18–39、中年 40–59、長者 60+（依玩家寫的年齡）。各階段有效果；嬰兒只能吃、喝、睡、休息、玩、看、發呆、打招呼；幼兒不能煮飯、釣魚、打工等；兒童不能打工；嬰兒與幼兒不會自己去別的地方。玩家安排做不到的事時會說明原因。程式繪製的角色年紀小時畫得比較小（匯入圖不變） | v16 10b、10c |
| 未成年與戀愛 | `Mind.romanceOK` 先問 `People.minor()`：未滿 18 歲**無論設定**都不會有戀愛；生活設定的「成年角色」對未成年者停用 | v16 9d、10c |
| 生日長大 | 每位角色：生日自動長大（新角色預設）／我按了才長大（舊存檔角色預設，不會突然變老）／固定年齡。生日照日曆（遊戲曆或實時曆），一年一次（key `age:<oc>:<年>`）；進入新階段有卡片、短句與回憶；「我按了才長大」只在生日寄一封信 | v16 11a–11c |
