# 物品系統（第五階段）

## 1. 單一資料來源
- **唯一登記表：`OC.Style.ITEMS`**。背包、快速背包、商店、圖鑑、佈置、生活 AI、任務、桌寵輸出都讀它。
- `game/js/items/items.js`（`OC.Items`）把完整目錄合併進去（第二階段的舊物品以 `PATCH` 補欄位，id 不變，舊存檔不受影響），並登記玩家的工坊商品（`save.custom.items`）。
- 物品圖示：原創程序繪製（`game/js/items/art.js`，`OC.ItemArt`，約 70 種畫法）；工坊商品用玩家的圖片（IndexedDB 素材 id）。
- 庫存只有一份：`save.inv { id: 數量 }`。所有增減只經過 `OC.Tx`（見 `docs/economy.md`）。

## 2. 欄位
| 欄位 | 說明 |
|---|---|
| `zh` `d` | 名稱、介紹（原創） |
| `kind` | `food drink crop seed fish bug sea material gift toy furniture clothing` |
| `price` `sell` | 商店售價（星幣）、可賣回價格（只有雜貨攤與每日市場收購） |
| `rarity` | 1 常見 … 5 傳說（圖鑑、釣魚機率、提示） |
| `tags` `src` | 搜尋標籤；取得來源（顯示在詳情與圖鑑提示） |
| `use` | 使用效果（需求 Δ，每次） |
| `flavor` `texture` `temp` `cat` `ingredients` | 食物屬性：口味（甜鹹酸辣苦鮮清爽，−2..2）、口感、溫度、分類、材料 |
| `grow` | 種子：`{ crop, days, n }` |
| `cookAs` | 料理時視為哪一類（例如任何魚） |
| `fp` `sit` `sleep` `verbs` `seats` `wall` `outdoor` | 家具：佔地、可坐／睡、提供給 AI 的動詞、位子數、掛牆、只能放戶外 |
| `slot` `val` / `anchor` | 服飾：內建外觀欄位與值／工坊服飾的部件錨點 |
| `art` / `asset` | 程序圖示描述／玩家圖片 id |
| `anim` `reaction` | 工坊商品：OC 拿到時的動作與台詞（可留空＝依個性） |
| `custom` `shop` | 工坊商品標記與上架的商店 |

分組（背包、商店分類）：吃喝、種植、生物與收藏、材料、禮物與玩具、家具、服飾。

## 3. 使用（`OC.Use`，`game/js/ui/p5pages.js`）
`OC.Items.useKind(id)` → `eat / drink / play / wear / place / gift`：
- **吃／喝**：OC 先轉向、（第一次吃會先疑惑一下）→ 吃的動畫 → **動畫完成且沒被打斷才扣 1 個**；被抱走、被事件或其他保留（hold）打斷＝不扣。效果依喜好調整（最愛：心情 +10；討厭：心情 −、飽足 ×0.7）。
- **玩具**：一起玩（不消耗），同一天同一個玩具效果遞減。
- **禮物**：交易成功後才有反應；喜歡的禮物好感更多。
- **服飾**：內建服飾改外觀欄位；工坊服飾變成角色部件（錨點）。再按一次＝脫下。不消耗。
- **家具**：進入佈置模式，按下「放這裡」才扣。
- 可接收的 OC：在場、沒有被保留、沒在睡覺（吃不下的不能餵）。只有一位時直接給，多位時列出（不能給的顯示原因）。

### 快速背包拖曳
- 垂直拖動（或水平按住 220ms 後拖）＝拖曳；快速水平滑＝捲動；點一下＝詳情。
- 拖曳時在每個可接收的 OC 身上顯示**虛線圈**；不能接收的顯示原因（灰色）；指到目標時圈變實心、物品放大。
- 放在 OC 上＝`OC.Use`；放在居民上＝送禮；放在空白處＝取消（不消耗，會提示）；家具只能在可佈置的地點拖出。

## 4. 背包
- 完整背包頁：搜尋（名稱、類別、標籤）、分類標籤（含數量）、排序（類別／名稱／數量／稀有度／價格）、收藏（★，快速背包優先顯示）、詳情（效果、口味、來源、可賣價格）與動作。
- 快速背包與完整背包讀同一份 `save.inv`；任何交易都會即時更新兩者。
- **生活模擬模式下，背包沒有任何新增或修改數量的功能**。

## 5. 飲食喜好（`OC.Taste`）
- 每個 OC：`tastes.food { id: { lv, src, locked } }`、`tastes.flavor { 口味: −2..2 }`、`tastes.tasted { id: { n, first, last, reaction } }`。
- 等級：最愛 2／喜歡 1／普通 0／不喜歡 −1／討厭 −2。
- 來源：`player`（玩家設定，預設鎖定）、`discovered`（第一次吃才知道）、`unknown`（由個性、口味傾向、喜歡的東西與穩定雜湊推導）。
- **玩家鎖定的喜好永遠不會被品嚐改寫**（測試 8f）。
- 第一次吃：先疑惑（`think` 動作＋「？」）→ 反應；最愛會跳起來＋♥♥，討厭會難過或生氣（敏感的 OC 會哭）；動作都走 `OC.Chars.ACTIONS` 的備用鏈，有自訂逐格動畫就用自訂的。
- 編輯：角色編輯器 ›「喜好」（口味傾向 5 段、每個食物 5 段＋鎖定／解鎖）。檢視：角色檔案 ›「生活」›「飲食」（最愛、最討厭、品嚐紀錄）。

## 6. 工坊商品
- 工坊 ›「工坊商品」：從素材庫或繪畫工坊選圖，設定名稱、類別（食物／飲料／家具／服飾／玩具／禮物／材料）、價格（10–5000）、效果強度、口味、穿戴位置、可坐、上架商店、介紹、標籤、OC 的反應台詞與動作。
- 驗證失敗會說明原因；**工坊不會產生庫存**，商品只能用星幣在指定商店購買。
- 背包裡還有的商品不能刪除；刪除會移除場景中擺放的同名家具。
- 存檔只存圖片 id（IndexedDB），不存圖片資料（測試 7e）。
