# 第一階段：三套視覺方案比較與建議

> 三支影片使用**完全相同的分鏡、時間軸與互動內容**（45 秒 · 1080×1920 · 30fps · H.264），差別只在美術、UI、動畫語言。
> 影片：`deliverables/videos/` ・ 總覽圖：`deliverables/overviews/` ・ 可互動原型：`prototype/index.html?theme=mallow|pixel|sketch`

### A · 棉霧島 Mallow Mist
- **理念**：把參考圖 1 的柔和配色與 Q 版比例，轉化為「霧面黏土模型」：沒有描邊，體積全靠漸層、接觸陰影與暖色邊緣光。
- **UI／HUD**：只有 5 個小元件（時間天氣、金幣、頭像心情環、背包、地圖、選單），全部是半透明奶霜膠囊；資訊需要時才浮出。
- **操作感受**：柔軟、慢、安心；按壓有 6% 縮放和彈簧回彈，不閃光、不劇烈彈跳。
- **優點**：最療癒、最「高級」、最接近大眾商業手遊；易讀、親和、低學習成本。
- **限制**：風格較常見；玩家自畫素材與官方漸層質感落差大，需要「濾鏡化」處理；大量半透明與漸層在低階機需降級。
- **Android 效能**：中。省電模式：漸層改平塗、關閉雲影與螢火蟲、30fps。

### B · 像素森語 Pixel Grove
- **理念**：參考圖 2/4/5 的俯視像素世界，但做成更乾淨的「高位元」：世界 270×480 原生像素（×4），UI 540×960（×2），兩層像素密度刻意區分世界與介面。
- **UI／HUD**：9-slice 像素框，角落小晶片；對話框帶頭像（經典 RPG 但更節制）；手套游標。
- **操作感受**：俐落、有「遊戲感」；所有回饋是整格步進（彈出、抖色、閃爍箭頭），沒有模糊淡入。
- **優點**：效能最好（最適合長時間常駐的懸浮桌寵）、素材量產最快、像素編輯器讓玩家創作門檻低。
- **限制**：表情細節受像素限制；繁中像素字選擇少（目前用 Unifont）；「高級感」需靠排版與調色盤紀律。
- **Android 效能**：最低。整數縮放、sprite atlas、夜晚光影用調色盤 LUT。

### C · 手帳繪本 Inkpot Tales
- **理念**：參考圖 3 的繪本世界，加上「手帳／剪貼簿」的 UI 隱喻：墨線每秒抖動 8 次（boiling line），填色像 Riso 印刷般微微錯位，陰影是排線，整個畫面壓在紙紋上。
- **UI／HUD**：毛邊紙卡、紙膠帶、印章按鈕、拍立得頭像；每個系統都有實體隱喻（貼紙創角、玻璃罐需求、價格吊牌、翻頁動畫本）。
- **操作感受**：俏皮、有手作溫度；漫畫狀聲詞（蹦！嚼嚼、哇—！咚！）與擠壓伸展讓反應更有個性。
- **優點**：原創性與辨識度最高；**玩家自己畫的 OC 和動畫會完美融入官方美術**——這正是 OC Shimeji 的核心價值。
- **限制**：美術規範最嚴（線寬、抖動幅度、排線角度必須一致）；線條密集時在小螢幕需控管；向量描邊成本較高。
- **Android 效能**：中高。正式版把每個部件預烘 3 幀 boil 成 atlas，執行期只換幀不重算向量。

## 我的建議（僅供參考，最終由你決定）

**最推薦：C · 手帳繪本 Inkpot Tales**，可考慮吸收 A 的「HUD 節制與柔和配色」做微調。

理由：
1. **與產品核心最契合**。OC Shimeji 的獨特之處是「玩家自己的角色、自己畫、自己做逐幀動畫，再放到手機桌面」。在 C 的世界裡，玩家不完美的手繪線條是風格的一部分；在 A 裡會顯得格格不入，在 B 裡則必須限制成像素畫。
2. **辨識度最高、最不像模板**。截圖一眼就認得出來，也最有社群分享的話題性。
3. **系統隱喻能延伸到所有功能**（貼紙、印章、手帳、翻頁、晾衣繩影格），讓之後 20+ 個系統風格一致、不會越做越擁擠。
4. **懸浮桌寵**：墨線角色疊在任何桌布、任何 App 上都清楚可辨（描邊天然提供對比）。

如果你更重視「第一眼的高級療癒感與大眾接受度」，選 **A**；如果你更重視「效能、開發速度、遊戲感」，選 **B**。也可以混合，例如：**C 的角色與世界 ＋ A 的 HUD 色調**，或 **B 的世界 ＋ C 的手帳 UI**。
