# 情緒與回憶模型（第四階段）

## 情緒（`OC.Mind.feel / tickEmotions`）
17 種：平靜、愉快、興奮、安心、害羞、緊張、無聊、疲倦、寂寞、低落、吃醋、困惑、好奇、驚訝、煩躁、滿足、得意。
每種有：效價（正負）、激動度、半衰期（遊戲分鐘）、臉部表情、閒置動作、優先權重。
- **原因與強度**：`feel(c, id, 強度, 原因, 對象)`。強度乘上個性敏感度：情緒表達滑桿、敏感、樂觀／開朗（負面較弱）、悲觀（負面較強）、害羞（害羞 ×1.6）、外向（害羞 ×0.4）、固執／溫柔（煩躁）、好奇……所以**同一件事對不同 OC 的影響不同**（測試 1b）。
- **疊加**：同一情緒用 `1−(1−a)(1−b)` 疊加，不會超過 1；同一原因 20 遊戲分鐘內再次發生只算 30%（冷卻）。
- **衰減**：依半衰期指數衰減；樂觀的 OC 負面情緒消退快 30%；低於 0.06 移除。
- **需求情緒**：疲倦、寂寞、無聊、餓到煩躁、全部滿足時的滿足感——每步重新計算，不疊加。
- **主導情緒**：分數 = 強度 × 優先權重；只有領先 0.12 以上、且距上次切換超過 2.5 秒（驚訝例外）才換——不會混亂切換。
- **影響**：臉（眼、嘴、眉、腮紅、汗）、閒置動作、移動決策（情緒加權）、邀請回應、對話分類條件、心情目標值。
- **顯示**：HUD 只顯示主導情緒與正在做的事；角色檔案「生活」頁顯示強度、其他情緒、最近 6 個變化與原因。

## 回憶（`OC.Mind.remember / consolidate`）
| 層 | 內容 | 上限 |
|---|---|---|
| 短期 | 情緒變化與原因（`emo.recent`） | 14 |
| 最近 | 所有新回憶 | 80（溢出時整理） |
| 長期 | 重要度 ≥ 0.55、里程碑、釘選 | 150（依重要度與時間淘汰；里程碑不淘汰） |
每個新的遊戲日整理一次：一天以前的「最近」回憶，重要的移到長期，其餘遺忘（但生活紀錄的統計保留）。
欄位：角色、時間（遊戲分鐘＋現實時間）、地點、類型、參與 OC、當時的情緒、重要度、資料、`key`（防重複）。

## 回憶如何改變未來
- **地點**：`placeFeel()` 依該地點回憶的情緒加權 → 選位置時加減分（喜歡的地方更常去）。
- **對象**：社交與共同回憶提升關係數值 → 社交候選分數提高（測試 3d）；爭執降低好感、提高衝突 → 比較少主動找對方，直到道歉和好。
- **對話**：`{mem}` 變數與 `hasMem` 條件讓 OC 提起往事；「想起從前」事件。
- **成長**：生活紀錄（次數、時間、天氣／時段、地點、先後順序）→ 後天習慣／特質建議 → 玩家同意後成為行為加權（測試 4c）。

## 後天習慣與特質（需要同意）
規則在 `HABIT_RULES`：雨天閱讀、早晨散步、夜晚看星星、飯後休息、睡前閱讀、照顧花圃、固定的老位置；特質：熱愛閱讀、喜歡自然、社交達人、愛睡、好奇、愛乾淨、夜貓子。
建議包含原因（例如「最近 8 次閱讀中有 8 次是在雨天（共約 4 小時）」）。玩家可以：接受、不要（5 個遊戲日內不再提）、稍後決定（保留但不通知 1 天）、永遠不要（鎖定）、關閉同類建議；已接受的習慣可以編輯名稱或移除。
