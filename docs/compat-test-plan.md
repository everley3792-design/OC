# 相容性與實機測試計畫（Android 12–16）

> **狀態：本文件的項目全部「尚未在實機或模擬器執行」。** 雲端開發環境沒有 Android 裝置，也無法下載模擬器映像（Google 伺服器被封鎖）。
> 不得把 Chromium 手機模擬或 JVM 單元測試的結果當成這些項目的結果。執行後請把結果填進最後的表格並更新 `phase7-report.md`。

## 裝置矩陣（建議最少 5 台）
| Android | API | 重點 | 建議裝置類型 |
|---|---|---|---|
| 12 | 31 | 不可觸控 overlay 的觸控遮擋規則（穿透模式 ≤ 0.8 不透明）、精確鬧鐘權限、PendingIntent 可變性 | 中階（Samsung One UI 4／Pixel 4a） |
| 13 | 33 | `POST_NOTIFICATIONS` 執行期權限、拒絕後的行為 | 小米／OPPO（積極省電的 ROM） |
| 14 | 34 | 前景服務類型 `specialUse` 必須宣告、`SCHEDULE_EXACT_ALARM` 預設拒絕、registerReceiver 匯出旗標 | Pixel 7／Samsung One UI 6 |
| 15 | 35 | targetSdk 35：Edge-to-edge 強制、SYSTEM_ALERT_WINDOW 從背景啟動前景服務需可見 overlay | Pixel 8 |
| 16 | 36 | 預測返回手勢（targetSdk 36 才強制，本版 35）、大螢幕方向限制（本版直向） | Pixel 9（Beta 或正式） |
另外：一台 ≤ 3 GB RAM 的低階機（記憶體、省電模式）、一台 120Hz 螢幕、一台摺疊或平板（分割畫面、旋轉）。

## 情境 1–17
每項記錄：裝置、Android 版本、結果（通過／失敗／部分）、截圖或螢幕錄影、`adb logcat -s OCDiag OCWeb OCPet AndroidRuntime`。

1. **安裝與覆蓋**：全新安裝與覆蓋 0.6.0（存檔 v5 → v6 遷移；第一隻桌寵＝原本的桌寵角色）；第三～六階段功能（創角、動畫工作室、生活、地點、商店、小遊戲、任務、成就、演出、音效）在 APK 中可用（按 `docs/phase2-report.md`～`phase6-report.md` 的清單抽查）。
2. **懸浮權限**：第一次按「啟動桌寵」→ 系統設定 → 允許 → 回來自動啟動；拒絕 → 不啟動、頁面顯示未允許；執行中到設定撤銷 → 桌寵收起、管理頁顯示「權限被關閉」。
3. **通知權限（13+）**：第一次啟動詢問；拒絕 → 桌寵照常、管理頁與工具頁提示；通知按鈕「暫停／觸控穿透／收起」都有效。
4. **前景服務類型（14+／15+）**：服務啟動無 `MissingForegroundServiceTypeException`／`ForegroundServiceStartNotAllowedException`；`adb shell dumpsys activity services app.ocshimeji` 顯示 `types=0x40000000`；15+ 從小工具按鈕啟動的流程。
5. **Shimeji 移動**：走、跑、跳、坐、睡、爬左右牆、倒吊在上方移動、從牆／天花板掉下、躲在邊緣偷看；不會跑出螢幕或停在狀態列／導覽列上；關閉個別動作後不再出現。
6. **觸控**：點一下、點兩下（回到遊戲）、長按選單、來回撫摸、拖曳擺盪、丟出撞牆；寵物以外的區域完全不影響下面的 App；不搶鍵盤（在聊天 App 打字時桌寵在旁邊）。
7. **觸控穿透**：開啟後手指直接操作下面的 App（Android 12+ 確認沒有被「untrusted touch」擋下）；桌寵略為透明；通知切換即時生效。
8. **玩家動畫**：分別用 PNG 序列、Sprite Sheet、GIF、APNG、WebP、`.ocpack` 匯入走路／攀爬動畫 → 更新桌面外觀 → 桌面上順序、每格時長、循環模式、腳底對齊、鏡像正確；「在桌面測試」每個動作；為牆面畫的攀爬不旋轉。
9. **多隻**：3 隻同時；互不重疊、會碰面（關係好 vs 不好的差異）；第 4 隻被拒絕；收起其中一隻。
10. **同步**：桌面摸摸頭、餵食（布丁）、送禮 → 回到遊戲：物品各扣一次、好感與回憶、任務進度；強制停止 App 後再開不重複；背包已沒有的東西不扣並提示。
11. **對話**：兩位個性不同的 OC 說法不同；頻率「常常／不閒聊」、靜音；自訂台詞出現；晚上說晚上的話。
12. **App 情境對話**：預設關；開啟 → 帶到使用情況存取 → 允許後切到遊戲／音樂 App 會說對應台詞；排除的 App 不說且可隱藏；撤銷後停止；清除規則。
13. **工具**：番茄鐘 25 分鐘（螢幕關閉、Doze 中）→ 通知＋桌寵說話＋遊戲計數；準時 vs 一般精度的誤差；休息提醒重複；鬧鐘；重開機後提醒仍在；主畫面小工具顯示頭像、心情、待辦、下一個提醒；小工具按鈕。
14. **生命週期**：旋轉（若系統允許）、分割畫面、鎖屏／解鎖（停止繪製 → 恢復）、切到其他 App 一小時、低記憶體（`adb shell am send-trim-memory app.ocshimeji RUNNING_LOW`）、系統回收後不自己復活、收起後沒有殘留通知／計時器（`dumpsys alarm`、`dumpsys activity services`）。
15. **主題與安全區**：系統深淺色切換時泡泡、選單、小工具、通知正確；瀏海、手勢導覽、三鍵導覽下活動範圍正確。
16. **效能與耗電**：1 隻／3 隻、60／30 fps、螢幕亮 1 小時：電量（`dumpsys batterystats`）、記憶體（`dumpsys meminfo app.ocshimeji`）、診斷頁 fps 與每幀耗時；目標 < 2%／小時、< 40 MB（1 隻、128 px）。
17. **安全畫面與隱私**：銀行／支付 App（`HIDE_OVERLAY_WINDOWS`）時桌寵被系統隱藏且沒有錯誤；確認沒有讀取任何其他 App 的內容（Manifest 無無障礙服務、無 `QUERY_ALL_PACKAGES`）；清除桌寵資料。
