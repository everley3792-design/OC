# 16.5（0.16.5-alpha）飲食與烹飪全面升級

玩家的要求：全面升級飲食與烹飪系統。依 16.x 計畫（玩家確認）：食物屬性、食材分類、約 80 個食譜、做法、自由料理與發現、食譜書、品質、自動做、廚房（冰箱只是庫存的檢視）、餐桌與份數、剩菜、角色自己下廚分享、用餐時間、咖啡館點餐，全部經 `OC.Tx`。

## 原本的狀況

| 項目 | 原本 |
|---|---|
| 食譜 | 10 個，固定材料，三步驟小遊戲 |
| 做法 | 沒有分（都在爐台上同一個流程） |
| 品質 | 小遊戲分數只決定「多做一份」，做出來的東西沒有品質差別 |
| 發現 | 沒有：不會的就是不會 |
| 吃 | 效果固定；喜好依風味；溫度沒有作用 |
| 一起吃 | 沒有：只能一個一個餵 |
| 角色下廚 | 「做料理」活動只是動畫，沒有做出東西 |

## 做了什麼（`js/items/food16.js`、`js/ui/cook16.js`）

| 項目 | 做法 | 驗證 |
|---|---|---|
| 食材分類 | 穀物、蔬菜、水果、魚、奶蛋、甜味、菇類、香草香料、花；食譜可以寫「任何蔬菜×2」 | v16 26a |
| 新食材 | 奶油、鮮奶油、洋蔥、高麗菜、檸檬、巧克力、麵條、豆腐、辣椒、茶葉（食品店、市場、磨坊） | v16 26a |
| 80 個食譜、七種做法 | 煮、炒、烤、烘焙、蒸、拌、調飲；每道有份數、營養（飽足、精力、心情、舒適…）、風味、溫度；原本的 10 道保留（同 id，舊存檔不受影響） | v16 26a |
| 品質 ★1–★3 | 小遊戲分數＋料理等級＋材料稀有度；★★／★★★ 是各自的物品（背包仍是數量），效果 ×1.25／×1.5、賣價較高；圖鑑把它們算成同一道 | v16 26b、27a |
| 自動做 | 廚房的開關：不玩小遊戲，品質只看等級（最高 ★★，料理 Lv.6 起可能 ★★★） | v16 30 |
| 自由料理與發現 | 從背包挑 1–4 種食材＋做法 → 即時告訴你會做出什麼（沒做過的食譜顯示「？？？新的料理！」）；對上就發現並記進食譜書；對不上是家常料理（七種）或「奇妙的料理」；燒焦不扣材料 | v16 27b |
| 食譜書 | 廚房「食譜」分頁：每道列出材料（有的 ✓、缺的 ✗）、份數、最好的 ★；圖鑑新增「食譜」分類（做過／會做／？？？與提示） | v16 30 |
| 冰箱 | 廚房「冰箱」分頁＝背包裡的食物（同一份，不另外存） | v16 30 |
| 吃的感覺 | 冷天（冬天、雨雪）吃熱的 → 舒適＋、「暖起來了」；熱天吃冰的 → 開心；物種有一點點口味傾向（貓、熊、狐喜歡魚；兔、鹿不太愛魚、喜歡蔬菜…），只影響還沒形成的喜好，玩家設定的不會被改 | v16 28 |
| 端上桌與剩菜 | 做好後「端上桌」，或家具桌子的選單「端上桌」：付一次，在這個地點的人餓了會來吃一份（不再付），會記得是誰做的、對做菜的人好感＋；放超過一個遊戲日就收掉 | v16 29a |
| 角色自己下廚 | 角色自己去做料理（不是你安排的）時，用廚房裡有的食材做一道會做的菜、端上桌給大家；一天最多兩次（key `aicook:<角色>:<日>:<n>`）；生活設定可以關（`aiCook`） | v16 29b |
| 用餐時間 | 原本的用餐時間加權保留；桌上有菜時，餓的人更想去吃 | — |
| 咖啡館點餐 | 咖啡館櫃檯的卡片直接有「點拿鐵・XX 幣」等：付錢、拿到、當場吃（`OC.Tx` → `OC.Use`） | v16 30 |

## 未完成／未驗證（誠實標示）

- **沒有新的廚房家具**（烤箱、流理台、冰箱的 3D 模型）：七種做法都在爐台（或家具爐子）上做；冰箱是廚房裡的一個分頁。
- 依食物種類的吃東西動作只有兩種（吃、喝），沒有湯匙、筷子、小口咬的分別。
- 角色下廚只會做「會做的」食譜，不會自己發現新食譜；做菜不玩小遊戲（品質只看等級）。
- 不在你身邊的角色（抽象生活）不會下廚、不會吃桌上的菜。
- 咖啡館點餐只列四樣常見的；其他的仍在商店頁買。
- 手機上的手感沒有實測。
