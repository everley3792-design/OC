## 一、方向（先建立系統，再重製畫面）
**暖陽照著的小島（世界）＋ 白瓷玩具般的介面（UI）**。參考圖的優先順序最高：
- 小島 HUD 圖 → HUD 版面（頭像名牌、天氣時間膠囊、右側工具列、任務卡、白色大導覽列、紅點）。
- 低多邊形世界圖 → 浮在世界上的白色圓角元件、物品坐在圓形底座上、膠囊工具列。
- 粉彩 App 圖 → 雲邊天空頁首、圓形分類圖示、長春花紫。
- 大頭角色圖 → 角色的「軟塑膠」體積感（角色仍是 2D 看板，依已選定的方向 G）。
- 動物森友會／Tomodachi Life／曠野之息 → 只吸收原則：柔和圓潤、按下有手感、角色帶情緒的回饋、自然的光與世界動態、低學習成本。
- **沒有使用任何作品或參考圖的角色、Logo、圖示、介面圖形或素材**；貼紙圖示、配色、版面都是原創。

## 五、需要實機（📱）
- `backdrop-filter`（HUD 毛玻璃、景深）與 CSS `linear()` 彈簧在各家 Android WebView 的效能與外觀；已設計退回：省電模式關閉調色與景深、平衡模式關閉景深，舊 WebView 自動用三次貝茲曲線。
- 觸覺強度、音效與畫面節奏的整體手感、120Hz 裝置上的彈簧動態。
- 桌寵泡泡、小工具、啟動畫面的新色在不同桌布上的對比。

## 六、尚未完成（✗／◐）與原因
- ✗ **3D 模型重新建模**（建築、樹、家具改成更圓潤的低多邊形造型）：這次只改了光、調色、景深與環境生物；重做模型需要逐一調整碰撞與佈置，留到下一輪。
- ◐ **動畫工作室、繪畫工坊、角色編輯器**：已套用新元件樣式，但版面沒有重新設計。
- ◐ **角色動作**：加了跳躍的預備與回彈、玩具光影；更多新動作（例如走路的重心起伏誇張化、各種情緒的全身表演）沒有在這一輪重做。
- ✗ 角色改成 3D 玩偶：與已選定的方向 G（角色一律 2D）衝突，沒有做。
- 參考圖中的「鑽石／星星等其他貨幣」「拍照模式」：遊戲沒有這些系統，**沒有做假按鈕**；工具列只放真的功能（背包、鏡頭、佈置）。
