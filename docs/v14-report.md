# 14.0（0.14.0-alpha）統一風格、桌寵重構、全面打磨

要求：全面重構桌寵；再次徹底重新設計整個遊戲、統一美學與風格、全部用動物森友會的設計；優化整個 App；做完還沒做到的；檢查並修掉發現的問題、錯誤、不便與醜的地方，改善畫面、視覺、操作、UI、HUD。

**先說清楚三件事**
1. 「全部用動物森友會的設計」做的是**設計原則**（奶油紙、暖棕字、圓潤的形狀、薄荷綠與陽光黃、溫暖的對話框、口袋式背包、安靜的小 HUD）。**沒有使用該作品的任何角色、Logo、圖示、介面圖形、圖樣、版面或音樂**——色值、形狀、貼紙圖示、圖樣全部是自己做的。這是專案一直以來的規定，也是著作權上必須守的線。
2. 桌寵的原生部分**仍然沒有在任何實機或模擬器上執行過**（這個環境沒有）。這一輪把桌寵的行為全部搬進可以單元測試的純 Kotlin 核心並寫了測試，但「在手機桌面上實際的手感與相容性」沒有被驗證。
3. 畫面好不好看最終要你在手機上看。這裡的檢查方式是：把每個畫面（淺色＋深色，共 70 多張）截圖下來逐張看、把看到的問題修掉，再用測試量得到的部分（對比、觸控高度、有沒有空白膠囊、標題有沒有斷行…）。

## 一、統一成一種風格「島日和」
| 之前 | 現在 |
|---|---|
| 三種介面風格可切換（樂園／雅緻／玩具），淺色與深色的圓角、形狀還不一樣 | **只有一種**。白天與夜晚是同一套設計的兩個調色盤（圓角、形狀、元件完全相同），風格切換從設定移除 |
| HUD 是直接疊在畫面上的白字，在亮的草地上看不清楚 | 幾個有底的奶油色小膠囊（頭像名牌＋星幣、時間天氣、工具、任務）；沒有背景模糊 |
| 導覽列是一塊深灰半透明厚板、貼紙被轉成灰階、只有目前的分頁有字 | 奶油色托盤、五個彩色貼紙都有文字、目前的分頁底下是陽光黃的圓塊；觸控高度補到 48 |
| 環狀選單是深色圓盤 | 奶油色圓鈕＋棕色標籤 |
| 角色卡、檔案、地圖上有「空白的彩色膠囊」 | 那其實是**字和底色同色**（上一輪的樣式把字色設成透明），已修正；真的沒有內容的膠囊不顯示 |
| 標題旁邊的說明太長時，標題從字中間斷成兩行（「自主行／動」「技／能」） | 標題不斷行，說明自己換行 |
| 對話框會蓋住任務膠囊的一半 | 有人說話時任務膠囊讓開 |
| 原生的啟動背景、桌寵泡泡與選單、小工具、診斷畫面還是舊的紫白色（從遊戲切過去會閃一下顏色） | 全部改成同一組顏色 |

規格：`docs/design-system.md` 最上面的「14.0 現行規格」、`game/css/tokens.css`、`game/css/island.css`。

## 二、重新排版的頁面
- **背包**：口袋格。圓形口袋、空口袋也畫出來（補滿整列、至少 16 格）、數量在右下、名稱在口袋下方、右上顯示星幣。
- **交易紀錄**：原本只有一行行的文字。現在最上面是現在的星幣、今天的收入與支出，下面依日期分組，收入綠色、支出紅色。沒有紀錄時有說明。
- **桌寵中心**：最上面多了「桌面」——你選的角色站在上面（會眨眼、偶爾打招呼），點牠進入那一隻的設定。在瀏覽器裡標示為「預覽」。
- 其餘頁面（角色、檔案、工坊、地圖、日常、成就、圖鑑、設定、生活設定、素材庫、動畫工作室、番茄鐘、App 情境）**結構沒有改**，只是套用新的統一風格並修掉上表的問題。

## 三、桌寵重構
- **架構**：以前一隻桌寵的行為寫在 Android 視窗類別（`PetWindow`）裡，和視窗、觸控事件、選單混在一起，無法測試。現在全部搬到 `core/pet/PetActor.kt`（純 Kotlin、不依賴 Android）：輸入是指標樣本、每幀 tick、選單選項；輸出是指令（說話、播放聲音、震動、回報事件給遊戲、開選單、收起、開啟遊戲）。`PetWindow` 只剩顯示與執行指令。
- **新功能**：長按選單多了「去睡一下／叫醒牠」——牠會一直睡到你叫牠或點牠（一般的睡眠一分鐘內就會自己醒）。
- **外觀**：原生的泡泡與選單改成和遊戲相同的奶油色／夜晚色。
- **測試**：12 個新的單元測試（點一下的反應、靜音、隱藏時不出聲、長按選單內容、撫摸 15 秒內只回報一次、餵食的數量與口味反應、送禮、待在這裡、睡覺與叫醒、關閉拖曳、丟出去不回報、雙擊設定、暫停或泡泡還在時不自言自語）。
- **沒有做**：服務本身（`OverlayPetService`：視窗管理、前景服務、通知、螢幕開關）沒有重寫；多隻之間的配對邏輯（`PetSocial`）沒有動。

## 四、補做上一輪沒做的
- **圖片角色用手指直接調整**：編輯頁的「調整圖片」多了一個裁切框——拖四邊的黃色把手＝裁切（上限 45%），框內單指拖曳＝移動，兩指＝縮放。滑桿保留作微調。原圖不會被改。
- **3D 重新建模**：果樹（三層圓潤的樹冠＋向陽面的亮色小球）、杉樹（三層有圓邊的裙擺）、灌木（平滑的圓球）、岩石（河邊的圓石，不再是有稜角的石塊）、房屋正面（條紋遮雨棚、屋脊圓頭、盆栽、信箱）。占地與碰撞不變。
- **沒有做**：房屋的主體（牆、屋頂的形狀）、攤位、橋、室內的房間外殼沒有重新建模；沒有新增地點。

## 五、效能
- **靜態模型依材質合併**（`OC.Models.fuse`）：一棟房子 80 多個零件 → 約 22 個；一朵花 8 個 → 3 個；露台欄杆 110 多個 → 1 個；樹冠的葉子合成 3 個。
- **小島的繪製呼叫：557 → 約 250–265**（含陰影那一遍；軟體渲染下量測，數字本身與裝置無關）。森林 153 → 119、海灘 91 → 70、商店街 162 → 79。
- 手機上實際的幀率**沒有量過**。

## 七、沒做與已知問題
- 📱 所有原生功能（桌寵、新的睡覺選項、聲音、作息、雙人動作、小工具、觸覺）仍未在實機驗證。
- ◐ 桌寵「全面重構」：行為層重寫並有測試；服務層沒有重寫。
- ◐ 「徹底重新設計」：風格統一、HUD／導覽列／選單重做、三個頁面重新排版；其餘頁面只換風格、結構沒有改。
- ◐ 3D：樹、灌木、岩石、房屋正面重新建模；房屋主體、攤位、橋、室內沒有。
- 裁切框的上方把手在編輯頁捲到最上面時會被固定在頁面頂端的預覽舞台擋住，需要往下捲一點。
- 軟體渲染下測試偶爾因時序失敗（見上表的說明）；不代表手機上的表現。
- APK 是 **Debug 簽章**，不是正式發行版。
