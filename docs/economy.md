# 商店與經濟規格（第五階段）

貨幣：**星幣**（沿用既有 `save.coins`）。

## 1. 唯一交易流程 `OC.Tx`（`game/js/items/tx.js`）
```js
OC.Tx.run(key, { pay: { coins, items: { id: n } }, get: { coins, items: { id: n } } }, reason, meta)
  → { ok: true, entry, firsts } | { ok: false, why: ['原因'…], dup? }
```
1. **防重複**：`key` 成功過就拒絕（`dup: true`）。固定 key 的來源：任務 `quest:<日>:<id>`、成就 `ach:<id>`、心願 `wish:<oc>:<w>`、首次造訪 `visit:<地點>`、新發現 `find:<物品>`、採集 `forage:<地點>:<點>:<日>`、收成 `harvest:<菜園>:<播種時間>`、小生物 `critter:<地點>:<點>:<半天>`、每日掉落 `daily:<地點>:<日>:<i>`、搖樹 `tree:<id>:<時間>:<i>`、摘花、收回家具 `store:<uid>`。購買、餵食等一次性動作用 `Tx.uid()`。key 會存檔（保留最近 800 個）→ 重開遊戲、切換頁面、連點都不會重複得到。
2. **先驗證再套用**：金額與數量必須是 ≥0 的整數；物品必須存在；星幣與物品足夠。任何一項失敗＝整筆不生效（原子性）。
3. **套用**：同一個 JS 執行回合內完成（不會半套），寫入帳本（最近 300 筆）、立即存檔、發出 `coins` / `inv` / `tx` 事件（背包、快速背包、HUD 同步更新）。

**除了 `OC.Tx` 之外，沒有任何程式會改變星幣或物品數量**（`Store.add/take/coins` 只由 Tx 呼叫）。生活模擬模式的背包沒有新增／修改物品的功能；工坊只登記商品、不產生庫存。

自動測試：`node game/tests/world/run.js`（T1–T8：重複 key、星幣不足、原子性、負數／小數、庫存不足、購買、帳本、任務不能重領）。

## 2. 商店（`game/js/items/shops.js`）
| 商店 | 地點 | 規則 |
|---|---|---|
| 晴日雜貨攤 `general` | 晴日島 | 基本食物、種子、基本家具；**收購**（物品的 `sell` 價） |
| 晴日食品店 `food` | 商店街 | 食物、飲料、料理材料、種子 |
| 小針線服裝店 `clothes` | 商店街 | 帽子、飾品、花紋、上衣；**服飾一次性擁有**（已擁有＝不能再買） |
| 木木家具行 `furniture` | 商店街 | 室內與戶外家具（含掛牆、雙人座） |
| 星星禮品屋 `gift` | 商店街 | 禮物、玩具 |
| 每日市場 `market` | 商店街 | 每個遊戲日從 13 種中換 6 種，**每種限量 2–5 個**（庫存每天重置、不會變負）；**收購** |
| 雲朵咖啡館 `cafe` | 咖啡館 | 飲料與餐點；可「現在就吃」（購買後直接請 OC 吃） |

- **規則都看得見、沒有抽獎**：每間店每天一件「今日特價」（8 折，依遊戲日決定）；雨天咖啡館熱飲 85 折；每日市場的品項與數量依遊戲日固定。
- 商品頁：分類、搜尋、價格（原價刪除線）、特價／雨天標籤、剩餘數量、已擁有、工坊商品標記、數量選擇、合計、星幣不足時按鈕說明原因。
- 工坊商品：上架到玩家選擇的商店，價格由玩家決定（10–5000），賣回價格＝35%。

## 3. 收入來源
| 來源 | 金額（星幣） | 防重複 |
|---|---|---|
| 每日任務（4 個） | 50–120／個 | `quest:<日>:<id>` |
| OC 心願（玩家幫忙完成） | 60 | `wish:<oc>:<id>` |
| 成就 | 150（或成就自訂） | `ach:<id>` |
| 第一次造訪地點 | 80 | `visit:<地點>` |
| 新發現（第一次取得某物品） | 10 | `find:<物品>` |
| 賣出（雜貨攤、每日市場） | 物品的 `sell` 價 | 每次一筆，物品先扣 |
| 採集／釣魚／收成／小生物／搖樹 | 物品（可賣） | 見上方 key |

## 4. 平衡（0.5.0-alpha 的基準）
- 一天認真玩（任務 4 個 ≈ 360、賣 5–10 樣採集物 ≈ 150–300、偶爾成就／心願）≈ **500–800 星幣**。
- 日常消耗：一餐 20–80、料理材料 20–60、種子 20–40（收成 2–3 個、每個可賣 26–30）。
- 中期目標：家具 120–600（沙發 420、書櫃 360、鞦韆 400）、服飾 80–300。
- 稀有魚（星斑鯛 180、月光水母 400），但需要技能與時段，不能無限刷（每次釣魚都要真的完成小遊戲）。
- 種田：番茄種子 30 → 約 3 天 → 收成 2–3 個 × 30 ＝ 小幅獲利，需要每天澆水（雨天自動）。
