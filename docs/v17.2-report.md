# 17.2（0.17.2-alpha）觀察模式

依據：`docs/v17-roadmap.md` 第二節（玩家已同意：觀察和操控並存，用 HUD 的一個開關切換，預設維持操控）。

參考作品只取玩法原則（「看著一群人自己過日子」），沒有用它的文字、介面圖形、戶型或素材。

## 做了什麼

### 1. 觀察模式的開關（`OC.Observe`，`js/ui/observe17.js`）

**進入**：右邊工具把手展開後的第四個鈕「觀察」（眼睛）。

**進入後**：
- 收起：名牌卡、工具把手、任務卡、動作清單、操控標記、導覽列；
- 留下：
  - 左上：時間與天氣；
  - 右上：「時間線」「戶型」「結束觀察」；
  - 下面：人物條（每個人的臉、名字、在做什麼或在哪裡）＋自動鏡頭與速度。

**操控模式**：
- 你操控的角色改成「全自動」，設成「手動」的角色也是（手動的角色在觀察時只會站著）；
- 「半自動」「全自動」的不動；
- **結束觀察時全部恢復**：每個人原本的操控模式、原本的速度、原本操控的角色。

**其他**：
- 在觀察中點世界裡的角色＝看他（人物卡），不會打開互動選單；
- 撫摸、抱起仍然可以（直接碰角色不是「操作按鈕」）；
- 點地面不會叫人走過去；長按也不會。
- 關掉 App 再打開：觀察模式還在（狀態存在 `life.obs17`），結束時一樣恢復。

### 2. 人物條與人物卡

**人物條**：
- 每個人一個頭像；
- 下面一行：在這裡的寫正在做什麼，在別的地點的寫地點名稱（頭像變淡），路上的寫「在路上」；
- 正在看的那個人有陽光黃的框。

**點頭像**：鏡頭跟著那個人，並打開人物卡；再點一次同一個頭像收起卡片（鏡頭仍跟著）。

**人物卡**：
- 名字、地點、心情；
- **現在**：正在做什麼（＋腦中的理由，例如「（肚子有點餓）」）；
- **精力／飽腹／心情**三條；
- **今天**：時間線裡今天和他有關的事，重要的優先，最多三條；
- **和誰**：最親近的三個人，關係名稱＋現在怎樣（很要好、處得不錯、普通、不太合、**鬧得有點僵**、**慢慢和好中**）；
- 在別的地點：「去〇〇看看」。

**看別的地點的人**：
- 按「去〇〇看看」：鏡頭（和你操控的角色）換成那個人，畫面到那個地點；
- 這用的是 16.0 的「切換操控不傳送」：沒有人被移動；
- 結束觀察時換回原本操控的角色（畫面回到他那裡）。

### 3. 自動鏡頭

打開時（預設打開），每 6 秒看一次「現在最值得看的事」：

| 事情 | 優先 |
|---|---|
| 正在進行的事件 | 最高 |
| 三人以上的聚會（`Arcs`） | 高 |
| 兩個人在聊天／互動（冷戰中的兩人更優先） | 中 |
| 有人寂寞、低落、生氣、吃醋、緊張 | 低 |

- 只看畫面上的人（別的地點的事不會把畫面帶走）；
- 上方一行說明鏡頭為什麼在這裡（例如「🎥 栗子和麻糬在聊天」）；
- **你自己點了某個人之後，40 秒內自動鏡頭不搶走**；
- 演出（小劇場、事件的鏡頭）進行時不插手；
- 「🎥 自動鏡頭」可以關掉，只看你選的人。

### 4. 時間速度

- 時間是「遊戲循環」時：1×、2×、5×、10×、**30×、60×**（60×＝每秒 1 遊戲小時，一天約 24 秒）；
- 30×、60× **只在觀察時**有效：結束觀察回到原本的速度，平常的時間面板仍然是 1–10×；
- 速度 5× 以上，走路也快一點（最多 2 倍），不然一段路要走掉半小時遊戲時間；只影響走路，不影響動作與時間；
- 時間是「真實時間」或「固定時刻」時：改成一個「時間：遊戲循環才能加速」的按鈕（打開時間面板）。

### 5. 戶型總覽（頁面 `plan17`）

- 三間住處各一個分頁（我的家、黃屋頂小屋、紫屋頂連棟屋），分頁上寫裡面有幾個人；
- 2D 俯瞰圖：牆、門（薄荷綠）、家具（依佔地大小，寫名字的最後一兩個字）；
- 每個在家的人一個圓點（衣服的顏色＋名字）：
  - 實心＝在畫面上，就是現在的位置；
  - 空心＝不在畫面上，是最後看到的位置（沒有就排在房間中間）；
- 不在這間的人列在下面（在哪裡，或「在路上」）；
- **點圓點或名字**：關掉頁面、鏡頭去找那個人（在別的地點就過去）。

**和計畫的差別**：
- 計畫寫了「有樓層切換」，但現在的三間住處都只有一層，所以沒有樓層分頁，頁面上直接寫「每間住處都是一層」；
- 多層的戶型在 17.5「住處與戶型」。

### 6. 其他

- 時間線可以帶一個人打開（人物卡開著時按「時間線」，只看那個人）。
- `World.setWalkMul`：只改走路的速度（路徑），給觀察的高速用。

## 修正（做的過程中找到的）

| 問題 | 原因 | 修正 |
|---|---|---|
| 觀察時整個畫面點不動 | 根元素的 class 叫 `obs17`，和觀察列本身的 `.obs17` 同名，根元素也被套上「固定位置、不接收觸控」 | 根元素改用 `obs17-on` |
| 收起的人物卡還在畫面上，擋住中間 | 卡片的 `display: flex` 蓋過了 `hidden` | `[hidden]` 時 `display: none` |
| 觀察中點角色會打開互動選單 | 點角色走的是 `OC.Touch`（撫摸系統），不經過世界的點擊 | `OC.Touch` 的放開也先問觀察模式 |

## 沒有做／還不完整

- **手機上沒有驗證**：觀察模式的版面在小螢幕、瀏海、手勢列上的實際樣子；60× 在手機上的效能。
- 戶型總覽**只有住處**，沒有咖啡館、圖書館等其他室內；也沒有樓層（現在沒有多層的房子）。
- 圓點在「不在畫面上」時只是大概的位置（背景生活只記地點，不記房間裡的位置）。
- 自動鏡頭只看畫面上的事；別的地點發生的事不會自己把畫面帶過去（避免一直換場景），只會出現在人物條的那一行和時間線裡。
- 觀察時仍然會出現要回答的事（請求、事件的選項）：照打擾預算出現，沒有因為觀察而另外安靜。
- 人物卡的「和誰」只寫關係的狀態，沒有「最近怎麼了」的說明（等 17.3 每天結算的關係）。
