# 16.7（0.16.7-alpha）自主與世界

計畫（`docs/v16-plan.md` 的原「16.4 自主與世界」）：感知與注意力、社交維繫、情境判斷、重新規劃；其他地點完整模擬（地點設施資料化）；地上物品（放下／丟棄，角色依個性／需求／注意力反應）；新道具。

## 原本的狀況

| 項目 | 原本 |
|---|---|
| 感知 | 角色只看自己的需求和清單上的分數；旁邊有人哭、有人被丟出去、有人在睡覺，都不會注意到 |
| 朋友 | 好幾天沒說話也不會想念；朋友在別的地方時不會去找 |
| 情境 | 會在睡覺的人旁邊跳舞、在圖書館玩耍、對心情不好的人開玩笑、下雨天在室外看風景 |
| 失敗後 | 長椅被坐走、路被擋住 → 放棄，下一次很可能又選同一件事；不說原因 |
| 其他地點 | 不在你身邊的角色只是「在某地做某事」：咖啡館可以同時有十個人在用一張桌子；兩個人在同一個地方也不會遇到 |
| 地上 | 只有樹上掉下來的果實（走過去就自動撿起）；不能把東西放下或丟掉 |

## 做了什麼（`js/life/aware16.js`＝`OC.Aware`、台詞 `js/life/aware16d.js`、道具 `js/items/props16.js`）

| 項目 | 做法 | 驗證 |
|---|---|---|
| 感知與注意力 | 每個在畫面上的角色每 2 遊戲分鐘看一下四周：有人心情不好、被丟出去、被摸摸、在睡覺、在吃東西、地上有東西、開始下雨。會不會注意到看距離、新不新鮮（看過的一段時間內不再注意）、個性（愛照顧人的更容易注意到別人難過、吃醋的會在意別人被摸、好奇的會注意地上的東西）。最強的那一個成為「焦點」：轉頭看過去、表情符號、有時說一句（想法泡泡），寫進診斷紀錄「注意到：…」；之後 20 多分鐘內影響牠想做什麼（安慰那個難過的人、看別人吃東西自己也餓了、擔心剛被丟出去的） | v16 35 |
| 社交維繫 | 好朋友／家人／伴侶（或好感 ≥ 45）超過一天沒說話 → 想念：和他有關的社交分數提高（「好久沒和…說話了（3 天）」）；外向、黏人的更想念，冷淡、獨立的比較不會；朋友在別的地方 → 有可能去那裡找他 | v16 36 |
| 情境判斷 | 旁邊有人在睡覺 → 不跳舞、不玩耍、不開玩笑（愛惡作劇的只減一點），累的話看別人睡自己也想睡；圖書館要安靜；下雨的室外 → 不看風景、不澆花（愛冒險的不在乎），想去室內躲雨；對方心情不好 → 不開玩笑。每一個都寫出原因 | v16 37 |
| 重新規劃 | 長椅被坐走、路走不過去、太遠 → 記住（2 分鐘），下一次選擇時避開同一個位子；生活紀錄寫「改變計畫：本來想休息，但長椅被佔走了，改成閱讀」，有時說一句（「那就換個計畫。」） | v16 38 |
| 地上的東西 | 背包裡的東西可以「放在地上」或「丟掉」（經 `OC.Tx`；每個地點最多 12 樣；存在 `save.ground16`，換地點回來還在）。地上顯示那個東西自己的圖示。角色依個性和需要反應：**肚子餓的去吃**（挑嘴、有潔癖的不吃地上的東西；記得「吃了你放在地上的咖哩」、對你好感 +1）；**無聊的去玩玩具**（口琴＝吹口琴、素描本＝畫畫、拼圖／紙牌／積木＝玩拼圖，玩完東西還在）；**丟掉的東西會被愛整潔的撿起來放回你的背包**（經 `OC.Tx`）；好奇的會過去看看。放著的食物一天後會壞掉、丟掉的東西兩天後不見；你自己點它可以撿回來。你操控的角色走過去**不會**自動撿起（那是你放的） | v16 39 |
| 其他地點 | 每個地點的設施有容量（`OC.Aware.FAC`：咖啡館雙人桌 6、廚房 1、圖書館閱讀書桌 4、懶骨頭 2、家裡的床 2…），滿了就不會選；生活紀錄寫是哪個設施（「葉影圖書館的閱讀書桌」）。不在你身邊、在同一個地方、醒著的兩個角色每 10 遊戲分鐘有機會遇到：用 `OC.Topic` 選一個真的話題，依兩人的立場決定聊得來（好感 +1）或意見不合（兩人之一固執才會有一點摩擦），留下回憶「在雲朵咖啡館和小空聊了釣魚，很聊得來」、寫進「最近的對話」 | v16 40 |
| 新道具 | 12 樣原創圖示的新東西：飛盤、泡泡水、跳繩、紙飛機、木頭陀螺、彈珠、口琴、小拼圖、紙牌、素描本、沙灘水桶（禮品店）、野餐籃（食品店、風車磨坊）。和其他玩具一樣可以「和 OC 一起玩」，放在地上時有自己的玩法 | v16 41 |
| 台詞 | 73 句（注意到各種事、吃了、玩了、收好了、看看、被拿走了、改變計畫），依特質選 | v16 41 |
| 生活設定 | 新增「角色會注意身邊的事」（可以關掉） | — |

所有改變只是調整 AI 候選的分數（`Brain.decide` 在 `Mind11`、`Arcs` 之後呼叫 `OC.Aware.shape`），不繞過 `Brain.reserve`／`hold`；手動操控的角色、玩家安排的事不受影響；離線補算時什麼都不做；沒有獎勵、不送進度事件（玩你放下的玩具會送一次 `play`）。

## 未完成／未驗證（誠實標示）

- 感知只用在畫面上（同一個地點）的角色；別的地點只有設施容量和「遇到聊天」，沒有感知。
- 地上的東西只能從背包放；點地上的東西只能撿起來，還不能直接「叫某某去吃／玩」（AI 會自己去，或由清單安排的內部路徑）。
- 設施容量是一張資料表（`FAC`），不是從 3D 場景讀出來的；有幾個地點的設施是概略的。
- 新道具 12 樣（計畫到 16.8 的目標是 +150 樣道具，這次沒有接近）；沒有新的家具。
- 「想念」只影響分數，不會主動傳訊息或寫信給對方。
- 手機上沒有實測（地上圖示的大小、點擊範圍）。
