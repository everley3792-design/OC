# Roadmap

## ✅ 第一階段（完成）— 視覺方向
三輪共 7 個方案（A–G）的影片、總覽圖、原型；使用者選定 **G：3D 固定視角世界 + 2D 角色（晴日島）**。

## ✅ 第二階段（本次）— 可操作的垂直切片 + Android
- 精緻 3D 場景（島＋森林）、2D 看板角色、光影與天氣、環境動畫。
- 完整 UI/UX、Design System、深淺色主題、效能模式。
- 可操作系統：移動、互動、居民對話與送禮、需求、背包、商店、佈置、任務、成就、圖鑑、人生目標、逐格動畫工作室、圖片匯入、桌寵輸出。
- Android 外殼（WebView + 原生橋接 + 系統懸浮桌寵）與實際建置的 Debug APK。
詳見 `docs/phase2-report.md`。

## ✅ 第三階段（0.3.0-alpha）— 角色創作基礎
多角色、完整創角流程、高自由度捏角與自訂部件、個性／特質／小怪癖、素材匯入匯出（含 GIF/APNG/WebP/Sprite Sheet/ZIP/.ocpack）、繪畫工坊、逐格動畫工作室、角色與動畫整合進 3D 場景。詳見 `docs/phase3-report.md`。

## ✅ 第四階段（0.4.0-alpha）— 深度生活模擬
每個 OC 的需求與情緒、個性驅動的自主行為（Utility AI＋完整活動流程）、作息、後天習慣（需同意）、願望與技能、
多 OC 自主社交與共同活動、有方向的關係、資料驅動對話（可匯入匯出）、回憶與人生故事、動態事件、玩家互動、
自主程度設定、分層／離線模擬、開發者診斷、情境測試 1–13。詳見 `docs/phase4-report.md`。

## ✅ 第五階段（0.5.0-alpha）— 世界、地點、物品與經濟
世界地圖與 7 個可進入的地點（晴日島、我的家、晴日商店街、雲朵咖啡館、葉影圖書館、苔光森林、星砂海灘）、跨地點 OC 自主生活與跟隨、
統一互動設施、每個地點各自的佈置、釣魚／料理／採集／種田／小生物小遊戲、統一物品系統、雙模式背包與拖曳使用、
每個 OC 的飲食喜好、工坊商品上架、7 間商店、星幣經濟與交易帳本、地點事件與回憶、圖鑑與探索進度、情境測試 1–13＋交易測試。
詳見 `docs/phase5-report.md`、`docs/world-map.md`、`docs/items.md`、`docs/economy.md`。

## 第六階段（建議下一步）
**先做：實機驗證**（雲端容器無法完成）——第三～五階段在手機上的效能（島 ≈ 560 draw calls 在軟體渲染下量到，需要實機確認與 LOD 調整）、多 OC 同時生活的 fps、小遊戲的觸控手感、桌寵驗證清單。

**內容與世界**
- 未開放地點：風車丘、彩虹遊樂園、其他島嶼／旅行（地點登記已預留，`locked`）。
- 更多食譜、魚、小生物、家具；季節與節慶。
- 音訊系統（事件已可記錄 `sound` 步驟）。
- 桌寵：使用 `OCApp.petContext(app)` 的 App 情境台詞；桌寵狀態已包含所在地點與最愛食物（`petState().place / favFoods`）。
- 居民（栗子、小空）接上同一套生活引擎與地點系統。

**發佈**
- AAB、targetSdk 34+、Play 上架素材、隱私說明（遊戲完全離線，不蒐集資料）。
- CI：在有 Google Maven 的環境跑 AGP 建置與 instrumented tests。
