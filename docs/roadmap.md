# Roadmap

## ✅ 第一階段（完成）— 視覺方向
三輪共 7 個方案（A–G）的影片、總覽圖、原型；使用者選定 **G：3D 固定視角世界 + 2D 角色（晴日島）**。

## ✅ 第二階段（本次）— 可操作的垂直切片 + Android
- 精緻 3D 場景（島＋森林）、2D 看板角色、光影與天氣、環境動畫。
- 完整 UI/UX、Design System、深淺色主題、效能模式。
- 可操作系統：移動、互動、居民對話與送禮、需求、背包、商店、佈置、任務、成就、圖鑑、人生目標、逐格動畫工作室、圖片匯入、桌寵輸出。
- Android 外殼（WebView + 原生橋接 + 系統懸浮桌寵）與實際建置的 Debug APK。
詳見 `docs/phase2-report.md`。

## 第三階段（建議下一步）
**先做：實機驗證**（無法在雲端容器完成）
1. 在 2–3 台實機（低階 Android 8–10、中階、旗艦）安裝 APK：啟動、WebGL 效能（目標 60fps，省電 30fps）、記憶體。
2. 走完 `docs/architecture.md` 的桌寵驗證清單（權限、覆蓋其他 App、拖曳、通知收起、重開機後狀態）。
3. 依實測調整效能模式預設值與陰影解析度。

**再做：內容與深度**（使用者先前要求延後的大型系統）
- 生活 AI（居民作息、彼此互動）、經濟平衡、社交事件、小遊戲。
- 更多地點（星砂海灘、風車丘、雲朵市集——目前在地圖上標示「未開放」）。
- 動畫工作室完整版：圖層、走路／待機多組影格、四方向素材、匯出 .ocpack。
- 事件演出（過場、表情特寫）、音樂與音效（目前設定中標示「未開放」）。
- 室內場景與室內佈置。

**發佈**
- AAB、targetSdk 34+、Play 上架素材、隱私說明（遊戲完全離線，不蒐集資料）。
- CI：在有 Google Maven 的環境跑 AGP 建置與 instrumented tests。
