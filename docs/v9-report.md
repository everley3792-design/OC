## 二、新增與改善

- **角色事件（補上 8.0 未完成的「新的多人趣味事件劇本」）**：15 個事件，全部經既有事件引擎（一次一個、間隔、冷卻、條件、`once` 鍵），並依特質／情緒／關係／旗標觸發：
  惡作劇、惡作劇過頭、和好、口味之爭、分零食、冒失鬼跌倒、扶起來、看雲的形狀、深夜聊天、講笑話給你聽（玩家選擇反應，三種結果）、一起整理、小鳥朋友，
  以及跨天的三段小故事「秘密基地」（發現 → 邀請 → 一起蓋好，以旗標 `baseFound`／`baseShared`／`baseDone` 串接）。約 98 句新台詞（`ev_*` 分類，依 voice／特質有不同說法）。檔案：`js/life/events9.js`。17a、17b ✅
- **創角／編輯器「回答 5 個小問題」**：5 題情境問答換算性格滑桿與建議特質（玩家確認才套用），角色會對結果有反應；「隨機性格」骰子。17c ✅
- **世界的環境生命（3D）**：蝴蝶（拍翅）、鳥群、跳出水面的魚與水花漣漪，只在白天、不下雨、室外出現；效能設定關閉特效時不出現、低像素比時減量；「減少動態」時翅膀不拍、不出鳥群；共用幾何與材質，純視覺、不改任何資料。檔案：`js/world/ambient.js`。17d ✅
- 版本 0.9.0-alpha（versionCode 12）。

## 四、需要實機驗證（📱）
與 8.0 相同：桌寵在其他 App 上方的觸控與同步、小工具、觸覺強度、音樂在手機喇叭上的聽感、120Hz／低階機效能、長時間耗電。步驟：`docs/compat-test-plan.md`。

## 五、尚未解決的限制（✗ / ◐）
- ◐ 背包、商店、工坊、地圖、動畫工作室等既有頁面：本次只修正了發現的錯誤與不一致，沒有重新設計版面（它們已使用 Design Tokens、深淺色、≥48dp）。
- ✗ 3D 場景模型與材質沒有重新建模（本次只新增環境生物）。
- ✗ 預測返回手勢：需要 targetSdk 36 與實機測試 WebView 返回行為；在無法實測的情況下不加入 `enableOnBackInvokedCallback`，以免返回鍵在手機上失效。
- ✗ AAB／Play 上架：需要 AGP 與 Google Maven（本環境無法連線）。APK 是 Debug 簽章，**不是正式發行版本**；正式簽章只能經環境變數 `OC_RELEASE_*` 提供。
- 參考作品只吸收原則（角色之間會自己發生小故事、玩家的選擇影響結果、世界裡有不打擾的環境生命），沒有使用任何角色、素材、圖示、音樂或介面圖形。
