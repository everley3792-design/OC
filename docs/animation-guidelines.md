# 動畫規範

所有數值來自第一階段原型（`prototype/shared/core.js`），Kotlin 版本在 `android/core/anim/Motion.kt`，兩者必須一致。

## 角色（共通原則）
| 動作 | 規格 |
|---|---|
| 呼吸 | 0.36–0.40Hz；吸氣 55%、吐氣 45%；身體 y 縮放 ±3%、頭上下 0.6 單位（B：1px，二值） |
| 眨眼 | 間隔 2.2–4.8s 不規則；18% 機率連眨兩次；閉 70ms、張 150ms |
| 走路 | 相位由「實際移動距離 / 步距」推進 → 腳不打滑；身體上下 2.2；手臂反向擺動；起步/停步有 0.08 的混合 |
| 轉身 | A/C：五官滑動 + 身體輕微擠壓，彈簧 (1.4Hz, 阻尼 6)；B：5 個角度逐格 |
| 跟隨動作 | 停步、轉身、落地後：耳朵 `wobble(3Hz, 阻尼 4–5) × 0.4–0.6`，左右耳相差 0.04–0.08s；尾巴、圍巾延遲 |
| 預備動作 | 跳起前 0.15–0.25s 下蹲（squash 0.82–0.88）、耳朵後壓 |
| 擠壓伸展 | 體積守恆：x = 1/√y；起跳 1.10–1.18、落地 0.80–0.88，0.15s 內回彈 |
| 表情 | 驚訝：眼睛放大＋眉毛上揚＋「!」；開心：^^ 眼＋臉紅＋愛心；吃東西：嘴開合 8–14Hz |
| 被拖起（桌寵） | 手腳揮動（快走路相位）、身體繞握點擺盪（阻尼彈簧）、驚訝臉 |

## 方案節奏
| | A Mallow Mist | B Pixel Grove | C Inkpot Tales |
|---|---|---|---|
| 角色時間 | 連續 60fps | 逐格：走路 4 幀/步、8–12fps | 一拍二（12fps 量化） |
| 線條 | — | — | boil 8fps，振幅 0.55 |
| UI 進場 | 淡入＋上浮 8dp，outCubic 500ms，依序 120ms | 直接出現（逐元件 100ms 間隔） | outBack(1.6) 彈入，紙卡微旋轉 |
| 按壓 | 縮放 0.90–0.94 | 下沉 2px | 陰影貼合 1.5px |
| 頁面轉場 | 霧化溶接 + 上浮 24px，600ms | 16 階 Bayer 溶接 / 菱形擦除 | 翻頁（捲曲邊），600ms |
| 地點切換 | 圓形霧化展開 → 鏡頭推入 → 淡入 | 菱形擦除 → 地名逐字出現 | 地圖展開 → 翻頁 → 手寫地名 |
| 特殊反應 | 柔彈簧（角色參數）＋ UI outBack(1.2) | 預設跳躍高度表 [3,7,9,7,3,0] | 誇張擠壓＋狀聲詞（蹦！嚼嚼） |

## 禁止事項
- **UI 元件縮放**的 overshoot：A/B ≤ 6%（`outBack` c1 = 1.2 → 實測 5.3%，單元測試 `uiPopOvershootStaysUnderSixPercent`）；C 為俏皮風格允許 `outBack` c1 = 1.6（約 9%），上限 10%。
- **角色參數彈簧**（轉身、升起、擠壓回彈）允許 15–28% overshoot，但只作用在小位移上（轉身參數、≤ 8dp 位移），且 1 秒內完全靜止；不可連續彈跳。
  - 參考值（單元測試驗證）：`spring(2.2Hz, 阻尼 6)` 峰值 1.280；`spring(1.4, 6)` 1.146；`spring(1.6, 5.5)` 1.207；`spring(1.3, 5)` 1.174。
- 不使用全螢幕閃白、強烈閃光；轉場霧化峰值 ≤ 55% 不透明度。
- 不用粒子特效掩蓋動作不足；先做好角色的預備與收尾。
- 同一時間最多 1 個主要動畫焦點（角色反應優先於 UI 動畫）。

## 環境動態
樹冠搖擺 0.8–1.3 單位（B：每 2 秒 1px）、水波擴散 2.2s 週期、雲影 9dp/s、煙 0.32 週期/s、雨 300–460dp/s（B/C 12fps 步進）、螢火蟲以噪聲路徑漂移並以正弦閃爍。

## 效能模式
省電模式：環境動態停止（保留水面一種），角色呼吸保留、眨眼保留，跟隨動作簡化為單次。
