# 16.3（0.16.3-alpha）角色工作室

玩家的要求：角色編輯頁滑動時嚴重跑版；圖片匯入模式流程與功能缺陷很多；重新設計整套創角／編輯；圖片模式要有自己的邏輯，拿掉捏臉選項，改成順手的圖片調整；裁切與縮放全部重做；加入自訂事件（**可匯入腳本、不限數量、接近星露谷物語的對話與過場模組**）、專屬互動、角色台詞；圖片角色的動畫可以選「用預設」或「全部自己匯入」，並且**一鍵全選**。

## 先找到的問題

| 問題 | 原因 |
|---|---|
| 編輯頁滑動跑版 | 整頁一起捲，舞台用 `position: sticky; top: 52px`，但頁首是 `position: absolute`、會跟著捲走——捲動時頁面內容從舞台上方露出來，舞台又蓋住段落標題 |
| 圖片角色有一堆用不到的選項 | 外觀分頁沿用捏臉（範本、臉、耳朵、顏色、服裝），對圖片沒有作用 |
| 裁切與縮放難用 | 三個小框（大小框、裁切框）＋十幾個滑桿分散在長頁面裡；預覽和實際畫面的比例不同 |
| 去背會吃掉角色身上的白色 | 匯入時用「全域顏色鍵」：跟背景同色的地方全部變透明（白背景的眼白、牙齒一起不見）；匯入後不能還原 |
| 匯入後還判斷不到背景 | 匯入會修邊並留 4 px 透明邊，偵測只看畫布最外圈 → 以為沒有背景 |

## 做了什麼

| 項目 | 做法 | 驗證 |
|---|---|---|
| 兩區版面 | 新的工作室頁（`ui/studio16.js`）：上面是固定的舞台＋預覽動作列＋分頁列，**只有下面的面板捲動**；頁面本身不捲 | v16 16a（捲動 1200 px，舞台與分頁位置完全不變） |
| 依角色種類的分頁 | 程式繪製：外觀、部件、資料、個性、喜好、說話、台詞、互動、事件、動畫。圖片角色：**圖片**、動畫、飾品、資料、個性、喜好、說話、台詞、互動、事件（沒有捏臉） | v16 16b |
| 取景台 | 圖片站在「腳底」線上、旁邊是「標準高度」虛線框；單指拖曳＝移動、兩指＝縮放、右邊把手＝寬、上邊＝高、右上角＝一起；「裁切」切換成四邊把手（選用，預設不裁）；數值微調收在折疊區。只改 `appearance.frame`，原圖不變；對應方式與世界的繪製相同 | v16 16c（真實觸控：拖曳與兩指撐開） |
| 自動對齊 | 找出圖片看得見的範圍，放大到標準高度、腳底對齊、左右置中 | v16 17d |
| 去背 | `OC.Cutout`：從圖片邊緣灌水（只去掉跟邊緣相連的背景色）＋柔邊（去掉背景的色偏）；**點一下**去掉被圍起來的空隙（手臂和身體之間）；有即時預覽、容許度、復原一處。套用到角色的所有動作、所有影格，存成新圖，**原圖保留、可以還原**（`.ocpack` 也帶著原圖） | v16 17a、17b、17c |
| 創角匯入 | 選檔 → 偵測到單色背景就出現去背畫面 → 自動對齊 → 外觀步驟就是取景台＋同一組工具 | v16 21（真實選檔） |
| 動畫來源 | 全部用預設（圖片自己表演所有動作）／混合（建議：有自己的就用，沒有的用預設）／全部自己匯入（不用預設表演）。每個動作有勾選框：**全選**、全不選、反選；勾選後一次「改用預設」「改用我的」「匯入到選取的」「清除選取的」。常用的 24 個動作先顯示，「顯示全部」可展開（全選一直包含全部 155 個） | v16 17e、17f |
| 批次匯入 | 一次選很多檔案，依檔名對應動作（walk_01、walk_02、行走3 → 走路；jump.gif → 跳），認不出來的在同一張表裡選或略過；沿用角色的去背設定 | v16 17g |
| 角色台詞 | 依情境（打招呼、聊天、和你、吃東西、一個人時、邀約、關係、桌寵）新增自己的話，可加心情／時段條件，「只用我寫的」或混合；「試說」用角色的說話方式唸出來 | v16 18a、18b |
| 專屬互動 | 名稱、圖示、性質、親密程度、雙方動作、關係變化、回憶、三組台詞（自己說的／對方答應／拒絕）。存檔後出現在互動選單的「專屬」，只有這個角色能做；對方用意願模型回應 | v16 19a、19b |
| 自訂事件 | `OC.Script`：純文字資料的事件腳本，最多 6 個角色（A–F）、條件（地點、時間、天氣、季節、旗標、變數、關係、需求、心情、特質、年齡、距離、機率…）、走位、面向、動作、表情、鏡頭、淡出淡入、黑邊、旁白、選項分支、標籤／跳躍／如果、旗標與變數、關係／情緒／需求、回憶。編輯器有**積木**與**原始碼**兩種，錯誤會指出第幾行（點一下跳過去），可以「試播」。可以**匯入腳本**（`.ocs`／`.txt`／JSON，一個檔案很多事件），**不限數量**；放在角色身上會跟著 `.ocpack`。格式：`docs/oc-script.md` | v16 20a–20d（錯誤行號、一次匯入 300 個、條件成立才演、`.ocpack` 來回） |

## 未完成／未驗證（誠實標示）

- **手機上的手感沒有實測**：取景台的兩指縮放、把手大小（觸控半徑 26 px）、面板捲動只在 Chromium 手機模擬與 CDP 觸控事件中驗證。
- 去背是「單色背景」的做法：照片、漸層或複雜背景去不乾淨（會提示「邊緣顏色不一致」），沒有做 AI 去背。
- 事件腳本的積木編輯器：設定區（trigger／cast／when…）是可編輯的文字框，不是一格一格的積木；步驟是積木。條件裡的 `if` 也是一行文字。
- 事件腳本沒有「多個選項同時顯示圖片」「角色移到別的地點」「改天氣」這類會影響世界的指令（刻意不做，避免腳本改變存檔以外的東西）；`sound` 只能用遊戲內建的合成音效名稱。
- 互動選單仍是 16.2 的社交選單（加了「專屬」分類）；16.4 會整個重做。
- 舊的編輯頁（`charpages.js` 的 `charedit` 定義）與 `charedit.js` 的「調整圖片」區塊（13.0／14.0 的小框）已經沒有地方使用（被新工作室覆寫），程式碼暫時保留，之後清理。
