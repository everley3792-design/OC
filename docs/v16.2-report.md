# 16.2（0.16.2-alpha）意願模型與互動

計畫：`docs/v16-plan.md` 的 16.2。玩家的要求：**互動不設門檻表，全部都能做，看對方願不願意**（個性、好感、關係多重疊加），可能被拒絕或降好感等各種反應。

## 做了什麼

| 項目 | 做法 | 驗證 |
|---|---|---|
| 意願模型 | `OC.Will`（`life/will16.js`）：B 對 A 的熟悉／好感／信任／親密／不合、**這件事的親密程度 vs 兩人有多親近**（太快太親近會大扣分；剛好的距離加分）、B 的個性（社交性、特質、物種、人生階段，經 `Traits13.accept`）、心情、需求、正在做的事、旁人在不在、歷史（剛拒絕過、一直做同一件事）、冷戰、一點隨機；很普通的事（打招呼、聊天氣）幾乎誰都會接受。**所有互動共用**（新的、舊的聊天／抱抱／吵架…都經 `Brain.Social.respond`） | v16 12a–12d |
| 反應光譜 | 不只是好／不好：熱情回應、開心接受、勉強配合、反過來捉弄、害羞閃躲、愣住、尷尬地笑笑、婉拒、不耐煩、推開、跑開、哭了。各有動畫、台詞與後果：成功的效果依反應打折或加成；**太突然**會讓對方好感下降、不合上升，並記住「突然…嚇了一跳」；被拒絕的一方也會受傷（敏感的更明顯）；被拒絕會被記住一天 | v16 12d、13a、13b |
| 60 種互動、12 類 | 問候、閒聊、關心、玩鬧、惡作劇、親近、才藝、禮物、八卦、爭執、和解、戀愛。新增 44 種（打招呼、聊近況、問「還好嗎」、好好聽對方說、扮鬼臉、鬼抓人、從背後嚇一跳、取綽號、牽手、蹭蹭、唱歌、畫一張給對方、變小魔術、遞小紙條、說祕密、說八卦、抱怨、怪罪、推一把、故意不理、主動伸手和好、請客賠罪、誇對方好看、說貼心的話、親臉頰、依偎…），都有原創台詞（`life/lines16.js`） | v16 12a |
| 點別的角色 | 環狀選單多了「（你的角色）的互動」：12 類分頁、每一項旁邊顯示對方**大概**的反應（😊😐🙁，可在生活設定關掉）；按下後你的角色走過去做，對方當場決定 | v16 13a、13b（真實點擊） |
| 硬規則（只有兩條，只為了保護） | 戀愛類互動要 `Mind.romanceOK`（戀愛開啟、兩人都標示成年、**兩人都滿 18 歲**）；不成立時那一項顯示 🔒 與原因 | v16 12c |
| 不照你的意思 | 小機率（生活設定：0／低 3%／中 6%（預設）／高 12%；固執的更常、心情不好也會）你操控的角色不做，**每次說出原因**（不想對喜歡的人這樣、不好意思、沒心情…） | v16 13c |
| 角色自己也會用 | AI 每次思考時抽幾種新互動當候選（依個性、關係、心情；壞關係才會選爭執類、有衝突才會選和解類） | v16 13d |
| 設施邀請 | 長椅、書架、沙灘巾、旋轉木馬的動作卡多了「邀請誰一起」；兩人座以上的家具（沙發、鞦韆）多了「邀請」；列出這裡的角色與大概的反應；對方答應就一起在**那個**設施做 | v16 14 |
| 新特質 12 個 | 慢熟、自來熟、愛吃醋、討好型、毒舌、怕麻煩、愛照顧人、記仇、好哄、愛表演、八卦、愛撒嬌——全部經資料改變社交選擇、接受度與情緒 | （v13 3a 的資料檢查） |
| 修正 | 玩家安排的互動不會被事件搶走（事件會等）；有事件正在用到某個角色時，邀請會說明「正在經歷一件特別的事」 | v16 13 |

## 未完成／未驗證
- 互動的動畫沿用現有動作庫（沒有為新互動畫新的動作）；部分組合在畫面上會比較像「說一句＋一個姿勢」。
- 意願模型的數值是我依常識調的；長時間遊玩下是否太常被拒或太容易，需要你玩過回報（16.8 會做長時間統計調整）。
- 對話仍是舊的系統（話題不連貫的問題在 16.3 處理）。
- 手機實機沒有驗證（選單在小螢幕上的操作）。
