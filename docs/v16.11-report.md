# 16.11（0.16.11-alpha）生老病死與收官

依據：`docs/v16-blueprint.md`（定案藍圖）版本表的 16.11：疾病與健康系統；選擇性死亡與告別劇場；壞關係完整衝突與和好弧線；重大事件小劇場與回放；補齊內容、長時間數值平衡、桌寵同步與全套回歸測試。

## 原本的狀況

| 項目 | 原本 |
|---|---|
| 健康 | 沒有。需求很低只會「想睡、想吃」，不會生病 |
| 壽命 | 年齡只由玩家設定；長者只是一個人生階段，不會離開 |
| 壞關係 | 12.0 的冷戰 → 緩和 → 和好／疏遠、互相避開、朋友調解、玩家調解、道歉；16.2 的意願模型在冷戰時拒絕（「還在冷戰」）。**沒有起因、不會在背後說壞話、送禮沒有作用、玩家看不到哪裡有問題** |
| 重大時刻 | 只有信箱的一封信；沒有演出，錯過就錯過了 |
| 桌寵 | 只知道名字、特質、心情、台詞、稱號、背包 |

## 做了什麼

### 生病與健康（`js/life/health16.js`＝`OC.Health16`）

| 項目 | 做法 | 驗證 |
|---|---|---|
| 真實的原因 | 在室外淋雨一個半小時擲一次感冒；需求「睡眠」見底三小時以上（一直沒睡）；精力和睡眠都很低卻還在活動四小時（過勞）；感冒沒休息、精力見底 → 發燒；吃了在地上放超過半天的東西（吃壞肚子）；兩小時內吃三次而且已經很飽（吃太多）；被你用力丟出去落地（擦傷）；站在感冒的人旁邊一陣子（傳染）；長者偶爾有老毛病（關節痠痛、咳嗽）。每一次都用固定的 key 擲一次，不會因為重試改變 | v16 60、62 |
| 體質 | 嬰幼兒和長者比較容易生病；愛運動、精力旺盛的比較不容易，敏感的比較容易 | — |
| 生病時 | 需求慢慢下降（感冒：精力、樂趣；發燒：精力、舒適；肚子痛：舒適…，休息時減緩）；AI 想休息、不想跑跳（候選活動分數乘上倍率並寫出「感冒，想休息」）；肚子痛不想吃東西；名牌卡顯示「🤧感冒」 | v16 60、66 |
| 朋友照顧 | 有好感的朋友生病了，照顧類的互動分數提高（關心的個性更高），寫出「○○感冒了」 | v16 62 |
| 病假 | 生病（感冒、發燒）的那天不去上班上學，記成病假，**不算缺勤**、不扣表現（先判斷生病再判斷忙碌——修正：生病而睡著的角色原本會被算成缺勤） | v16 61 |
| 治好 | 時間到就好（休息時好得比較快）；藥：感冒藥（感冒、發燒）、胃藥、薑茶（感冒、肚子痛、咳嗽，效果較弱）、OK 繃（擦傷）、痠痛貼布（老毛病緩解一天）。藥在晴日雜貨攤買（不會免費取得）；喝的經 `OC.Use` 餵（動畫完成才扣），OK 繃、貼布用「送給」；效果只從 `OC.Progress` 的 eat／gift 事件判斷。好了之後一段時間不會再得同一種病 | v16 61 |
| 「健康」App | 口袋手機新 App：每個人生了什麼病、原因、還要多久、什麼有幫助；每個角色的壽命設定；紀念欄 | v16 62 |
| 設定 | 生活設定「生病與健康」（預設開）；關掉後沒有人生病 | v16 60 |

長時間平衡：用真的遊戲迴圈、時間 ×10、4 個半自動角色跑 3.3 個遊戲日。第一版有 5 次生病（同時一半的人在生病，太頻繁）→ 調低機率與門檻（沒睡 3→4 小時且 45%→25%、過勞 2.5→4 小時且只有 40%、傳染門檻提高且 20%→12%、發燒 50%→30%、淋雨 30%→22%）→ 重跑同樣 3.3 天：0 次，睡眠見底的時間比例 0.8%。生病應該是偶爾的事件。

### 壽命與告別

| 項目 | 做法 | 驗證 |
|---|---|---|
| 預設關閉 | 生活設定「壽命與告別」預設關；每個角色有自己的壽命設定：**會生病、不會離開（預設）**／自然／不會生病、不會離開 | v16 63 |
| 壽命 | 物種壽命倍率 × 82 歲，每個角色再差幾歲（龍、幽靈、機器人等很長）。年齡仍然只來自玩家的設定與生日成長 | — |
| 常常說累 | 只有設定打開、選「自然」、過了壽命的長者才會進入：寄一封信、留下回憶、更常休息、更想見朋友（社交分數提高）。改回別的設定或關掉，就取消 | v16 63 |
| 道別 | 七天後：小劇場——本人先說話，每位朋友（好感夠或家人）各說一句再見，最後一句話；留下「紀念相框」（`OC.Tx` key `keep16:<角色>:<日>`）；朋友難過一週（樂趣類活動降低、寫「還在難過」）並記住「和○○道別了」；寄信 | v16 63 |
| 可以撤銷 | 角色的全部資料存進紀念欄；「讓牠回來」恢復角色並改成「不會離開」，朋友的難過也結束 | v16 63 |
| 最後一個 | 最後一個角色永遠不會離開 | v16 63 |

疾病**不會**致死；離開只來自玩家打開的壽命設定。

### 壞關係（`OC.Feud16`，建立在 12.0 的 `OC.Arcs` 上）

| 項目 | 做法 | 驗證 |
|---|---|---|
| 起因 | 冷戰開始時記下起因：先找兩人最近「出問題」的回憶（嚇了一跳、被推開、放鴿子、聽說被說壞話…），沒有就依兩人的個性（愛比較的一點小事吵起來、潔癖受不了對方亂放…） | v16 64 |
| 避開、拒絕 | 已有：冷戰中不去找對方、碰到會尷尬；聊天、邀約的意願寫「還在冷戰」（出遊的回答也會用到） | v16 64 |
| 背後說壞話 | 冷戰中，一方偶爾（一天最多一次，愛八卦、衝動的比較會，溫和有禮的比較不會）向共同的朋友抱怨：朋友若不太信任被說的人，對他的印象變差並記下；正直的、或很信任被說的人的朋友反而對說壞話的人印象變差。有時會傳回被說的人耳裡（衝突增加、冷戰變長） | v16 64 |
| 和好的路 | 時間、道歉、朋友調解、你讓他們談（已有）＋**送小禮物**：冷戰中縮短剩下的時間，緩和期有機會直接和好 | v16 64 |
| 你可以幫忙 | 「健康」App 的「關係問題」：誰和誰、冷戰中／緩和中／和好了／疏遠了、起因、誰跟誰抱怨過；按鈕：讓他們談談、請某一方道歉（排進那個角色的動作清單）、請共同的朋友幫忙（三個人要在同一個地方） | v16 64 |
| 和好的小劇場 | 和好時播一段：道歉、接受、之後的一句話，副標寫起因與怎麼和好的 | v16 64 |

### 重大時刻的小劇場（`js/ui/theatre16.js`＝`OC.Theatre`）

| 項目 | 做法 | 驗證 |
|---|---|---|
| 播放 | 上下柔和黑邊（一般半透明層，沒有 filter／混合模式）、標題卡、一句一句（說話者頭像與名字）、點一下下一句、×2、跳過；減少動態時沒有動畫。播放中角色 `hold('stage')`，結束一定放開；**不改任何資料**（發生的事已經做完才演） | v16 65 |
| 錯過與回放 | 不在島上看（開著頁面、小遊戲、別的演出）＝錯過：寄信「錯過了：…」；口袋手機「回放」列出所有小劇場（新的有標記），點了再看（回放時不保留任何角色）。同一件事只記一次（固定 key） | v16 65 |
| 哪些是重大時刻 | 告別、和好、出生或領養（`home16:child`）、畢業（`career16:grad`）、兩人都到了的約會 | v16 63、64 |
| 設定 | 生活設定「重大時刻播放小劇場」（預設開；關掉也會記在回放） | — |

## 未完成／未驗證（誠實標示）

- 沒有診所、醫生職業的看診；藥只能買。嚴重疾病、住院、長期病程沒有做；疾病不會致死（這是刻意的）。
- 告別沒有葬禮、墓碑、掃墓等地點或物件；紀念相框只是物品（不能擺在家裡當家具）。
- 嬰兒的「乾淨」需求、被抱著移動、自動放進嬰兒床（藍圖第 3 節）仍沒有做。
- 霸凌與和解（學校）、同事的摩擦沒有各自的種類，都走同一套冷戰。
- 小劇場是「頭像＋台詞」的介面演出，沒有鏡頭運鏡或 3D 世界裡的走位。
- 台詞總量仍遠低於藍圖目標（約 1,200 句 vs 3,000＋）。
- 長時間平衡只在模擬器的軟體渲染下跑了 3.3 個遊戲日；更長時間與手機上的數值沒有驗證。
- 桌寵的生病行為只有單元測試，**沒有在實機上看過**。
