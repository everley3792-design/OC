# 15.2（0.15.2-alpha）兩個新地點與島上生活內容

計畫的第三個版本：開放**風車丘**與**彩虹遊樂園**（兩個都要），並加入一批「島上生活」的內容。參考的生活模擬遊戲只取設計原則；場景、模型、名稱、圖示、小遊戲全部是原創的。

## 一、風車丘（`js/world/areas15.js` 的 `hill`）
| 東西 | 能做什麼 |
|---|---|
| 石造風車＋**風車磨坊**（商店） | 風車葉片一直在轉（下雨、起霧時轉得比較快）；磨坊賣麵粉、麵包、蜂蜜、**小風車**、**薰衣草束**、向日葵種子、風箏、花草茶 |
| 薰衣草田（兩排花圃） | 和島上的花圃一樣可以摘花 |
| 野餐墊 | 躺下來休息（角色也會自己去） |
| 山丘頂、薰衣草田邊 | 角色會去看風景、玩耍；天上有兩隻風箏 |
| 採集點 ×3、小生物 ×4 | 香草葉、林間莓；晴蝶、小瓢蟲、新的**草原蚱蜢**（白天、不下雨時） |
| 長椅、柵欄、果樹、杉樹、石頭、步道、路牌 | 路牌回地圖 |

## 二、彩虹遊樂園（`fair`）
| 東西 | 能做什麼 |
|---|---|
| **星光舞台** | 「上台表演」＝演唱會小遊戲：音符沿三條線滑下來，碰到線時按那一條（真的觸控，按下的瞬間判定）；24 個音符、連擊、1–3 星。演出費**每位角色每天一次**（交易 key `concert:<角色>:<日>`），台下的朋友越多越多；之後再演還是會記入技能、回憶與進度。在場的朋友會拍手、結束時歡呼 |
| **摩天輪** | 「搭一圈」：角色坐進最低的那節車廂（地上看不到角色，那節車廂亮燈），約 14 秒轉回來；搭乘中不能離開這個地點、操控的角色不會自己帶你走 |
| **旋轉木馬** | 「坐一圈」：新的活動「坐旋轉木馬」，角色坐進前面的馬車座位，木馬一邊轉一邊上下起伏；角色也會自己去坐 |
| **套圈圈** | 一局 20 星幣、3 個圈；標記停在瓶子上時點一下丟出去。套中 1／2／3 個＝爆米花／套圈圈熊熊／閃亮星星徽章 |
| **點心攤**（商店） | 彩虹棉花糖、焦糖爆米花、冰淇淋汽水、檸檬汽水、綜合果汁 |
| 彩虹拱門、氣球、長椅、花圃、路燈 | — |

- 兩個地點都進了世界地圖（新的小島圖樣、航線），地圖上**已經沒有鎖住的島**；地點卡片有各自的特色說明。
- 新的物品 8 種（含 3 種原創圖示：小風車、棉花糖、爆米花）、2 間商店、4 個地點任務、4 個成就（風的山丘、舞台常客、神準〔隱藏〕、最高的地方）。「環島旅行」成就與「走遍所有開放的地點」目標改成跟著開放的地點數。
- 繪製呼叫：風車丘約 29、遊樂園約 34–110（看鏡頭裡有幾個大型遊樂設施；軟體渲染量測）。

## 三、島上生活內容
| 內容 | 說明 |
|---|---|
| **島報**（口袋手機的新 App） | 每天的報紙，**只寫真的發生的事**：今天的天氣、昨天每位角色最重要的回憶、昨天的帳本、今天各店的特價、兩週內的生日、小島評價、房間評分。昨天沒事就寫「很安靜」 |
| **房間評分** | 「我的家」的分數：家具價值、種類、基本配備（床、可以坐的地方、桌子、燈、植物）、換過牆壁地板；超過 18 件會扣分（太擠）。5 個等級，達到的等級在島報**由玩家領取**（key `room:<地點>:<級>`，只能領一次）。一開始的家約 120 分，低於第一級 |
| **小島評價** | 1–5 星，來自六項真實數值：家、探索、收藏、感情（角色對你、角色之間）、菜園、回憶（照片），並提示最弱的一項。只讀資料，不會建立新的關係紀錄 |
| **生日** | 角色資料裡的「生日」（3/14、3月14日、03-14 都可以）。當天角色心情變好、留下回憶，背包裡多一個蛋糕可以送給牠（一年一次，key `bday:<角色>:<年>`）。島報會提前兩週提醒 |
| **打工** | 雲朵咖啡館的櫃台、風車磨坊、遊樂園點心攤的動作卡多了「打工一班」。角色走到櫃台後面工作 30–40 遊戲分鐘（會累、會見到人），做滿 20 分鐘才算一班，工資**每位角色、每個地點、每天一次**（key `job:<角色>:<地點>:<日>`，從唯一的進度事件流算，離線補算不會付錢）。這個活動**只有玩家安排時才會發生**（新的 `cmdOnly`，AI 不會自己去打工） |

## 五、計畫裡 15.2 還沒做的
- **夢境、宣言、連續劇（多集劇情）、願望與恐懼、人生階段、季節活動**：沒有做。（情緒感染、冷戰與和解在 12.0 的 `OC.Arcs` 已經有；生日這次做了。）
- 新地點沒有地點專屬的角色事件，也沒有室內。
- 遊樂設施只有摩天輪與旋轉木馬能搭；摩天輪是「角色躲進車廂、車廂亮燈」，不是把角色畫在車廂裡。
- 📱 一樣只在 Chromium 的手機模擬裡看過；手機上的幀率（新地點有比較多會動的模型）沒有量過。
