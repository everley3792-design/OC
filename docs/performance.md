# 效能與耗電（0.7.0-alpha）

## 遊戲（WebView）
效能模式（高／平衡／省電／自訂）真的改變像素比、陰影、特效、草、fps 上限、看板解析度與點光源（`docs/architecture.md`）。
App 在背景時暫停繪製與模擬；回來時一次離線補算（最多 8 小時）。軟體渲染（測試環境 SwiftShader）的數字不代表手機。

## 桌寵（原生）
| 項目 | 做法 | 玩家設定 |
|---|---|---|
| 幀率 | Choreographer 迴圈依上限跳幀：活動 60 或 30、大家都在休息時 15、暫停時 10 | 60／30 |
| 螢幕關閉 | 收到 `SCREEN_OFF` 停止 frame callback（不是降低，是停止），`SCREEN_ON` 恢復 | 螢幕關閉時暫停（預設開） |
| 視窗更新 | 只有位置真的改變時才 `updateViewLayout`；`PetView` 只在影格／姿勢改變時 `invalidate` | — |
| 繪製 | 軟體 Canvas、不建立 GL context；畫質「省電」關閉點陣圖濾波 | 畫質 96／128／160 px |
| 記憶體 | 影格懶載入，所有寵物共用以位元組計的 LRU；`onTrimMemory(RUNNING_LOW)` 與 `onLowMemory` 清空 | 快取 16／24／48 MB |
| 數量 | 硬上限 3 隻 | 1–3 |
| 背景工作 | 沒有 wake lock、沒有輪詢網路；使用情況查詢最多每 4 秒一次，只在開啟功能且螢幕亮著時 | App 情境對話（預設關） |
| 提醒 | AlarmManager（非精確為預設），不常駐計時器 | 準時（需權限） |

診斷頁可以看到實測 fps、每幀耗時、快取用量、每隻的重畫次數。

## 尚未量測（需要實機）
第二階段訂的目標仍待實機量測：連續 1 小時 < 2% 電量／小時、記憶體 < 40 MB（1 隻、128 px）；60/90/120Hz 螢幕的拖曳流暢度。步驟見 [`compat-test-plan.md`](compat-test-plan.md)。
