# 角色動畫、特殊演出與音效（第六階段）

## 1. 動畫原則
角色仍是 2D 看板放進 3D 世界（不轉成 3D 模型）。內建骨架（`OC.Rig`）與玩家逐格動畫（`OC.Anim`）走同一套狀態：`OC.World.setAction(actor, action, { dur, priority })` → `OC.CharRender.draw()`。

每個動作都有：**預備 → 動作 → 跟隨 → 收尾**（`game/js/char/render.js` 的 `rigState`，用 `seg / arc / ease` 依時間分段），不是整段同一個彈跳。

| 動作 | 分段 |
|---|---|
| 跳躍 jump | 蹲下（壓扁、耳朵往後）→ 起跳（拉長、手舉高、耳朵落後）→ 落地（壓扁）→ 回正 |
| 開心 happy | 小蹲 → 兩次跳（第二次較小）→ 左右搖擺、尾巴快搖 |
| 吃 eat | 手拿上來（嘴「喔」）→ 咬 → 嚼三下 → 停頓滿足 → 重複 |
| 品嚐 taste | 拿起 → 咬一口 → **屏住呼吸的停頓**（眼睛閉、微歪頭）→ 交給下一個反應 |
| 好吃 yum | 雙手捧臉（有回彈）、臉紅、搖擺、輕跳、尾巴快搖、耳朵豎起 |
| 難吃 yuck | 往後縮 → 發抖（逐漸減弱）→ 耳朵垂、汗、陰影線 |
| 驚訝 surprised | 微蹲 → 彈起、手張開、耳朵豎直 → 回落 |
| 歡呼 cheer／得意 proud／點頭 nod／搖頭 shake／收下 receive／唱歌 sing／素描 sketch／打哈欠 yawn | 各自的分段姿勢與道具（素描本、音符、手上的物品） |

**次級動態**：走路時耳朵隨步伐彈、尾巴擺；待機時重心慢慢移動、偶爾抖耳朵、心情好尾巴搖；睡覺偶爾耳朵動。
**個性**（`CharRender.motion(c)`）改變的是**姿勢本身**而不只是速度：活力 → 幅度與節奏；害羞 → 手收在前面、跳得低、臉紅、頭低；疲倦（精力／睡眠低）→ 耳朵垂、頭低、眼睛半閉、偶爾打哈欠；開朗 → 幅度更大。
看板只在量化後的姿勢改變時重畫（`CharRender.key`；表演中的動作每秒最多 10 次、待機 4 次）。

### 玩家逐格動畫與備用
新動作都登記在 `OC.Chars.ACTIONS`（含備用鏈）：`yum → happy`、`yuck → sad → hurt`、`cheer → happy → jump`、`taste → eat`、`receive → happy`、`sing → talk → happy`、`sketch → read → sit` …
玩家沒有畫某個動作時，自動用備用鏈中有影格的動作；全部沒有就用內建骨架——**不會因為缺動畫而中斷**（測試 9）。手上拿的東西（禮物、食物）兩種角色都會畫出來。

## 2. 特殊演出 `OC.Stage`（`game/js/play/stage.js`）
可重用的演出系統，劇本是資料（`STAGES`），每個劇本可以有依個性的版本（`plain / bright / shy / cool / tired`）：

```js
taste_fav: { important: true, steps: { plain: [['cam','a',2.5], ['face','a','player'], ['anim','a','taste',1.1], ['sfx','chew'], ['wait',1.0],
  ['anim','a','yum',2.6], ['sfx','yum'], ['fx','a','hearts'], ['say','a','react_yum'], ['wait',2.0]], bright: [...], shy: [...], cool: [...] } }
```
步驟：`cam`（鏡頭柔和拉近，永遠比目前近）`face` `walk`（走到玩家身邊）`anim` `jump` `say`（對話引擎，依聲線）`fx`（愛心、閃光、音符、陰影、汗、臉紅、彩紙）`sfx` `prop`（手上拿著物品）`wait` `card` `emote`。

- 內建：品嚐（最愛／喜歡／普通／不喜歡／討厭 × 個性）、收禮、請求接受／婉拒／完成、技能升級、人生目標新／進展／完成。
- **演出不改資料**：呼叫者先用 `OC.Tx` 等完成資料（扣物品、入帳、回憶），所以跳過、中斷、App 切出去都不會遺失或重複獎勵（測試 11）。
- 播放時角色被保留（`Brain.hold('stage')`），自主行為不會打斷；角色正在特殊事件中時會等一下再開始；結束後保留與鏡頭都恢復（測試 10）。
- 重要演出：柔和遮幅＋「跳過 ›」＋「×2」。特殊事件（`OC.Events`）觀看時也用同一組按鈕；跳過＝剩下的步驟立即完成，結果照常只套用一次（測試 11c）。
- 一次只播一個（佇列），卡片另外排隊，同時最多 2 張。
- 降低動態：沒有鏡頭移動與遮幅、粒子變少、卡片只淡入。

### 回饋卡片 `OC.Stage.card`
任務完成、成就、圖鑑新發現、技能升級（含解鎖內容）、新稱號、請求完成、人生目標：小卡片從下方淡入、3 秒後淡出、可點掉；不會跳出大面板或強烈閃光。

## 3. 音效 `OC.Sound`（`game/js/play/sound.js`）
- **全部即時合成**（WebAudio 振盪器＋柔化噪音）：原創、沒有音檔、沒有授權問題，APK 也不會變大。
- 類別與音量：主音量、介面（點擊、開關、分頁）、角色與物品（咀嚼、吞嚥、跳、腳步、水花、收線、切菜、炒、門、放家具…）、環境音、事件與獎勵（鈴聲、升級琶音、號角、閃亮、星幣）；設定 › 聲音，可整個關閉。
- 環境音：依地點／天氣／時段交叉淡入（海浪、風、雨、雨打在窗上、室內底噪），白天偶爾鳥鳴、晚上蟲鳴（戶外、沒下雨時）。
- 同步：音效由演出步驟、小遊戲事件（拋竿、上鉤、收線、切菜、火候）、交易（星幣）觸發，跟著畫面同時發生；同一個音效有冷卻、同時最多 10 個聲音 → 不會因重複觸發而疊成一團。
- 第一次觸碰後才啟動（瀏覽器／WebView 規定）；App 切到背景自動暫停。

## 4. 新增內容
- 新動作：在 `rigState` 加分段姿勢＋在 `OC.Chars.ACTIONS` 加備用鏈（玩家可以替換成影格）。
- 新演出：在 `STAGES` 加一筆（可只寫 `plain`），程式呼叫 `OC.Stage.perform(名稱, { oc, item, vars })`。
- 新音效：在 `LIB` 加 `[類別, 冷卻毫秒, 合成函式]`。
