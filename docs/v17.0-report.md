## 灰色畫面

| 問題 | 原因 | 修正 | 驗證 |
|---|---|---|---|
| **匯入圖片（或在工作室按去背）時，畫面變灰變糊、什麼都看不到也按不到** ← 最可能就是你遇到的 | 16.3 的「去除背景」視窗是 `.sheet`，但程式從來沒有讓它滑上來（少了 `.open`）。它一直停在螢幕下方，只有灰色模糊的遮罩蓋住整個畫面。舊的測試是用程式直接按它的按鈕，所以沒發現 | 讓它像其他視窗一樣滑上來 | v17 4：真的出現在畫面上，用手指按「套用」 |
| 開任何下方視窗時，整個畫面（連 HUD）蓋上灰色＋模糊 | 遮罩 `#scrim` 用 `backdrop-filter: blur(2px)`。這就是「被壓縮、變灰」的樣子；每一幀還多一次全螢幕模糊 | 拿掉模糊，只剩半透明色 | 逐頁截圖 |
| 點灰色的地方沒反應／要點好幾下 | 點遮罩關的是「堆疊最上面那一層」。上面有看不見的層（動作卡、環狀選單、狀態卡）時，點擊被它用掉，灰色還在 | 點遮罩關掉要遮罩的那個視窗，和它上面的層 | v17 2（真實觸控） |
| 往下滑關視窗，視窗不見了、灰色留著 | 抓取條只有 5 px、沒有 `touch-action: none`，手機把滑動當成捲動而中斷；手指在視窗外放開時收不到事件，視窗停在被拉下去的位置 | 頂端 22 px 的滑動區、`touch-action: none`、`setPointerCapture` | v17 2（真實觸控：在視窗外放開） |
| 事件過場結束後，上下黑邊和「跳過／×2」留著 | 腳本事件（16.3）的結束路徑沒有收起 `Stage.controls` | 結束時一定收起 | 安全網測試 v17 1 |
| 從別的 App 回來，3D 畫面是空的 | 繪圖環境被手機收回後，只在 App 在前景時檢查一次 | 回來後仍中斷 → 出現「重新載入畫面」卡片（先存檔） | v17 3 |

**安全網**（`OC.Guard`，`js/ui/guard17.js`）：
- 每秒檢查所有會蓋住整個畫面的東西：灰色遮罩、已消失的視窗、上下黑邊、演出黑邊、對話狀態、小劇場、3D 畫面。
- 沒有擁有者超過 2.5 秒（還在動畫中的不算），就用原本關閉它的方式關掉。
- 每次處理都寫進「設定 › 關於 › 畫面安全網紀錄」。

**原本我沒能用隨機操作重現。** 在 Chromium 手機模擬裡用真實觸控隨機操作約 900 步（點按鈕、點世界、返回、長按、滑動、模擬鍵盤開關）都沒有卡住。後來在回歸裡，安全網把一個「看不見的視窗」關掉，才找到第一列的去背視窗。如果裝了 0.17.0 還會發生，「畫面安全網紀錄」會寫出是哪一層。
