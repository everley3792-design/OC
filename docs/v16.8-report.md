# 16.8（0.16.8-alpha）住處與家庭

依據：`docs/v16-blueprint.md`（玩家提供的定案藍圖）第一部分 2、3 節與版本表的 16.8：三種住宅與入住管理頁；同居摩擦；雙人床、兒童與嬰兒家具；伴侶、子女與家族樹。

## 原本的狀況

| 項目 | 原本 |
|---|---|
| 住宅 | 開局可以選三棟房子，但黃屋頂、紫屋頂兩棟**沒有室內**（標成「16.5 前不存在」）；所有人都回「我的家」睡 |
| 入住 | 只有開局能分配；之後不能搬家；搬進去也沒有人有意見 |
| 床 | 只有單人床；誰睡哪一張不看關係 |
| 同居 | 住在一起沒有任何影響 |
| 嬰兒 | 有「嬰兒」階段（很多事做不了），但沒有人照顧、沒有成長紀念 |
| 家庭 | 只能在開局設定父母／伴侶；不會有新的家人；沒有家族樹 |

## 做了什麼（`js/life/home16.js`＝`OC.House16`、模型 `js/world/models16.js`）

| 項目 | 做法 | 驗證 |
|---|---|---|
| 三棟房子都能進去 | 島上的黃屋頂、紫屋頂房子有了門和室內（`yhouse` 黃屋頂小屋 2 人、`phouse` 紫屋頂連棟屋 3–4 人；珊瑚屋頂＝原本的「我的家」4–6 人，家具全部保留）。新房子可以自由佈置、換牆壁地板；點門的卡片會寫「住著：…」 | v16 42 |
| 回自己的家 | 角色睡覺回**自己的**房子（AI、別的地點的抽象生活、旅行都改了）；只有住戶能睡那間房子的床，客人可以打盹；島上每扇門只給自己家的人進去睡 | v16 43 |
| 四種新床 | 雙人床（兩個位子）、上下舖（上舖、下舖）、兒童床（幼兒、兒童）、嬰兒床（只有嬰兒）——原創模型，家具行買得到 | v16 42、44 |
| 同床共枕 | 不是固定規則：伴侶、家人（沒有在吵架）、很要好又信任的朋友才會睡同一張雙人床或上下舖；陌生人不會；未成年和不是家人的大人絕不同床 | v16 44 |
| 入住管理頁 | 口袋手機「住處與家人」→「住處」：每棟房子、住戶、人數；點一個人 → 搬到別棟／搬出去。搬進有人住的房子時，原住戶依關係和個性反應（😊 很歡迎／🙂 可以／😐 有點勉強／🙁 不想），每個都寫原因（是家人、還不熟、之前有過摩擦、喜歡自己的空間、家裡會變擠…）。有人不想 → 頁面上顯示反應，可以「強制入住」（**不跳確認視窗**）：不想的人好感下降、摩擦增加、留下回憶「…不顧我的意思搬進來了」，之後一週每天一點摩擦，第八天「漸漸習慣了」 | v16 45 |
| 同居日常 | 每個遊戲日：住在一起的每一對更熟（熟悉 +1）；生活習慣不合會累積摩擦（潔癖／愛整齊對邋遢、淺眠對愛熱鬧），有時留下回憶；愛照顧人的讓室友好感上升；早上與回家時更常和室友打招呼聊天；每週一封「…的這一週」的信（經 `OC.Budget.mail`） | v16 46 |
| 照顧寶寶 | 同住的大人或青少年看到寶寶需要東西（吃、陪、安撫）就走過去照顧（抱著、哄，有台詞），寶寶需求回升、照顧的人累一點、兩人更親；這個動作只由需要觸發，不出現在選單 | v16 47 |
| 成長紀念 | 寶寶被照顧足夠次數、過了足夠天數後：第一次翻身、會爬、扶著站起來、走出第一步、說出第一句話——每一個都成為寶寶和家人的回憶，並寄一封信 | v16 47 |
| 孩子（預設關閉） | 生活設定「伴侶、子女與領養」打開後：同住、感情好、兩人都成年的伴侶，偶爾會想要孩子 → 經打擾預算**先問你**（好啊／再等等／現在不要）；答應的話三天後寶寶出生，住進同一棟（有空位才會問），和父母是「爸媽／孩子」、和父母其他的孩子是兄弟姊妹。新角色只會因為你同意才出現 | v16 48 |
| 領養 | 每棟房子「領養一個孩子」：選要領養的大人（可以兩位）、嬰兒／幼兒／兒童、名字；未成年不能領養、房子滿了不行 | v16 48 |
| 家族樹 | 「家族樹」分頁：依關係（父母 → 孩子、伴侶）自動分代，伴侶並排加 ♥，每個人寫是誰的孩子 | v16 48 |

另外：玩家提供的定案藍圖存成 `docs/v16-blueprint.md`，逐節列出已做到與還沒做到的部分（包括前幾版和藍圖不同的地方）。
