# 全系統視覺規劃（與方案無關的骨架）

選定方向後，第二階段依此骨架為每個系統套上該方案的皮膚。**版面、資訊層級、操作與動畫回饋在三方案間共通**，只有材質、圖示、字體、節奏不同。目的是讓 20+ 個畫面一開始就有一致的規則，不會越做越擁擠。

## 0. 全域規則

- **畫面骨架**（直向 360×640dp 設計基準，xxhdpi = 1080×1920）：
  - 狀態列安全區 24dp（實際讀取 `WindowInsets`）、底部手勢區 16dp、左右邊距 16dp。
  - 單手熱區：主要操作放在**下方 40%**；破壞性或少用操作放上方。
  - 每頁最多 **1 個主要按鈕**（實心）＋ 2 個次要（外框）。
- **三層結構**：世界層（2.5D 地圖）→ HUD 層（≤6 個常駐小元件）→ 頁面層（底部表單 / 全頁 / 對話）。
- **頁面類型只有 4 種**，所有系統都必須套用其中一種：
  1. **底部表單 Sheet**（背包、快速選單、物品詳情）：可拖曳半開/全開，背後世界仍可見。
  2. **全頁 Page**（創角、檔案、圖鑑、設定、動畫工坊）：左上返回，右上一個主要動作。
  3. **疊層 Overlay**（地圖、對話、事件）：半透明遮罩，點遮罩可關閉（對話除外）。
  4. **提示 Toast / 浮字**：2 秒內自動消失，不阻擋操作。
- **手勢**：點擊＝選取/確認；長按 450ms＝拿起/更多；拖曳＝移動物品/旋轉角色/捲動；雙指＝縮放世界（0.8×–2×）與工坊畫布；返回鍵/手勢永遠關閉最上層。
- **回饋**：每個觸控在 100ms 內有視覺反應（按壓縮放或像素下沉）；成功＝角色反應優先於 UI 特效。
- **深淺色**：每個方案都有 light/dark token；世界層不跟系統深色模式，改由遊戲時間日夜控制，HUD 與頁面才切換。

## 1. 系統逐一規劃

| 系統 | 頁面類型 | 主要資訊（層級由上而下） | 主要操作 | 動畫回饋 |
|---|---|---|---|---|
| 開場與首次遊玩 | 全頁 | Logo → 一句世界觀 → 開始 | 點任意處 | Logo 書寫/彈入、角色登場 |
| 新手引導 | 疊層（局部聚光） | 一次只講一件事 | 依指示點擊 | 聚光圈移動、角色示範 |
| 角色選擇 | 全頁（水平卡片） | 3 個預設角色＋「自己創造」 | 左右滑、點選 | 選中角色跳出揮手 |
| 自由創角 / 捏臉 | 全頁 | 角色預覽（上半）→ 分類 → 選項 → 顏色 | 點選項、拖曳旋轉、雙指放大臉部 | 套用時角色小反應、耳尾彈簧 |
| 角色檔案 | 全頁 | 頭像＋名字 → 個性 → 需求 → 想法 → 關係 → 目標 | 捲動、點關係對象 | 需求量表填充、頭像呼吸眨眼 |
| 生活需求 / 狀態 | HUD 頭像環 ＋ 檔案 | 最低的需求優先顯示 | 長按頭像 = 快速狀態 | 需求低時頭像環變色、角色表情改變 |
| 個性特質 | 檔案內標籤 | 2–4 個特質 | 點特質看說明 | 標籤彈入 |
| 角色關係 | 檔案分頁 / 圖譜 | 好感度、關係名稱、共同回憶 | 點人物→互動選單 | 愛心增加、關係升級動畫 |
| 自主生活 | 世界層 | 角色正在做的事（頭上小圖示） | 點角色 = 查看/打斷 | 行為切換有預備動作 |
| 對話 / 特殊事件 | 疊層 | 說話者 → 內容 → 選項 | 點選項、點畫面跳過打字 | 打字機、角色表情同步、特殊反應 |
| 2.5D 小島 | 世界層 | 角色 > 互動物件 > 環境 | 點地面走路、點物件互動、雙指縮放 | 樹搖、水波、雲影、日夜與天氣 |
| 世界地圖 | 疊層 | 地點 → 路線 → 地點資訊卡 | 點地點、點「出發」 | 地圖展開轉場、路線繪製 |
| 多地點探索 | 世界層 | 地點名稱卡（進入時 2 秒） | 同小島 | 地點名稱淡入、天氣切換 |
| 建築室內 | 世界層（固定鏡頭） | 房間、家具 | 同小島；進入佈置模式 | 進門時屋頂淡出 / 鏡頭推入 |
| 物品與背包 | 底部表單 | 分類 → 格子 → 數量 | 點看詳情、長按拖曳到角色/地面 | 拿起放大、拖曳時表單下沉、角色注視 |
| 商店 | 全頁或表單 | 店主 → 商品 → 價格 → 購買列 | 點商品、點購買 | 金幣滾動、物品飛入背包 |
| 家具佈置 | 世界層＋底部工具列 | 格線、可放置提示 | 拖曳、旋轉、收回 | 可放=綠框，不可放=紅框＋輕抖 |
| 換裝 | 全頁（類創角） | 角色 → 部位 → 衣物 | 點選、拖曳顏色 | 換上時角色轉一圈 |
| 繪畫工坊 | 全頁（畫布） | 畫布 → 工具 → 顏色 → 圖層 | 單指畫、雙指縮放平移、長按吸色 | 壓感筆刷、撤銷波紋 |
| 逐幀動畫工作室 | 全頁 | 畫布（含洋蔥皮）→ 影格列 → 播放 | 畫、新增/複製/刪影格、拖曳排序、播放 | 播放時預覽循環、影格彈入 |
| 任務 | 底部表單 | 進行中 → 可領取 → 已完成 | 點任務看路線 | 完成蓋章 / 打勾 |
| 生活目標 | 檔案 / 表單 | 目標 → 進度 → 獎勵 | 點目標 | 進度條、達成慶祝（短） |
| 技能 | 全頁 | 技能樹/清單 → 等級 → 解鎖 | 點技能看說明 | 升級時角色學會新動作 |
| 收藏圖鑑 | 全頁（網格） | 類別 → 已收集/未收集 | 點看詳情 | 新收藏閃一下（僅一次） |
| 遊戲設定 | 全頁（清單） | 顯示/效能/聲音/桌寵/帳號/資料 | 開關、滑桿 | 標準切換動畫 |
| Android 懸浮桌寵 | 系統疊加視窗 | 角色本身＋偶爾的小對話泡 | 拖曳、點擊、長按 = 選單（回到遊戲 / 收起） | 擺盪、落地、走路、睡覺 |

## 2. HUD 規格（三方案共通的位置與數量）

```
┌───────────────────────────────┐
│ [時間·天氣]             [金幣] │  ← 上方：只顯示「狀態」，不放按鈕
│                               │
│            （世界）            │
│                          [⋯]  │  ← 選單（次要）
│ [頭像+心情環]     [地圖] [背包] │  ← 下方：所有「動作」在拇指區
└───────────────────────────────┘
```
- 常駐元件 ≤ 6 個；任何新功能都進入「⋯」選單或情境按鈕（靠近物件時才出現），**不得新增常駐 HUD**。
- 對話、創角、拖曳時 HUD 自動淡出（A/C）或收起（B）。

## 3. 圖示規格
- 設計網格 24×24（A/C 向量）或 9×9 / 12×12（B 像素），視覺尺寸 16–24dp，**觸控熱區至少 48dp**。
- 線寬：A 1.9 單位圓角；C 2.0 墨線＋內填色；B 1px 外框＋2 色填色。
- 每個圖示只用一個隱喻；同一概念全遊戲只能有一個圖示（例如「背包」不能有兩種畫法）。

## 4. 使用者流程（第一階段已在影片示範）
`開場 → 小島（HUD）→ 創角 → 檔案 → 對話事件 → 地圖 → 新地點 → 背包餵食 → 商店 → 動畫工坊 → 開啟桌寵 → 回到桌面`
