# 15.4（0.15.4-alpha）剩下的頁面

把 15.1 計畫裡還沒重新設計的四個頁面做完。參考作品只取設計原則；版面、圖示、配色都是原創。

| 頁面 | 之前 | 現在 |
|---|---|---|
| **創角的外觀（大舞台）** | 角色在一個小框裡，下面是一長串要一直往下捲的設定 | 上面是一個打了燈的大舞台（聚光燈、地板光圈），下面一排分類貼紙（範本、耳朵尾巴、顏色、臉、服裝、〔詳細模式〕體型、部件、表情），**一次只顯示一類**。點角色的耳朵／臉／身體／尾巴會跳到那一類 |
| **設計亭**（工坊新工具） | 沒有 | 畫 12×12 的圖樣：手指畫線（快速移動也不會斷——會補上中間的格子）、填滿、9 種顏色（含透明）、復原／重做、清空；畫的時候上面的角色就穿著它；「儲存圖樣」「穿上」（選要試穿的角色）。草稿自動保存；沒存就按離開會先問；從外面關掉（返回鍵、換分頁）不問、草稿留著。圖樣很小（144 個數字），存在存檔裡，不是圖片 |
| **地圖** | 點地點只會在下面出現卡片 | 從你現在的位置到選的地點畫出一條會走動的虛線，路上標「約 N 分鐘」（和真的移動時間相同）；「前往」鈕也寫出時間；你所在的地點標「你在這裡」 |
| **桌寵中心** | 一整頁很長 | 分成三頁：「桌面」（誰去桌面、啟動）、「互動與效能」、「權限與工具」；上面的預覽變成一支手機的主畫面，角色站在 App 圖示前面 |

## 修正
- **設計亭的無限迴圈**（開發時發現）：設計亭被「從外面關閉」時（例如切換分頁會一直關掉最上層的視窗），如果還有沒存的筆畫，它會跳出「要離開嗎？」——而那個關閉的動作又把這個問題關掉、設計亭再問一次……無限重複，記憶體在幾秒內用完、頁面當掉。現在從外面關閉時不問（草稿本來就會保存），只有按設計亭自己的返回鍵才問。
- 設計亭格子一開始被全域的 `.empty` 樣式撐大（格子變成 60×134），改用自己的類別名稱。
