# 擴充計畫：全面盤點與開發計畫（第十五節）

依據：玩家在 2.0.0-rc.1 之後提供的〈全面性重構、系統擴充與遊戲內容深化計畫〉。文件列了 30 個主要方向（01～30）、6 條設計原則（A～F）和額外的 20 項（31～50）。

完整的 50 項版本（整合版規格）已收到，39～50 項已補進下面的盤點與各階段。

這份文件分三部分：
1. 盤點：現在做到哪裡、哪裡有問題；
2. 和已確認方向的衝突，以及我的處理方式；
3. 分階段計畫：優先級、依賴、修改範圍、做法、驗收標準。

### 4. 已知問題（要在第一階段處理）
1. **文字被截斷**（#05）：清單、人物卡紀錄、訊息、吐司、泡泡的長文字會被「…」切掉。
2. **猜拳與躲貓貓**（#07）：要從玩家選單移除。
3. **聊天建議是固定的**（#07）：每次都一樣。
4. **設定分散**：好讀好用、桌面設定、畫面品質在不同地方。
5. **手機上全部沒有驗證**：觸控、效能、耗電、桌寵、小工具。這要等你的實機回報，`device-checklist.md` 仍然有效。

### 5. 架構評估
- **好的地方**：
  - 一個模擬、一個時鐘、只用自己的亂數，所以結果可重現；
  - 每個系統有自己的模組（`Society`、`Drama`、`WithYou`、`Days`、`TownLife`…）；
  - 存檔有 17 步遷移，每一步都有測試；
  - 介面用截圖比對測試。
- **要改的地方**（為了文件要的「加一種互動不必改程式」）：
  - 互動、事件、心情、家具、台詞現在寫在 Kotlin 程式碼裡。要做到 200 種互動、200 個事件，又能讓玩家匯入，需要**一套統一的內容資料格式**。
  - 這套格式要能寫條件（時間、天氣、地點、家具、性格、關係、心情、技能、物品、前置事件）和結果（數值、記憶、後續事件），由一個引擎解讀。
  - 現有的劇本系統（M5 的積木）是這個方向的雛形，會升級成這套格式，舊的 `.ocmod` 照樣能讀。
  - 這是第三階段的基礎，所以放在第一、二階段。

## 二、和已確認方向的衝突，以及我的處理

1. **3D 場景（#04）**：
   - 已確認的方向是「2D 分層插畫、斜俯視」，而且全部原生 Kotlin、沒有遊戲引擎、連不上 Google 的套件庫。
   - 文件要 low-poly 3D 立體透視模型（Diorama），角色維持 2D。
   - **我的做法**：在現有的繪圖層上自己做一個小型的 3D 投影：
     - 家具、建築、樹改成真正的多邊形模型（有厚度、面的明暗、陰影）；
     - 固定斜俯視鏡頭，依深度排序後畫出；
     - 角色維持 2D 圖，站在 3D 場景裡，有接地陰影和遮擋。
   - 不用 OpenGL 或引擎，所以手機和測試畫出來會一樣。
   - 風險：中低階手機的效能。會接上效能分級，並在第五階段做壓力測試。
   - 這是最大的一項，放在第五階段，前面的資料與玩法不受影響。

2. **未成年角色（#19，整合版仍要求暗戀、初戀、害羞牽手）**：
   - 規則是「未成年絕不涉及戀愛」，這一條**不改**。
   - 未成年角色會有**友情**的青梅竹馬劇情：一起放學、分享秘密、交換小禮物、互相打氣。
   - 不會有暗戀、初戀、牽手這類戀愛內容。整合版第 19 項仍要求這些；這一條我不會做，理由是遊戲內任何浪漫框架都不套用在未成年角色身上，這是專案既有的規則，也是我不會越過的界線。
   - 戀愛、婚姻仍然只限兩位成年角色，而且要戀愛打開。

3. **移除小遊戲（#07）**：
   - 我會把**玩家直接啟動的**猜拳、躲貓貓、接點心、翻牌都從選單移除，因為文件寫的是「猜拳、躲貓貓**等**獨立小遊戲」。
   - 住民之間自己玩猜拳的場景會保留，那是生活的一部分。
   - 如果你想留下接點心或翻牌，告訴我，可以馬上放回來。

4. **商店店員與 NPC（#17、#26）**：
   - 現在只有你的角色住在世界裡。
   - 店員會是原創的小鎮角色：只在店裡、有台詞和樣子，但**不會**有自己的生活模擬，也不會搬進家裡。
   - 你的角色仍然是世界的主角。

5. **版本號**：
   - 2.0.0 正式版仍然在等你的實機回報與金鑰。
   - 這份計畫的每個階段出一個 Debug 版：2.1.0、2.2.0…2.8.0。

## 三、分階段計畫

每個階段完成時都會做這些事：
- 全部測試；
- 看過每一張截圖；
- 建 APK；
- 寫一份報告，列出做到的、沒做到的、改了哪些檔案、只能在手機上驗證的；
- 提交並推送。

### 第一階段（2.1.0）盤點與基礎修復
| 工作 | 做法 | 驗收 |
|---|---|---|
| #05 長文字 | 介面元件改成自動換行，高度跟著內容長：清單列、底單、人物卡紀錄、訊息、吐司、泡泡、資訊卡；真的放不下的區域可以捲動 | 測試掃過所有畫面，重要的字不再出現「…」；長文字截圖看過 |
| #07 移除小遊戲 | 選單、人物卡、和你頁拿掉四個小遊戲；存檔裡的最高分保留但不顯示 | 選單裡找不到；住民之間的猜拳仍會發生 |
| #07 聊天建議 | 依情境產生：心情、最近發生的事、共同朋友、煩惱、興趣、天氣、時間、你們的關係、他記得的事 | 同一個角色在不同情境下的建議不同（測試） |

| 設定整合 | 一個設定頁：畫面、聲音、遊戲、資料四類；每一項都真的有效果 | 每項設定都有一個「改了看得到差別」的測試 |

### 第三階段（2.3.0）互動與內容資料庫
- **內容量**：用第一階段的格式寫：
  - 互動 200 種以上（個人、雙人、多人，每種有自己的條件和結果）；
  - 日常事件 100 個以上；
  - 特殊劇情 100 個以上；
  - 心情小卡 100 張以上；
  - 聊天話題 100 個以上。
- **#06 聊天泡泡**：
  - 平常只出現心情泡泡和話題字卡；
  - 點開看摘要，再點看完整對話。
- **#33 蝴蝶效應**：
  - 事件可以接下一個事件；
  - 誰看到、誰去關心、誰提議，由在場的人和關係決定。
- **#32 秘密**：分種類；會被保守、分享、意外發現、揭露；影響信任。
- **#35 傳聞**：分親眼見到、聽說、猜測、已確認；有來源和可信度；只有真的聽說過的人才知道。
- **#42 小動作**、**#46 糗事**：依性格擴充；糗事會變成笑料、綽號（#43）和聊天話題。
- **#50 故事線引擎**：故事線＝有階段的資料（開始條件、參與者、每階段的觸發條件、分歧），每一步仍由角色自主行為推動；現有的連續劇、夢想、戀愛線搬進來。
- **#12 自訂事件編輯器**：
  - 所有欄位都能設；
  - 有預覽、條件測試（「現在這個世界裡誰會觸發」）、格式檢查、重複 id 檢查；
  - 可以啟用、停用、一鍵匯入匯出；
  - 匯入失敗不碰存檔。
- **驗收**：
  - 內容數量由測試計算；
  - 每個事件都通過驗證器；
  - 60 天模擬中觸發的種類達到一定比例，而且沒有一個事件獨佔。

### 第四階段（2.4.0）家具與生活
- **#16 家具資料庫**：約 60 種；耐久、清潔、升級、自訂顏色、套裝、房間主題、專屬房間。
- **#09 家具互動**：
  - 電腦：上網、遊戲、寫作、線上聊天、接案、學習；
  - 電話、電視頻道、音響類型、廚房、書架都有多種用法；
  - 每種用法有自己的效果。
- **技能**：約 20 種技能、成長曲線、技能之間的關聯，接到家具和職業。
- **#18 職業**：5 類 25 種以上；條件、時間、薪水、事件、升遷、壓力、轉職、兼職。
- **#23 飲食**：「味道勾起回憶」、更多料理、一起做菜。
- **#44 紀念物**：物品的情感價值（和售價分開）；拿起、看到時想起送的人或那次旅行。
- **#15 首頁常駐背包**：浮動的小背包；把東西拖給角色、拖到地上擺家具，三種拖曳不會互相誤判。
- **#17 商店重製**：
  - 有店面展示、店員、稀有度、搜尋篩選、收藏清單、折扣、限時商品；
  - 至少 6 種店。

### 第五階段（2.5.0）世界與視覺
- **#04 3D 場景**：做法見第二部分。
  - 家具、牆、地板、建築、樹改成多邊形模型；
  - 柔和光、陰影、遮擋；
  - 角色融入場景。
- **#08 環境細節**：電視、電腦、手機畫面、音響、魚缸、壁爐、植物擺動、窗外天氣、腳步。
- **#11 動畫**：統一的動作系統，加擁抱、握手、拿取、交付、跺腳、遮臉、跳躍、被嚇到、慶祝；轉身、坐下、站起都要接得順。
- **#10 小劇場**：獨立演出模式，有鏡頭、字幕、表情、配樂、停頓；部分可以選擇。
- **驗收**：
  - 效能分級三級都有截圖；
  - 壓力測試（10 個角色＋60 件家具）的每幀繪製量在預算內；
  - 實機效能要你回報。

### 第六階段（2.6.0）社交與長期玩法
- **#19 關係**：
  - 關係種類擴充到文件的清單（未成年見第二部分）；
  - 吃醋、婚姻、婚後生活；
  - 觀看用的關係圖：雙向、分群、縮放、搜尋、共同回憶。
- **#28 角色的手機**：角色之間傳訊息、群組、留言、行事曆、相簿。
- **#36 自動攝影**：特殊事件自動拍照，有各種相簿、標籤、時間軸。
- **#37 夢境、#38 願望**：夢與記憶、關係連動；分類的願望清單，角色自己努力，你可以幫忙。
- **#25 節慶**：更多節日、限定家具、服裝、食物、音樂。
- **#26 地圖**：13 個以上地點，各有場景、互動、收集物、聲音；探索解鎖。
- **#27 收集與製作**：昆蟲、魚、礦石、植物；配方、材料、技能、時間。
- **#29 長期目標**：隱藏解鎖、個人里程碑。
- **#24 天氣**：大風、日出日落；依天氣換衣服。
- **#41 社交圈**：形成、默契、內部衝突、成員變動、各圈自己的活動與話題。
- **#43 專屬稱呼**：小團體專用稱呼、糗事綽號、你自訂。
- **#48 私人傳統**：重複發生的共同活動會變成傳統（每週五看電影…），沒實現會失落；你也可以安排。
- **#13 角色離開**：專屬劇情，處理關係與回憶。

### 第七階段（2.7.0）介面打磨
- Minimalist 版面（#20）：首頁按鈕減到最少，資訊壓力降低。
- 完整設定系統、關係圖、商店、背包的最後打磨。
- 聲音與視覺回饋。

### 第八階段（2.8.0）全面測試與效能
- 多角色壓力測試、長時間測試（模擬 365 天）、記憶體增長檢查。
- 不同解析度的截圖、舊存檔相容性。
- 準備交給你做實機驗收。之後才是正式的 2.0／3.0 發行。
