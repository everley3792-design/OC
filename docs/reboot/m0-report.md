# M0（0.1.0-reboot）地基

依據：`docs/reboot/reboot-plan.md`（玩家已確認第十節的全部建議），里程碑 12.11 的 M0。

## 做了什麼

### 1. 舊版移出
- 舊的 `game/`（網頁＋three.js）、`prototype/`、`android/`、舊文件與舊交付物全部從工作目錄移除；
- 它們留在 git 歷史，最後一個舊版提交是 `d88e849`。
- 計畫要打標籤 `legacy-0.17.3`：本機有這個標籤，但這個環境的 git 代理只允許推送工作分支，**標籤推不上去**；所以 README 與 CLAUDE.md 都寫了提交編號。

### 2. 新專案骨架（全部 Kotlin，不依賴 AndroidX）

| 模組 | 內容 | 測試 |
|---|---|---|
| `core:sim` | `Rng`（SplitMix64：模擬唯一的亂數，依用途分流）、`GameClock`（現實時間／可加速的遊戲時間，永遠不倒退） | 5 |
| `core:save` | 收藏庫＋存檔兩層；原子寫入（壞掉時退回前一版）；每日備份保留 3 天；新增、繼續、改名、複製、分支（擲自己的骰子）、刪除；版本升級框架（比 App 新的存檔會拒絕並說明） | 8 |
| `render:api` | 所有畫面都畫在這個介面上（dp 單位） | — |
| `render:jvm` | Java2D 實作：在電腦上把畫面畫成 PNG（截圖測試用，不進 APK） | — |
| `ui` | 設計 tokens（白天／夜晚）、彈簧動態、元件（卡片、按鈕、圓鈕、清單選單、確認、提示、角色、頭像、圖示）、畫面堆疊與點擊區、存檔選單、開始新的觀察、M0 的世界畫面 | 5（含 7 張截圖比對） |
| `app` | Android 外殼：單一全螢幕畫面、Canvas 後端（硬體加速）、安全區、深色模式、返回鍵、輸入框、App 私有目錄的存檔 | 建置檢查 |

### 3. 畫面
截圖在 `deliverables/m0/`（電腦上的 Java2D 繪製；手機上用同一份程式，只有字型點陣化不同）。

- **觀察日誌（第一個畫面）**：
  - 天空、雲、草丘上的肉桂捲（會呼吸）；
  - 「開始新的觀察」；
  - 每個存檔一張卡：住民頭像、名字、第幾天、幾位住民、多久前玩過；
  - ⋯ 選單：繼續、改名、複製、分支、刪除（只有刪除會確認）；
  - 很多存檔時可以捲動。
- **開始新的觀察**：
  - 選住民（目前收藏庫只有肉桂捲；可以不選、也可以選很多位）；
  - 卡片上直接寫明「命名小鎮、選房型、安排房間在 M1；匯入或自己畫在 M2」，不假裝已經有。
- **世界（M0）**：
  - 住民站在房間裡呼吸；點牠會跳一下並顯示「肉桂捲看著你」；
  - 遊玩時間會記下，離開時存檔；
  - 畫面上寫明「家、需求與生活在 M1 製作」。

### 4. 肉桂捲
- 原圖保留在 `docs/reboot/cinnamon-roll.png`（玩家上傳的檔案，未修改）；
- `art/chars/cinnamon/original.png` 只裁掉四周的透明邊；
- `idle.png` 是 1024px 的工作圖（APK 只帶這張）；
- 定位依玩家指示：開新觀察時可以選的預設角色，不是引導員。

### 5. 字型
粉圓（Huninn）與 Nunito（SIL OFL，Google Fonts）：舊版的 WOFF 解開成 TTF（字形未修改），手機與電腦用同一份。

### 6. APK
- `deliverables/apk/oc-shimeji-0.1.0-reboot-debug.apk`（Debug 簽章，非正式發行版）；
- 套件名稱仍是 `app.ocshimeji`，versionCode **100**（比舊版的 43 大，可以直接覆蓋安裝；舊版的網頁存檔不會被讀取）；
- `verifyDebugApk` 檢查：簽章、targetSdk 35、versionCode 100、沒有無障礙服務或 `QUERY_ALL_PACKAGES`、APK 裡有 `classes.dex`、字型與肉桂捲的圖；
- 離線管線沿用：ProGuard 只改寫 lambda（`-dontshrink`）＋`checkNoIndy`。

## 驗證
- `gradle -PcoreOnly=true test`：**18 項全部通過**（core:sim 5、core:save 8、ui 5）。
- UI 測試用**點擊區**模擬手指：
  - 開新觀察 → 沒選人時沒有「開始」→ 選肉桂捲 → 開始 → 世界裡有肉桂捲 → 點牠 → 返回 → 存檔有遊玩時間；
  - 複製、分支、改名、刪除（確認後才刪）；
  - 選單剛出現 0.3 秒內不接受點擊、點外面關閉、返回鍵先關選單、第一個畫面按返回＝離開；
  - 九個存檔時捲到底。
- 截圖比對：7 張與核准的版本（`ui/src/test/resources/golden/`）比對，平均通道差 < 2。

## 和計畫的差別
- **渲染**：計畫寫的是 OpenGL ES 2.0。M0 先用**硬體加速的 Android Canvas**（同樣跑在 GPU 上，文字與圓角現成可用），放在同一個 `Gfx` 介面後面。如果之後的場景（很多角色、粒子）在手機上不夠快，再換成 GL 實作，畫面程式不用改。
- **舊版標籤**：推不上去（見上）。

## 沒有做／只能在手機上驗證
- **手機上全部沒有驗證**：
  - 能不能正常安裝、開啟（特別是不同 Android 版本）；
  - 安全區（瀏海、手勢列）的位置；
  - 觸控與捲動的手感、震動回饋；
  - 深色模式切換；
  - 改名的系統輸入框；
  - 耗電：第一個畫面有呼吸動畫，現在以全幀率繪製；M1 會加上靜止時降幀。
- 用的是硬體加速 Canvas，效能還沒量。
- 存檔匯出／匯入（`.ocsave`）、備份還原的介面、收藏庫頁面：在 M1／M2。
- 開場流程（命名、房型、房間、關係、入住日）：M1。

## 請你在手機上試（M0）
1. 安裝 APK（如果裝過舊版但簽章不同，要先解除安裝舊版）；
2. 打開：第一個畫面的字、肉桂捲、按鈕有沒有被瀏海或手勢列擋住；
3. 開始新的觀察 → 選肉桂捲 → 開始 → 點肉桂捲 → 左上返回；
4. 存檔卡的 ⋯：改名（會跳出系統輸入框）、複製、分支、刪除；
5. 切換手機的深色模式，看顏色有沒有跟著變；
6. 按系統返回鍵：選單開著時先關選單，第一個畫面時離開 App。

有任何閃退或畫面怪怪的地方，截圖或描述給我。
