# M7 第一批（1.0.0-beta.2）：補完 M6、1.0 的第一批項目

依據：
- `docs/reboot/m6-report.md`「和計畫不同的地方、沒做的」；
- 計畫 12.11 的「M7 → 1.0」：第十一、十二、十三節標「1.0」的項目，共 74 項。

這一版先把 M6 沒做完的補上，再做 1.0 的第一批：用現有系統就能做紮實的 19 項。剩下的列在最後，不假裝完成。

- **版本**：`1.0.0-beta.2`（versionCode 107）；**Debug 簽章，不是正式版**。
- **測試**：118 個全部通過（`core:sim` 69、`core:save` 33、`ui` 16，含截圖比對）。
- **手機上的部分全部還沒驗證**（這個環境沒有模擬器或實機）。

## 一、補完 M6 沒做的

| M6 沒做的 | 這一版 |
|---|---|
| 小鎮只是地圖、住民只有大頭像 | 小鎮畫面上的住民改成**全身**：路上用走路的姿勢，在地點時用那件事的姿勢（坐著喝咖啡、躺著看雲…），面向會跟著走的方向。它仍然是一張固定的插畫，不能走進去，見「還沒做的」。 |
| 咖啡館只有一句提示 | **咖啡館頁**：<br>・誰在那裡；<br>・今天的特調；<br>・「請在場的人喝一杯」（每人 8 星幣，經帳本；喝到的人心情變好、更親近你）。 |
| 環境分數沒有數字 | 佈置模式上方顯示你正在弄的房間：<br>・**一句房間個性**（「堆滿書的安靜房間」「綠意盎然的房間」…）；<br>・**整潔、好看、舒服**三個分數。 |
| 系列加成（G-04） | 同一個系列的自訂物品放在同一個房間，**好看分數會加分**。<br>第一次湊齊時，在家的人會說出來，並有閃亮特效、記進時間線。 |
| 貼紙不能貼在家裡 | 「貼紙」類的自訂物品可以**貼在房間的牆上**（最上面那一排），用你畫的圖；貼在地板上會說原因。 |
| 家具不能轉 | **翻面**：家具左右翻轉，可以復原。只是外觀，旋轉 90 度還沒做。 |
| 作品集沒有頁面 | **作品集頁**：<br>・做了幾個、賣出幾個、平均評分、最近的評語；<br>・**評語**：市集賣出時有客人的評語；住民在公共角落看到你的作品也會留一句。 |
| 季節音效只有雨聲 | 時段音樂底下加了季節的聲音（全部合成、原創）：<br>・春天早上、白天：鳥叫；<br>・夏天白天：蟬聲；<br>・秋天傍晚、晚上：蟲鳴；<br>・冬天：風聲。 |

## 二、1.0 的第一批（19 項）

### 生活與紀錄
- **A-12 角色日記**：
  - 每天早上，每個人把昨天最重要的幾件事寫成一篇日記，用自己的說話方式；
  - 「生活紀錄 → 日記」可以讀。
- **A-06 夢**：
  - 睡覺時，頭上的夢泡泡輪流出現當天發生的事的小圖示；
  - 醒來會講出夢的內容（「我夢到……然後突然……」），也記進時間線。
- **A-15 稱號**（14 種）：
  - 只依真實行為得到，例如煮 8 次飯＝小廚師、去 8 次小鎮＝小鎮通、澆 8 次水＝綠手指、收成 3 次＝菜園主人；
  - 得到時有特效、記進時間線；
  - 人物卡上顯示最新的稱號。
- **G-05 對佈置的反應**：
  - 你擺好一件家具，在家的人會說說看法；
  - 喜歡的（愛植物的人看到盆栽、愛看書的看到書架、你自己做的作品）心情會變好。
  - 「偶爾自己挪一下」沒做，避免改掉你的擺法。
- **P-10 房間個性**：
  - 每個房間依擺設和分數有一句描述；
  - 平均分數高的房間，住民比較愛待。
- **O-05 休息提醒**：
  - 連續玩一小時，在家的某個人會提醒你起來動一動、喝水；
  - 只是畫面上的話，不影響生活。

### 植物、菜園、採集
- **G-09 會長大的植物**：
  - 盆栽被澆水會長大：小芽 → 長大 → **開花**（開花時有事件）；
  - 三天沒人澆會**垂頭、變黃**，好看分數會扣；
  - 家具移動時，生長狀態跟著走。
- **G-10 菜園收成**：
  - 住民照顧菜園三次就收成一次：小番茄、紅蘿蔔、豌豆、南瓜，放進背包；
  - 這些可以餵給住民吃。
  - 「拿收成做料理」還沒接起來。
- **I-04 採集**：
  - 公園多了「撿東西」，雨天不去；
  - 依季節撿到野花、漂亮的石頭、橡實、野莓、紅葉、松果，放進背包；
  - 這些可以擺上市集攤位，或放到公共角落。

### 小鎮的日子
- **H-03 市集日**：
  - 每 7 天一次；
  - 雜貨店多 2 樣特別的商品（手工果醬、現烤麵包、蜂蜜蛋糕、醃黃瓜）；
  - 攤位比較好賣，住民比較常去廣場；新聞會寫。
- **H-04 原創節日**（每季一個，固定日期）：
  - 春：花瓣夜（4/15）；夏：螢火蟲祭（7/20）；秋：落葉祭（10/25）；冬：星燈節（12/20）。
  - 當天：
    - 新聞報導；
    - 傍晚住民會去廣場「逛祭典」，可以晚一點回家（21:30）；
    - 祭典限定的食物和**紙燈籠**（新家具：晚上會亮）。
- **Q-13 本週之星**：
  - 每週結算一次，選出這週最活躍的人，附上理由（「最常煮飯」「最常上街」…）；
  - 會上新聞、記進時間線，人物卡也會標出來。
  - 「廣場掛照片」沒做。

### 收集與統計
- **I-07 圖鑑**：
  - 食物、市集、菜園、公園、家具、祭典、小鎮事件、節日，共約 60 樣；
  - 四種狀態：沒見過（？）、聽說過、見過、擁有（打勾）；
  - 只由真實發生的事更新：買過、撿過、收成過就是「擁有」，小鎮事件發生過就是「見過」。
- **I-08 成就**（20 個）：
  - 例如一起過了一週、第一次上街、開張大吉、第一次收成、花開了、本週之星；
  - 只由真實行為累積，**你自己領取**，領了得到星幣（經帳本）。
- **K-07 統計小卡**：這週誰最常煮飯、聊天、上街、澆水…，還有這週最常在一起的兩個人。

### 好讀、好用
- **O-04 無障礙**（標題畫面右上角的按鈕）：
  - **大字**：所有東西放大 15%，重新打開 App 後生效；
  - **減少動態**：不畫雨雪粒子；
  - **震動**：關、弱、標準。
  - **色弱友善配色還沒做**。

### 這些東西在哪裡
- 錢包或布告欄 →「**生活紀錄**」：日記、稱號、成就、圖鑑、這週的統計、作品集。
- 小鎮 →「工坊委託」第一行也能進作品集。

## 五、只能在手機上驗證
- 季節的聲音：鳥叫、蟬聲、蟲鳴、風聲好不好聽、音量、循環接縫。
- 大字模式：每個畫面都放得下、沒有被切掉。
- 震動「弱」「關」在你的手機上有沒有差別（各廠牌的震動回饋不一樣）。
- 小鎮的全身角色、夢泡泡在中低階手機上的速度。

## 六、請你在手機上試（接著 M6 的清單）
1. 標題畫面右上角 → 打開「大字」，關掉 App 再打開：字和按鈕都變大，每個畫面都放得下。
2. 「減少動態」打開：下雨下雪時沒有粒子。
3. 「震動」切成關、弱：按按鈕時的震動跟著變。
4. 錢包 →「生活紀錄」：
   - 過一天後有日記；
   - 成就可以領，領了星幣增加（帳本有一行）；
   - 圖鑑會隨著買東西、撿東西亮起來。
5. 晚上看睡著的人：頭上有夢泡泡；早上醒來會說夢。
6. 讓住民澆水幾天：盆栽變大、開花；放著不管會垂頭。
7. 有菜園的房子（庭院平房）：收成的蔬菜出現在背包，可以餵。
8. 小鎮：
   - 住民是全身的，喝咖啡時坐著；
   - 點咖啡館 → 請客；
   - 公園撿到的東西出現在背包。
9. 佈置模式：
   - 上方顯示房間的一句話和三個分數；
   - 「翻面」；
   - 自訂的貼紙只能貼在牆上那一排；
   - 兩件同系列的作品放在同一間，會有人說「湊成一套」。
10. 季節的聲音：春天早上、夏天白天、秋天晚上、冬天，各聽一下。
11. 4/15、7/20、10/25、12/20（或把手機日期調過去）：
    - 新聞有節日；
    - 傍晚住民去廣場逛祭典；
    - 雜貨店有限定商品和紙燈籠。
