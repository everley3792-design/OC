# R5（1.5.0）美術與細節

依據：`docs/reboot/overhaul-plan.md` 的 R5（B-5 節、D 節，玩家已確認）。

- **版本**：`1.5.0`（versionCode 112），**Debug 簽章，不是正式版**。
- **測試**：145 個全部通過（`core:sim` 86、`core:save` 38、`ui` 21）。
- **手機上的部分全部待驗證**，尤其是效能（30 fps）。沒有模擬器或實機。

## 做了什麼

### 1. 物件狀態（V2）
每件家具會跟著生活改變樣子。全部由 `LifeSim.stateOf` 決定，家的畫面、桌寵、測試看到的都一樣。

| 家具 | 狀態 | 怎麼來的 |
|---|---|---|
| 床 | 整齊／有人睡／凌亂 | 睡過、午睡過→凌亂（被子掀開、皺起來、枕頭歪了）；有人「整理床鋪」→整齊 |
| 餐桌 | 空的／擺著飯菜（冒熱氣）／剩碗盤 | 鍋裡有飯、有人在吃→飯菜；有沒洗的碗→碗盤疊著；洗完→空的 |
| 落地燈 | 關／開 | 晚上（18:30～6:30）房間裡有人醒著→開，有暖色光暈 |
| 電視 | 關／節目 | 有人看 |
| 浴缸 | 乾／有水有泡泡 | 有人在洗 |
| 爐子 | 冷／煮東西冒煙 | 有人在煮 |
| 書架 | 整齊／書被抽出來 | 在書架看書、翻相簿，有時會抽出一本放在上面；整理房間→放回去 |
| 窗戶 | 開（窗簾拉開、微微飄）／關（窗簾拉上） | 依時段：6:30～20:00 拉開 |

- **會留下來的狀態**（凌亂的床、抽出來的書）存在 `Life.things`，重開 App 還在。
- **地上的東西**（`Life.litter`）：
  - 吃點心可能留下包裝紙，喝茶喝咖啡可能留下杯子，看書可能留下一本書；
  - 有人「整理房間」時，那個房間的東西全部收掉；
  - 最多 10 件；搬家具後擋路的會自動消失。
- 這些都用世界自己的亂數，同一個存檔每次一樣（測試會比對）。

### 2. 四層光（V3）
1. **天光**：清晨帶粉紅、傍晚帶橘色，下雨或起霧時整體偏灰。
2. **窗光**：白天窗戶在地板上投下一塊光：
   - 早上斜向一邊、下午斜向另一邊，跟著時間移動；
   - 晴天最亮，陰天、下雨、霧天變淡；
   - 光裡有灰塵在飄。
3. **燈光**：開著的落地燈有一圈暖色光暈，地上也有一片光。
4. **夜色**：照舊。

### 3. 材質（V1，部分）
- 木頭：餐桌、電視櫃、長椅有木紋和邊緣反光。
- 布：被子有布紋條紋。
- 冰箱：有反光和兩個磁鐵。
- 窗戶：有窗簾桿和窗簾皺褶；下雨時玻璃上有雨痕。

### 4. 室內小動態
- **牆上的時鐘**：在第一個有空牆的房間；時針、分針跟著遊戲時間走。
- 窗簾被風吹（減少動態模式時不動）。
- 窗光裡飄的灰塵。
- 熱飲冒熱氣：拿著杯子的人手上會冒熱氣。
- 看書會翻頁。

### 5. 室外（V5）
- **天空**：會飄的雲，晴天少、陰天雨天多，下雨時雲變灰。
- **遠山**：房子後面兩層淡淡的山丘，顏色跟著天色。
- **四季的樹**：

  | 季節 | 樣子 |
  |---|---|
  | 春 | 粉紅花 |
  | 夏 | 綠 |
  | 秋 | 橘紅 |
  | 冬 | 光禿的枝椏＋積雪 |

  冬天灌木叢上也有雪。
- **路燈**：在門前小路旁，晚上（18:00～6:30）亮，地上有一片光。
- **水窪**：下雨時草地上有水窪和漣漪。
- **地上的季節**：春天花瓣、秋天落葉、冬天積雪，散在房子四周。

## 和計畫不同的地方、沒做的
- **家具快取成點陣圖**：沒做。
  - 原因：畫面可以縮放（最多 2.8 倍），先畫成固定大小的圖，放大後會糊；要依手機的實際像素大小快取，需要繪圖介面提供「畫進一張圖」的功能，兩個後端（手機、測試）都要加。
  - 這版是直接畫更多細節。所以**效能更需要在手機上驗證**；如果中低階手機跑不到 30 fps，下一版優先做快取。
- **材質依日夜各一份**：沒做（跟快取一起）。
- **細節 40 項**：做了約 26 項（上面列的）。沒做的：
  - 角落的毛球被撞到會滾；
  - 脫下的拖鞋；
  - 雨天水窪的倒影（只有漣漪）；
  - 角色的「杯子放回桌上」「坐久了換姿勢」「被雨淋會甩頭」；
  - 小鎮的部分全部（見下）。
- **小鎮改成可以平移縮放的 2.5D 場景**：沒做。小鎮還是原本的畫面，連同立面、招牌、店員剪影一起移到 R7。
- **新圖示 30 個、空狀態插圖**：沒做，移到 R7。
- **快取記憶體上限 64 MB**：沒有快取，所以沒有這個問題。

## 只能在手機上驗證
- **效能**：家的畫面多了很多東西（雲、山、樹、窗光、灰塵、木紋）。請看中低階手機能不能維持 30 fps、會不會發燙。
- 窗光、燈光暈、黃昏色在手機螢幕上的顏色與亮度，會不會太淡或太刺眼。
- 晚上室外是否太亮。夜色只是加一層藍，路燈的光在亮的草地上不明顯。
- 減少動態模式下，窗簾、灰塵、雲是否真的不動。

## 請你在手機上試
1. 打開世界，切到遊戲時間 10×：
   - 看早上、中午、下午窗光在地板上移動；
   - 傍晚畫面帶橘色，晚上窗簾拉上、有人的房間燈亮、門外路燈亮。
2. 看住民起床後的床（凌亂），讓人「整理床鋪」（環狀選單 → 床 → 叫誰來整理床鋪）。
3. 吃點心、喝茶後，地上可能出現包裝紙或杯子；叫人「整理房間」把它收掉。
4. 環境面板：
   - 季節定在春、秋、冬，看樹和地上；
   - 選下雨，看水窪、窗上的雨痕、灰灰的天色。
5. 打開「減少動態」，確認東西不會一直晃。
6. 用一陣子，告訴我順不順、手機熱不熱。
