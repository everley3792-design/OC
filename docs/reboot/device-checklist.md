# 2.0.0 實機測試清單

正式版 2.0.0 之前，請在手機上照這份清單試一遍。這份清單把 M0～1.9.0 每份報告的「只能在手機上驗證」整理在一起。

計畫第 2.4 節要求 3 支不同等級的手機。至少一支低階或舊手機最好。

**回報方式**
- 每一項寫「好」或「有問題」；
- 有問題就寫手機型號、Android 版本、怎麼重現；
- 有截圖最好；
- 設定 →「畫面品質」那一行會寫這支手機被判成哪一級，請一起附上。

## 0. 先記下來
- [ ] 手機型號、Android 版本、記憶體（設定 → 關於手機）。
- [ ] 設定 → 畫面品質：「這支手機」被判成省電、標準還是高畫質？你覺得合理嗎？

## A. 安裝、存檔、升級
1. [ ] 從舊版覆蓋安裝：舊存檔自動升級，角色、關係、星幣、創作的東西都在。
2. [ ] 開新的觀察：取名、選房子（也試一個情境開局）、選人、安排房間、搬家日。
3. [ ] 匯出存檔再匯入：存到雲端硬碟或下載資料夾，再讀回來，內容一樣。
4. [ ] 關掉 App 幾小時再打開：「你不在的時候」摘要合理，時間沒有亂跳。
5. [ ] 改手機時區，或遇到日光節約時間切換：時間線的時間正確。

## B. 畫面、安全區、深色模式
6. [ ] 瀏海、手勢列、三顆按鈕導覽列的手機上，上方膠囊和底部導覽都沒有被擋住。
7. [ ] 深色模式切換：每個畫面的顏色都正常。
8. [ ] 大字模式：每個畫面都放得下、沒有被切掉。
9. [ ] 色弱友善配色：選取和提醒分得清楚。
10. [ ] 減少動態：雨雪、窗簾、雲、轉場真的變少或不動。

## C. 觸控手感（家）
11. [ ] 點住民打開環狀選單；靠邊時沒有被切到，文字沒有被手指擋住。
12. [ ] 摸摸（來回滑）、抱起來（按住）、丟出去：彼此不會誤判，力道自然。
13. [ ] 兩指縮放、拖空地平移，不會和摸摸混淆。
14. [ ] 拖曳給點心、佈置模式拖家具：手指上方的圖沒有被擋住，放開的位置準。
15. [ ] 長的底單、收納格子的捲動，有慣性、不會誤點。
16. [ ] 系統輸入框：改名、寫一句話、筆記、時光膠囊（彈出、取消、字數限制）。

## D. 效能與耗電（最重要）
17. [ ] 家的畫面放著 10 分鐘：順不順、會不會發燙。
18. [ ] 雨、雪、特殊天象（流星、極光、花瓣、雷雨閃光）：會不會掉幀；雷雨閃光會不會太刺眼。
19. [ ] 觀察模式 60×、快轉：會不會變慢或發燙。
20. [ ] 小鎮畫面放 10 分鐘的耗電；拖曳、縮放順不順。
21. [ ] 在設定裡把畫面品質切成「省電」：雨雪變少、雲變少，畫面最多每秒 30 幀，有沒有比較省電、比較涼。
22. [ ] 自動模式在慢的手機上：玩一陣子後「現在」那一級有沒有自己降下來。
23. [ ] 繪圖工坊在 1024×1024 畫布上畫畫：會不會卡；筆壓。
24. [ ] 大量影格（接近 600 格）的匯入角色：記憶體、順暢度。

## E. 匯入與創作
25. [ ] 選圖：系統選擇器、各家相簿 App；HEIC 這類解不開的格式會說明原因；很大的圖不會卡。
26. [ ] 多選檔案、ZIP、GIF、APNG、動態 WebP 的匯入。
27. [ ] 手指去背、點腳底和標記的準確度。
28. [ ] 匯入聲音並播放：角色的聲音、家裡的音樂（循環、離開時停止）。
29. [ ] `.ocpkg`、`.ocitem`、`.ocmod`（內容包工坊）的匯出與匯入。
30. [ ] 照片、名片「存成圖片」：PNG 打得開，在相簿 App 裡看起來和畫面上一樣。

## F. 聲音
31. [ ] 音效、聲線：音量合適、沒有爆音（部分廠牌的 `AudioTrack` 可能沒聲音，只會靜音，不應閃退）。
32. [ ] 依時段的音樂、季節的聲音：好不好聽、換曲和循環接縫。
33. [ ] 即興歌、主題旋律：和背景音樂一起時會不會太吵。
34. [ ] 震動的「關」「弱」「標準」有沒有差別。

## G. 桌寵（手機桌面）
35. [ ] 權限流程：說明卡 → 系統設定頁 → 回到 App 再按一次；Android 13 以上會詢問通知權限。
36. [ ] 懸浮窗的位置、大小、探頭；瀏海和手勢列；桌面旋轉後。
37. [ ] 拖曳跟手、甩出的力道、長按時間；追手指的圈會不會擋到底下 App 的按鈕（可以在設定關掉）。
38. [ ] 3 隻桌寵加 5 樣東西：會不會變慢、變熱。
39. [ ] 放一小時的耗電；睡覺時、螢幕關閉時是否接近 0。
40. [ ] 看影片或玩遊戲（全螢幕）時會不會躲起來。
41. [ ] 小米、華為、OPPO、三星等：服務會不會很快被關掉；關掉後回到 App，角色有沒有回家；「讓桌寵更穩定」的說明對不對。
42. [ ] 通知的按鈕（收回、讓手指穿過、恢復觸控）；專心計時的倒數每分鐘更新。

## H. 主畫面小工具
43. [ ] 長按主畫面 → 小工具 →「家裡的大家」：能加上去，大小對、文字沒被切掉、圖片正常。
44. [ ] 打開 App 再離開，小工具會更新；點它會打開 App。
45. [ ] 省電模式下，30 分鐘的更新會不會停（停了也只是顯示舊的，不應出錯）。

## I. 節奏（玩幾天再回答）
46. [ ] 泡泡、請求、決定、訊息：會不會太多（吵）或太少。
47. [ ] 故事（夢想、熱潮、八卦、比賽…）、傍晚出門、住民挪家具、旅行：頻率感覺如何。
48. [ ] 三種熱鬧程度的差別感覺得出來嗎。
49. [ ] 角色的個性差異在實際玩的時候看不看得出來（包含桌寵的性格）。

## J. 正式版需要你提供的
- 正式簽章：用 `OC_RELEASE_KEYSTORE`、`OC_RELEASE_STORE_PASSWORD`、`OC_RELEASE_KEY_ALIAS`、`OC_RELEASE_KEY_PASSWORD` 四個環境變數，執行 `gradle :app:assembleRelease`。
  - 金鑰只在你的電腦上，**絕不放進專案**。
- 以上清單的回報。2.0.0 會把每一項回報處理完再發。
