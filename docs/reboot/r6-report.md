# R6（1.6.0）桌寵重構

依據：`docs/reboot/overhaul-plan.md` 的 B-1 節與 R6，以及 `reboot-plan.md` 的 F-04～F-08（玩家已確認）。

- **版本**：`1.6.0`（versionCode 114），**Debug 簽章，不是正式版**。
- **測試**：170 個全部通過（`core:sim` 99、`core:save` 40、`ui` 31）。
- **存檔格式 v14**（`Migrate` 13 → 14）：世界多了「桌面上的東西」。
  - 舊存檔直接升級；測試檔是 `world-v13.json`。
- **桌寵的一切都只能在手機上真正驗證**：沒有模擬器或實機。這一版的測試只證明「邏輯不會卡住、規則有照著走」，手感、耗電、各廠牌的懸浮窗都要你試。

## 做了什麼

### 1. 三層結構（取代隨機權重）
全部在 `core:sim/desk`，純 Kotlin，有測試。

| 層 | 做什麼 |
|---|---|
| **驅動** | 每 0.5 秒讀一次：<br>・肚子、精神、想被理（跟家裡同一個人）；<br>・性格；<br>・時段、電量、充電；<br>・桌上的東西、其他桌寵、你的手指、專心計時 |
| **意圖**（有優先級） | 5 反射：被抓、被丟、掉下來、全螢幕躲起來<br>4 照顧：去吃桌上的點心、討東西吃、想睡、手機沒電陪你瞇一下、探頭提醒、陪你專心、休息時間<br>3 回應你：追著手指、被叫醒、被點<br>2 自己的事：回窩、澆花、看紙條、找朋友、靠過來看你、想要你理牠<br>1 閒晃：走、跑、坐、伸懶腰、爬牆、探頭、發呆 |
| **動作** | 每個動作一筆資料：<br>・樣子；<br>・最短／最長時間；<br>・誰可以打斷；<br>・要先做什麼（坐下前要先蹲）；<br>・之後可以接什麼（倒吊只能放手掉下來） |

- **新的意圖只有在優先級比現在高時才會打斷。** 例：
  - 肚子餓（4）會打斷閒晃；
  - 在牆上肚子餓：先放手掉下來，再走去吃（照轉移表）；
  - 睡覺（4）不會被朋友找（2）或你的手指（3）吵醒，但全螢幕（5）會讓牠躲起來；
  - 提醒（4）會等牠睡醒，因為「照顧只被反射打斷」（計畫的規則）。
- **轉移表**：動作只能沿著表走。
  - 要去的動作不能直接到時，會自動找最短的路，例：探頭 → 站好 → 蹲 → 坐下。
  - 每個動作都有路回到閒晃（測試檢查）。
- **資料化**：新增行為只要在 `DeskActs`（動作）、`DeskIntents`（意圖）、`DeskProps`（桌面東西）、`DeskTogethers`（一起做的事）加一筆。

### 2. 性格驅動
每一項都是 `Catalog` 裡的一筆效果，從角色的性格、標籤自動算出來：

| 效果 | 哪些性格 | 桌面上的樣子 |
|---|---|---|
| `desk:cling` | 黏人、有點黏人（獨立、害羞相反） | 常常走過來看你、看比較久；追手指追得比較快 |
| `desk:nest` | 獨立、懶散、害羞（黏人相反） | 常回窩裡待著 |
| `desk:climb` | 勤快、好奇、急性子（懶散、慢吞吞相反），加上「活躍」光譜 | 常爬牆、跑來跑去 |
| `desk:hide` | 害羞、社恐（好奇相反） | 全螢幕時更早躲；常從邊邊探頭 |
| `desk:social` | 健談（害羞、獨立、社恐相反） | 常去找其他桌寵 |

### 3. 跟著手指（F-04）
- 桌寵的視窗四周多了一圈 30dp 的空白。
- 手指按在這圈空白（不是按在牠身上）再拖，牠會追過來：
  - 遠的時候用跑的；
  - 追到時說「抓到你的手指了！」。
- 按在牠身上照舊：拖＝抓起來、來回滑＝摸摸、長按＝選單。

### 4. 桌面小物件（F-05）與窩（F-06）
- **放東西**：長按選單 →「放在牠旁邊」：點心、小毯子、小盆栽、紙條、窩。
  - 點心是背包裡的食物：放下時從背包拿出來，記在帳本「放到手機桌面」；收回時放回背包。
  - 桌面上最多 4 樣，加 1 個窩。
- **牠會去用**：

  | 東西 | 牠會… |
  |---|---|
  | 點心 | 餓了走過去吃掉，跟在家裡吃一樣：會飽，有喜不喜歡，也記成回憶 |
  | 小盆栽 | 自己去澆水 |
  | 紙條 | 自己去看，看完心情變好 |
  | 小毯子 | 睏了在上面睡 |
  | 窩 | 睏了回窩睡；獨立的角色沒事也會回窩坐著 |

- **移動與收起**：
  - 手指拖東西可以沿著地面移動；
  - 點兩下收起來；
  - 選單「收起桌上的東西」一次全收。
- 東西存在世界裡，關掉桌寵、重開 App 都還在。

### 5. 多隻互動（F-07）
最多 3 隻，依兩人的「喜歡」決定能做什麼：

| 一起做的事 | 喜歡至少 | 什麼時候 |
|---|---|---|
| 打招呼 | 不用 | 任何時候 |
| 追來追去 | 50 | 有精神的時候 |
| 一起坐著 | 60 | 任何時候 |
| 靠在一起睡 | 70 | 晚上或累的時候 |

- 先走去找對方，對方忙（睡覺、吃東西…）就會說不要。
- 做完記成兩個人的回憶，例如「和小雨在桌面上一起坐著」。
- 兩人熟悉一點、喜歡一點，照舊經過關係規則（`Society.relUpdate`）。

### 6. 陪伴模式（F-08）
- 長按選單 →「陪我專心 25 分」：
  - 桌寵走到旁邊坐著看書，不吵你（只會被全螢幕、被抓這種反射打斷）；
  - 25 分鐘到了：「休息一下！起來動一動吧。」，休息 5 分鐘；
  - 最多 4 輪；
  - 每一輪記成回憶「陪你專心了 25 分鐘」，牠也覺得被陪伴。
- 再按一次＝停止。做超過 5 分鐘的那一輪也會記下來。
- 原本的喝水、休息提醒（每 30／60／90 分鐘探頭）和深夜「早點睡吧」照舊。

### 7. 其他
- 每個動作的畫面更新率來自動作表：
  - 拖著 60；
  - 走路 30；
  - 坐著 6；
  - 睡覺 1；
  - 躲起來 0。
- 安全網：萬一某個動作超過它的最長時間，會讓牠落回地面（有計數；100 小時測試中一次都沒有發生）。

## 和計畫不同的地方、沒做的
- **小毯子、小盆栽、紙條、窩不用買**：它們是桌寵自己的東西，不經過背包。只有點心從背包拿、收回時放回（經 `Economy`）。計畫寫的「收回時帶回小鎮」只對點心成立。
- **跟著手指的範圍**：只有手指按在桌寵視窗四周那圈 30dp 時才會追。原因：Android 的懸浮窗不能接收螢幕其他地方的觸控，除非蓋一層全螢幕的透明層，而那是規則不允許的。
- **陪伴模式**：
  - 計時在桌寵服務裡；桌寵被系統關掉時計時也會停；
  - 通知列沒有顯示倒數。
- **多隻互動的動畫**：「一起坐著」「靠在一起睡」是兩隻並排做同一個動作，沒有專門的雙人姿勢（例如頭靠肩）。
- **自訂桌面動作**：資料表已經分開，但還沒有讓你在 App 裡自己加新動作的介面（要改程式裡的表）。
- **桌寵日記（F-12）、主畫面小工具（F-13）**：不在 R6 範圍，留給 R7。

## 只能在手機上驗證
- **全部的觸控手感**：
  - 按在旁邊拖（追手指）和按在身上拖（抓起來）會不會誤判；
  - 30dp 的空白圈會不會擋到底下 App 的按鈕。這圈也會吃掉觸控；如果太擾人，可以在下一版縮小或改成選單開關。
- 桌面東西的小視窗：
  - 位置是否剛好在螢幕最下面的地面上（各手機的導覽列高度不同）；
  - 拖動、點兩下收起好不好按。
- 3 隻 + 5 樣東西 = 最多 8 個小視窗＋泡泡：會不會讓手機變慢、變熱。
- 陪伴模式 25 分鐘的耗電：看書時每秒畫 4 次。
- 各廠牌（小米、華為、OPPO、三星）會不會在專心途中把桌寵服務關掉。
- 性格差異在真實使用中看不看得出來（測試是 6 小時的統計，實際使用通常短很多）。

## 請你在手機上試
1. 帶兩位住民到桌面（人物卡 → 桌面）。先在關係圖把他們設成好朋友。
2. 長按一隻 → 選單：
   - 放「窩」「小盆栽」「紙條」；
   - 有點心的話放「點心」。
3. 看一陣子：
   - 牠們會不會自己去澆花、看紙條、回窩；
   - 兩隻會不會去找對方打招呼、一起坐。
4. 手指按在一隻**旁邊**（不是身上）然後慢慢拖，看牠會不會追過來。
5. 長按 →「陪我專心 25 分」：
   - 牠會走到旁邊看書；
   - 用手機做別的事 25 分鐘，看會不會提醒你休息。
6. 拖桌面上的東西、點兩下收起來；選單「收起桌上的東西」。
7. 換一個「黏人」和一個「獨立」的角色，各放 30 分鐘，看看感覺有沒有不一樣。
8. 告訴我：
   - 會不會擋到你點其他 App；
   - 手機熱不熱、耗電多不多；
   - 有沒有被系統關掉。
