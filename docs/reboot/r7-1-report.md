## 二、R7 第一批：角色（10 項）
| 項目 | 做了什麼 |
|---|---|
| **A-08 夢想** | 創角時寫的夢想（例：「做出最好吃的蛋糕」）會對應到一件會累積的事（煮飯次數、看書次數、朋友數、去小鎮次數…），分 3 步：<br>・每一步說一句話、心情變好、記進時間線；<br>・最後一步「夢想實現了」，並寄信給你。<br>8 種夢想；認不出來的夢想＝「每天都過得開開心心」（數開心的日子） |
| **A-11 怕的東西** | 創角時寫的「怕的東西」：<br>・會真的發生：雷雨天打雷、停電的晚上、一個人在家、偶爾看到蟲；<br>・發生時會害怕、說話、頭上冒汗、記進時間線；<br>・有好朋友在家時會過來陪；你摸摸牠也算陪；<br>・陪 3 次以後就「克服了」，不再那麼怕 |
| **A-14 人生階段與生日** | 生日那天會問你：「要讓牠長大一歲嗎？」<br>・只有你說好才長大；不要就維持原本的年紀；<br>・滿 18 歲才算成年，未成年的規則照舊 |
| **B-09 生病與照顧** | 三種：<br>・淋雨感冒（下雨時在小鎮）：2 天；<br>・熬夜沒睡好（半夜 2～4 點還醒著）：1 天；<br>・吃太飽肚子痛（已經很飽還給點心）：1 天。<br>生病時不想做會動的事、想多休息；好朋友會來照顧（煮粥），被照顧兩次會早一天好。**不會變嚴重，也不會死** |
| **B-13 熱潮** | 偶爾突然迷上一件事（畫畫、跳舞、摺紙、唱歌、看雲、掃地…）1～2 天，做那件事的意願變成 2 倍。<br>好朋友（喜歡 ≥ 60）在同一個房間看到時，可能被傳染 |
| **D-02 突發奇想** | 偶爾一早宣布：「我決定了，今天開始我是偵探！」<br>・那一整天會說那個身分的話；<br>・8 種：偵探、公主、廚師、忍者、老師、探險家、詩人、管家 |
| **D-03 誤會劇場** | 3 個新的小劇：<br>・看到朋友和別人分我最愛的布丁；<br>・聽錯「搬走」；<br>・神秘的禮物謝錯人。<br>都會說開、和好 |
| **D-04 辯論大會** | 兩個人為一個話題吵起來（布丁要不要加焦糖、西瓜要不要加鹽、貓派狗派…8 題），**你當裁判**：<br>・判誰贏：贏的人得意、輸的人認輸；<br>・「都有道理」：兩人笑出來 |
| **D-05 即興歌曲** | 心情很好時在哼歌、跳舞、聽音樂，會即興唱一首：<br>・旋律自動生成（五聲音階），用角色自己的音高，每次都不一樣；<br>・有歌名，例如〈布丁在跳舞〉，記進時間線 |
| **D-08 如果問答** | 問題從 5 題加到 30 題（「如果可以變成一種食物…」「如果流星只實現一個願望…」）。<br>你的回答會被記住，之後偶爾提起：「你說過……的話會選『布丁』，我一直記得。」 |
| **N-04 角色主題旋律** | 每個角色有一段固定的 8 音旋律（依名字與音高產生）：<br>・跑到手機桌面上時播；<br>・生日派對時播 |

## 三、R7 第一批：社交（10 項）
| 項目 | 做了什麼 |
|---|---|
| **C-05 八卦網** | 重要的事（吵架、一起做了什麼）會變成消息，在朋友之間傳開：<br>・時間線寫「從誰那裡聽說：…」；<br>・傳著傳著可能走樣（「吵架」→「大吵一架」，「聊天」→「聊到半夜」）；<br>・被傳的人心情會差一點 |
| **C-07 綽號** | 很熟以後（喜歡 ≥ 70、熟悉 ≥ 60）會幫對方取綽號（小X、XX、阿X、X仔、X寶…）：<br>・說「以後叫你『X』好不好？」，之後都這樣叫；<br>・有設定暱稱的就用暱稱；<br>・你在創角時設的叫法永遠優先 |
| **C-08 共同秘密** | 很要好的兩人會有只有彼此知道的事（沙發底下的秘密基地、半夜一起偷吃的布丁…）。<br>之後在同一個房間時，偶爾會偷偷互看一眼，忍住不笑 |
| **C-09 小圈圈** | 三人以上互相都很熟，會自動組成小團體：<br>・有名字（「點心同好會」「深夜聊天社」…）；<br>・每週一次固定聚會 |
| **C-10 團體活動** | 7 種，都要人夠多才會發生：<br>・野餐（晴天中午）、睡衣派對（晚上）、營火（晴朗的晚上）、大掃除（家裡亂的時候，真的會變乾淨）；<br>・生日派對、停電講鬼故事、小圈圈聚會。<br>大家一起開心、互相更熟；畫面上方會出現「大家一起：野餐」。一天最多一次（生日和停電例外） |
| **C-13 對手與比賽** | 「好勝」的人一天會找人比一次賽：<br>・比吃、比跑、比腕力、比整理、猜謎、比誰先笑出來；<br>・依能力、個性、運氣決定輸贏；<br>・比了 3 次以後，兩人的關係多一個「對手」標籤 |
| **C-14 戀愛線** | **只在戀愛打開、兩人都成年時**：<br>・很喜歡對方（≥ 75）會慢慢心動，時間線先寫「看到他時，心跳好像快了一點」；<br>・兩人都很心動時問你：「要讓他告白嗎？」；<br>・你說好才告白、成為戀人；說「再等等」就不說。<br>關係改變照舊經過 `Relations.problem`。未成年、戀愛沒打開時**完全不會發生**（測試掃過 25 天） |
| **Q-08 料理對決** | 兩個會做菜的人（料理能力 ≥ 2 或美食家）各做一道菜，其他人試吃，依自己的口味投票 |
| **Q-09 停電颱風夜** | 雷雨的晚上（或偶爾）停電：<br>・家裡的燈都熄了；<br>・大家聚在一起點蠟燭講鬼故事；<br>・怕黑的人會害怕 |
| **Q-14 驚喜派對** | 生日前三天，其他人開始偷偷準備：<br>・你看得到（時間線、信箱）；<br>・壽星不知道。<br>生日當天派對時，壽星依個性反應：愛哭的會哭、害羞的說不出話、其他的大叫「我完全不知道！」 |

已經做過、這版不另外列的：Q-07 口頭禪傳染（1.5.1）。

## 四、你的決定
辯論的裁判、長大一歲、告白，都是**只有你能決定的事**：
- 你在看的時候：直接跳出選項；
- 你關掉了：先放著。家的畫面左上角會出現「有 N 件事等你決定」，點它再決定；信箱也有一封信；
- 你在看、但 6 個小時都沒選：採用比較溫和的選項（「都有道理」「維持年紀」「再等等」）。你不在的時候，它會一直等你。

## 和計畫不同的地方、沒做的
- **生日派對、團體活動的演出**：大家各說一句、心情和關係改變、畫面上方提示。沒有專門的「圍成一圈」站位或派對佈置（蛋糕、彩帶）的畫面。
- **料理對決**：菜是從 7 道裡選的，不是用菜園收成做的（I-03 料理與食譜在 1.9.0）。
- **主題旋律**：只在桌面出場與生日播；在家的畫面裡角色出場時沒有播。
- **戀愛線**：
  - 有心動 → 你同意告白 → 成為戀人；
  - 之後的約會、紀念日（J-04 在 1.9.0）、分手與復合還沒有演出。
- **八卦**：只有文字（時間線、說「聽說……」），沒有偷聽的泡泡畫面。
- **怕的東西**：「很高的地方」還沒有會觸發的情境（桌寵爬牆時本來可以用，留給下一版）。

## 只能在手機上驗證
- **即興歌曲和主題旋律的聲音**：
  - 用合成的撥弦聲，音量、好不好聽；
  - 和背景音樂一起時會不會太吵。
- **故事出現的頻率**：
  - 在手機上實際玩幾天，會不會太多（吵）或太少（感覺不到）；
  - 測試只能數次數，感覺要你判斷。
- 決定的選單在你正在做別的事（例如佈置）時跳出來，會不會打斷你。
- 通知的專心倒數在各廠牌手機上會不會每分鐘更新。

## 請你在手機上試
1. 創角第 6 步（喜好）最下面寫「夢想」和「怕的東西」（例：打雷）。打開世界，人物卡「現在」頁會看到夢想和怕打雷。
2. 環境面板選「雷雨」，看牠會不會怕、會不會有人來陪；摸摸牠。
3. 多觀察幾天（遊戲時間 30×）：
   - 時間線裡的熱潮、突發奇想、綽號、八卦、小圈圈、比賽、野餐；
   - 有人在爭論時當裁判。
4. 把一位住民的生日設成明天：
   - 三天前看看大家有沒有偷偷準備；
   - 生日當天決定要不要讓牠長大一歲。
5. 打開戀愛，讓兩位成年住民很要好，等「要讓他告白嗎？」。
6. 桌面：
   - 去雜貨店買小毯子、小盆栽，放到桌面再收回來，看背包；
   - 在桌面設定把「追手指」關掉；
   - 專心計時中把服務從通知收回再放出來，看倒數有沒有接著算。
7. 告訴我歌好不好聽、故事會不會太多或太少。
