## 1-2. 怎麼在「純 2D＋極簡」裡融合

- **畫面的主角是房子和角色**：平常只留兩樣東西。
  - 上方一條細的**時間／天氣膠囊**，點開是環境面板（inZOI）；
  - 下方 5 個入口的**導覽列**。
  - 其他（現在左右兩排浮動圓鈕）全部收進導覽列或環狀選單。
- **互動從「點東西」開始**（Sims）：點角色、家具、地上的東西、窗戶、天空，都打開同一套環狀選單；不再「點角色＝人物卡」。
  - 人物卡變成環狀選單裡的「看看他」。
- **觀察的節奏**（角色觀察屋）：
  - 每件小事都變成一行**有旁白的回憶**（時間、動作、擬聲、一句旁白、多久）；
  - 回憶可以**回放**（1×～1024×）、可以收藏；
  - 這是觀察系的核心樂趣，優先度最高。
- **創角像一場表演**（Tomodachi）：
  - 創角畫面的中間永遠站著角色；
  - 每改一項，牠就用新的口吻說一句、做一個動作。
- **材質與時間感**（AC）：
  - 2D 家具從「幾何圖形」升級成**有陰影、紋理、狀態**的插畫物件；
  - 光線分成：天光、窗光、燈光、夜色四層，依時段和天氣混合。

## B. 系統架構重構方案

### B-1. 桌寵：分層狀態機（取代隨機權重）

**三層結構**（全部在 `core:sim/desk`，純 Kotlin、可測）：

1. **驅動層（Drives）**：
   - 每 0.5 秒算一次「想做什麼」的分數；
   - 分數來源：需求（從家裡同一個 `Person` 來）、心情、性格（`Catalog` 效果）、時段、電量、玩家互動。
2. **意圖層（Intents，有優先級）**：

   | 優先級 | 意圖 | 例 |
   |---|---|---|
   | 5 反射 | 被抓、被丟、掉落、全螢幕要躲 | 立刻打斷任何事 |
   | 4 照顧 | 討食、想睡、低電量時陪你 | 只被反射打斷 |
   | 3 回應你 | 被摸、被叫、手指靠近（F-04 跟著手指） | 打斷 2 以下 |
   | 2 自主 | 去用桌面物件、找另一隻、窩回去睡（F-06） | 打斷 1 |
   | 1 閒晃 | 走、坐、伸懶腰、探頭 | 隨時可被打斷 |

3. **動作層（Actions）**：
   - 每個動作是一筆資料：`進入條件、可被哪個優先級打斷、過渡動作（坐下要先蹲）、最短／最長時間、結束後接什麼`；
   - 用**轉移表**檢查，不能從「倒吊」直接跳到「坐下」，一定經過「落下」。

**桌面物件框架**：
- `DeskProp(id, 種類, 位置, 能提供什麼)`，例如飯糰＝吃、毯子＝睡、小盆栽＝澆水、紙條＝讀、窩＝回去睡；
- 角色用和家裡一樣的「物件廣告」方式感知與選擇；
- 物件可以拖、可以收（F-05），收回時經 `Economy` 回到背包。

**性格驅動**（每一項都是 `Catalog` 的一筆效果）：
- 黏人＝靠近你的時間長；
- 獨立＝常回窩；
- 好動＝多爬牆；
- 怕生＝陌生 App 全螢幕時更早躲。

**擴充**：
- 動作、意圖、物件都是資料表（`DeskActs`、`DeskIntents`、`DeskProps`）；
- 加新動作＝加一筆資料＋（可選）動畫名稱；`DeskTest` 會檢查每個動作都有路回到閒晃。

**驗收**：
- 每個意圖都能被正確的優先級打斷；
- 100 小時模擬中沒有卡死的狀態；
- 不同性格的分布有明顯差異（測試量化比較）。

### B-2. 自主／操控＋全物件環狀選單

**互動登錄表**（`core:sim/act/Interactions`，資料化）：

```
Interaction(
  id, 名稱, 分類（社交／照顧／玩／生活／物件／你）,
  對象種類（角色、家具種類、地上的東西、窗、門、天空、地板）,
  條件（時段、需求、關係、戀愛規則 Relations.problem、天氣…）,
  執行者（你直接做／請某位角色做）,
  結果（經 LifeSim／Society／Economy 的既有函式）
)
```

- 現有的觸碰、餵食、聊天、建議、社交 44 種、物件活動 40 種**全部轉進這張表**；
- 目標**第一版 150 個互動**。
- **環狀選單**（`ui/PieMenu`）：
  - 點任何東西，打開以它為中心的圓形選單：最多 8 片，超過的分到第二層「更多…」；
  - 第一層是**分類**，第二層是**指令**；
  - 不能做的指令會變灰，並寫出原因（例如「睡著了」「戀愛沒打開」）；
  - 長按＝直接做第一個指令；
  - 選單出現後 0.3 秒內不接受點擊（沿用 `Dim.GUARD`）。
- **兩種模式**：
  - 上方膠囊旁有一個切換：**觀察**（AI 全自主）／**操控**；
  - 操控時，選中的角色腳下有一圈標記，指令進**看得到的佇列**（右下角，最多 5 個、可以一個一個取消）；
  - 沒有指令時，角色照樣自主（「半自動」）。
  - 每位角色可以分開設定（沿用 observe／suggest／command）。
- **人物卡**：
  - 改成環狀選單的「看看他」；
  - 分成 3 頁：現在、關係、紀錄，不再一頁塞滿。

**驗收**：
- 每個互動在條件不符時一定有原因；
- 環狀選單在 360×640 的螢幕上不出界；
- 指令佇列存檔後讀回一樣；
- 原本的觸碰手勢（摸、抱、丟）保留，不和點擊衝突。

### B-3. 角色創建、世界編輯、說話與稱謂

**創角流程**（取 Tomodachi 的原則，內容原創，7 步）。中間永遠是角色，每一步改完牠都會反應：

1. **外觀**：匯入／畫／預設＋配件貼紙（見 D1）；取景、腳的位置。
2. **基本**：名字、怎麼稱呼自己、年齡（未成年規則不變）、生日、代表色。
3. **聲音**：音高、速度、音色，**按一下就試聽**一句。
4. **個性光譜**：5 條滑桿（外向、活潑、認真、坦率、溫柔）；拖的時候角色的表情跟著變，旁邊顯示「這樣的人會…」。
5. **性格與職業**：
   - 職業分「現代、古風、奇幻、自訂」；
   - 性格最多 10 個，分社交、脾氣、起居、做事四色；
   - **互斥的兩個用 × 連起來**（話多×社恐、早起×夜貓、潔癖×邋遢），選了一邊，另一邊變灰。
6. **喜歡與不喜歡**：
   - 一個標籤點一下＝喜歡、再點＝不喜歡、再點＝取消；
   - 各最多 10 個，分日常、興趣、相處、食物。
7. **說話與稱謂**（新，見下）＋**自訂事件**（一句話＋頻率三段＋頭上泡泡圖示，接到現有劇本系統）。

**說話與稱謂系統**（`chars/Address`，新）：

| 設定 | 內容 |
|---|---|
| 叫你 | 依親近度分三段：陌生（例：你）→ 熟（例：自訂暱稱）→ 很親（例：自訂暱稱 2）；每段可以自訂 |
| 叫別人 | 對每一位住民可以設「怎麼叫他」與「對他的態度」（客氣、普通、撒嬌、嘴硬、敬重）；沒設的話，熟了會自己取綽號（C-07） |
| 自稱 | 已經有，保留 |
| 語氣 | 已經有（說話方式），加上**情緒風格**：開心時、生氣時、難過時各自怎麼說（例：生氣時變得很客氣） |
| 口頭禪 | 已經有；加**使用場合**（打招呼、驚訝、結尾）與頻率；常在一起的人會互相傳染（Q-07） |
| 禁用詞 | 已經有，保留 |

- 全部經 `Speech.say`：先換稱謂、再套語氣、再加口頭禪；
- `SpeechTest` 會檢查每一種組合都說得出完整的句子。

**開始畫面的編輯入口**：
- 標題畫面的每個存檔卡加兩個按鈕：
  - **編輯世界**：名字、房子、住民、關係、戀愛開關、時間模式；
  - **編輯角色**：直接進該存檔的角色創建頁。
- 不用打開世界就能改。
- 改住民或房子時，會先檢查房客規則、未成年規則，並先做備份。

### B-4. 時間、天氣、季節控制

**環境面板**（點上方的時間／天氣膠囊）：

| 控制 | 內容 | 怎麼保持確定性 |
|---|---|---|
| 時間模式 | 現實／遊戲 | 已有 |
| 流速 | 1×、10×、30×、60×；暫停 | 已有，暫停是新的 |
| 跳到時刻 | 早上、中午、傍晚、晚上（只在遊戲時間） | 記一筆「你把時間撥到 X」；中間的時間用補算 |
| 天氣 | 自動／晴／陰／雨／霧／雪／**特殊天象**（流星雨、極光、櫻花雨、雷雨） | `Life.env` 存「今天的天氣被你改成 X」；`Weather.of` 先看這筆 |
| 季節 | 自動（照日期）／鎖定某一季 | 同上；節日依「季節＋日期」 |
| 回到現在 | 一鍵讓時鐘對回手機時間 | 修 T1 |

**反映到畫面與生活**：
- **光影**：四層光（見 B-5），依時刻與天氣混合；
- **聲音**：時段音樂＋季節聲音（已有），加雷聲、雨打窗；
- **角色**：
  - 怕打雷的會躲（A-11）；
  - 流星雨會有人許願（記進時間線）；
  - 下雪會去堆雪人（已有）。

**要先修的錯誤**：
- **T1**：切回現實時間時，時鐘要對回來：
  - 未來 → 現在：凍結到現實追上，或一鍵「回到現在」；
  - 過去 → 現在：補算。
- **T2**：時區與日光節約時間改用「日期＋時區規則」換算，換時區時記一筆。
- **T3**：遊戲日期和手機日期不同時，上方膠囊顯示「遊戲日期」。

**驗收**：
- 改天氣、季節後存檔讀回一樣；
- 同一個存檔、同樣的手動調整，結果完全相同（測試比對）；
- 有 T1、T2 的回歸測試。

### B-5. 2D 美術與細節

維持純 2D、斜俯視固定鏡頭；全部用程式繪製或內建原創圖，**不使用外部素材**。

**繪製管線升級**：
- 家具從「每幀畫幾何」改成「**第一次畫成點陣圖並快取**」，畫得起更多細節：
  - 木紋、布紋、金屬高光、陰影、描邊；
  - 依日夜各快取一份。
- **四層光**：
  1. 天光（時段色）；
  2. 窗光（白天從窗戶照進來的光斑，會隨時間移動）；
  3. 燈光（晚上燈附近的暖色光暈）；
  4. 夜色。
- 天氣改變天光的顏色與窗光的強度。

**物件狀態**（每件家具 2～4 種狀態，存在 `Life`，由活動改變）：

| 家具 | 狀態 |
|---|---|
| 床 | 整齊／有人睡／凌亂（起床後，整理後變回整齊） |
| 餐桌 | 空的／擺著飯菜／剩碗盤（洗碗後變乾淨） |
| 燈 | 關／開（晚上有人在房間就開） |
| 電視 | 關／節目（有人看） |
| 浴缸 | 乾／有水有泡泡 |
| 書架 | 整齊／有書抽出來放在旁邊 |
| 窗 | 開／關、窗簾開／合（依時段） |
| 爐子 | 冷／煮東西冒煙 |

**細節清單**（第一批 40 項）：
- **室內小動態**：時鐘指針會走、窗簾被風吹、杯子冒熱氣、灰塵在窗光裡飄、角落的貓毛球被撞到會滾。
- **地上的東西**：住民吃剩的包裝、看到一半的書、脫下的拖鞋，被整理時才消失。
- **室外**：
  - 天空有雲在飄、遠方有山或城鎮剪影；
  - 四季的樹（春花、夏綠、秋紅、冬枯＋積雪）；
  - 路燈晚上亮，雨天地上有水窪倒影；
  - 落葉、花瓣、雪花會堆在地上。
- **角色的小動作**：喝東西時杯子放回桌上、看書會翻頁、坐久了換姿勢、被雨淋會甩頭。
- **小鎮**：改成可以平移縮放的 2.5D 場景；地點有門可以點、有招牌、有店員剪影（不是 NPC，不會互動）。

**驗收**：
- 新舊畫面的截圖並排比較；
- 中低階手機（實機）30 fps；
- 快取記憶體上限 64 MB。

## C. UI／UX 設計規範

### C-1. 視覺方向：極簡、留白、主角是世界
- **顏色**：
  - 沿用 `Theme` 的暖色系，但面板改成**半透明奶油色＋柔和陰影**，飽和度降低；
  - 強調色只用一個（主要動作）；
  - 分類色（社交綠、脾氣紅、起居橘、做事藍、戀愛粉）只用在標籤上。
- **字**：標題 20、內文 15、說明 13，行高 1.5；大字模式全部 ×1.15（已有）。
- **元件**：只保留這些，其他一律不做：
  - 按鈕（主要、次要、文字）；
  - 膠囊標籤；
  - 卡片；
  - 底單（半屏、全屏）；
  - 對話框；
  - 環狀選單；
  - 吐司；
  - 分段切換。
- **每個畫面最多一個主要按鈕**（已有的規則）。

### C-2. 底部導覽（5 個入口）

| 入口 | 圖示 | 內容 |
|---|---|---|
| **家** | 房子 | 觀察畫面（預設）；在家時再點一次＝回到全景 |
| **小鎮** | 小房子群 | 小鎮場景 |
| **住民** | 兩個人 | 名冊、關係圖（像參考截圖的狀態流動圖）、創角、角色卡 |
| **收納** | 包包 | 背包（有物品圖的格子）、家具、作品集、帳本、圖鑑 |
| **紀錄** | 書 | 時間線＋**回放**、名場面收藏、日記、相簿、統計、成就 |

- **上方只留**：時間／天氣膠囊（點開是環境面板）、觀察／操控切換、錢包（小）。
- **創作工具**（繪圖、動畫、物品、聲音、劇本）從「住民」與「收納」裡的「新增／製作」進入，也保留在標題畫面。
- 觀察模式（30×、60×）時導覽列自動收起，點一下畫面就出現。

### C-3. 收納系統（Inventory）
- **格子版面**：每格有物品圖、數量、新的標記；分頁為食物、家具、作品、撿到的、全部。
- **點一格**：底單顯示大圖、說明、來源（帳本那一行）；可以做的事依種類列出：
  - 給誰吃、擺到家裡、放上攤位、放到公共角落、送給誰。
- **拖曳**：從收納拖到家裡＝擺放（佈置模式自動打開）；拖到角色身上＝給他。
- 所有進出照舊經 `Economy`，帳本一致。

### C-4. 彈出視窗系統（Modals）

| 種類 | 用在 | 規則 |
|---|---|---|
| 半屏底單 | 選項、物品詳情、角色快看 | 可以**捲動**（取代翻頁，修 U7）；往下拉可關 |
| 全屏底單 | 創角、紀錄、收納 | 上方有拖曳把手與關閉 |
| 對話框 | 只有無法復原的事（刪除） | 已有規則 |
| 環狀選單 | 點任何東西 | 以點的位置為中心，不出界 |
| 吐司 | 一句話的結果 | 2 秒，可以點掉；不擋按鈕（移到上方） |

- 同時最多一個底單＋一個吐司；
- 底單打開時，世界畫面**變暗但繼續動**。

### C-5. 動態與微互動規範

| 動作 | 時間 | 曲線 |
|---|---|---|
| 按下 | 立即下沉 2dp | 放開時彈回（`Spring` 剛性 600、阻尼 28） |
| 底單打開／關閉 | 280ms／200ms | 開：ease-out-back（回彈 4%）；關：ease-in |
| 環狀選單 | 每片延遲 18ms 依序長出，總長 220ms | ease-out-back |
| 畫面推進／返回 | 240ms | 新畫面從右滑入 24dp＋淡入；返回相反 |
| 導覽切換 | 180ms | 交叉淡化，不滑動（避免暈） |
| 數字變化（星幣、分數） | 400ms | 數字滾動 |
| 得到東西 | 物品圖從發生的位置飛進導覽列的「收納」 | 弧線 500ms |

- **減少動態**模式：上面全部改成 120ms 淡入淡出，不回彈、不飛。
- 每一種都寫成 `Dim`／`Motion` 的常數，UI 測試檢查沒有寫死的數字。

### C-6. 參考截圖裡值得學的版面原則（不照抄畫面）
- 步驟指示放在最上面，**已完成的打勾**，目前那步用強調色。
- 標籤分類用**顏色**而不是標題；互斥用「×」連起來。
- 選房子的卡片：平面圖＋「最多住 N 人」＋2～3 個情境標籤。
- 回憶一行＝時間＋頭像＋一句話＋擬聲＋斜體旁白＋持續時間；名場面用淡黃底＋星號。

## E. 新舊版本過渡策略

- **存檔**：
