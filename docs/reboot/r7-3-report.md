## 和計畫不同的地方、沒做的
- **小鎮仍是一張可以平移縮放的圖**，不能讓角色走進店裡。
- **家具不能旋轉 90 度**（只能左右翻面）：要改家具佔的格子、座位位置和所有家具的畫法，留到之後。
- **旅行**：沒有旅行地的畫面，只有出發、回來和時間線上的事。
- **相框**：畫的是照片的「樣子」（人數、時間、濾鏡），不是縮小的照片本身。
- **小工具**：只有一種大小的版面；不會即時更新，只在離開 App 和每 30 分鐘時更新。
- **戀愛線**：約會有了；分手與復合還沒有演出。
- **效能分級**、**內容量達到 13.5 的目標**還沒做。

## 只能在手機上驗證
- **主畫面小工具**：
  - 各家啟動器能不能加上去、大小對不對、文字有沒有被切掉；
  - 圖片顯示正常嗎；點它能不能打開 App；
  - 30 分鐘的更新在省電模式下會不會停。
- **色弱配色**：實際看起來分不分得清楚。
- **傍晚出門、住民挪家具、旅行**的頻率：玩幾天後會不會太多或太少。

## 請你在手機上試
1. 長按主畫面 → 小工具 → 找「OC Shimeji / 家裡的大家」放上去；打開 App 再離開，看小工具有沒有更新。
2. 家具店買「回憶相框」掛到牆上，先拍一張照片，看相框和住民會不會去看。
3. 小鎮 → 更多 → 一日小旅行：早上選兩個人去海邊，傍晚回來看收藏櫃、相簿、動態牆。
4. 菜園收成或公園撿到東西後，看食譜頁；吃飯時間看看會不會做新菜。
5. 和你 → 神明的小道具：晚上用「流星」。
6. 設定 → 打開「色弱友善配色」。
7. 傍晚用遊戲時間加速，看有沒有人去看星星。
