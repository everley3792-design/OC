# R2（1.2.0）導覽與彈窗

依據：`docs/reboot/overhaul-plan.md` 的 R2（第十四節，玩家已確認）。

- **版本**：`1.2.0`（versionCode 109），**Debug 簽章，不是正式版**。
- **測試**：128 個全部通過（`core:sim` 75、`core:save` 35、`ui` 18）。
- **手機上的部分全部待驗證**（沒有模擬器或實機）。

## 做了什麼

### 1. 底部 5 個入口（D3）
家的畫面、小鎮、住民、收納、紀錄的底部都有同一條導覽列：

| 入口 | 內容 |
|---|---|
| 家 | 觀察畫面 |
| 小鎮 | 小鎮場景 |
| 住民 | 每個人在做什麼、心情、稱號；有煩惱或請求會標出來；點一個人＝人物卡；可以進關係圖、收藏庫與創角 |
| 收納 | 有物品圖的格子（見下） |
| 紀錄 | 時間線與信箱、回憶回放、日記、稱號、成就、圖鑑、統計、作品集 |

- 切換入口時一律先回到家，所以「返回」永遠回家，不會越疊越深。
- 紅點：
  - 「紀錄」＝新信件＋可以領的成就；
  - 「住民」＝有煩惱或請求的人。
- 觀察模式與佈置模式時，導覽列會收起來，讓出畫面。

### 2. 家的畫面變乾淨了
以前左右兩排有 6 個浮動圓鈕，現在只剩：
- 返回；
- 中間一個**時間／天氣膠囊**：天氣圖示（有天空色的底）、時間、第幾天、遊戲日期、速度、暫停；點它就是環境面板；
- 右邊的觀察鈕；
- 下面一行錢包。

原本的按鈕都搬到新的地方：

| 原本的按鈕 | 現在在 |
|---|---|
| 信箱 | 紀錄 → 時間線與信箱 |
| 壁紙地板音樂 | 收納 → 壁紙地板音樂 |
| 小鎮 | 底部「小鎮」 |
| 擺家具 | 收納 → 擺家具，或點一件家具 → 擺到家裡 |

### 3. 環境面板（D4，計畫 B-4）
點時間膠囊打開，面板可以捲動：

| 區塊 | 可以做的事 |
|---|---|
| 時間 | 現實時間、遊戲 1×／10×／30×／60×、**暫停** |
| 撥到 | 早上 7 點、中午、傍晚、晚上（只有遊戲時間；中間的時間照樣補算）；**回到現在** |
| 今天的天氣 | 自然、晴、陰、雨、霧、雪；**特殊天象**：流星雨、極光、花瓣雨、雷雨 |
| 季節 | 跟著日期，或定在春、夏、秋、冬 |

- 每一個改變都記在存檔（`Life.env.changes`）和時間線上，同一個存檔重開一樣。
- **特殊天象**：
  - 畫面上：流星劃過、極光的光帶、飄落的花瓣、雷雨的閃光；
  - 生活上：雷雨算下雨，流星雨、花瓣雨算晴天，極光算陰天；
  - 在家的某個人會反應，例如對流星許願、被雷聲嚇到，並記進時間線。
- 規則：
  - 只有冬天會下雪，可以先把季節定在冬天；
  - 現實時間不能撥時刻；
  - 減少動態模式下，花瓣和流星不會動。

### 4. 收納（計畫 C-3）
- **格子**：每格有物品圖、名字、數量；分頁為全部、食物、家具、作品、撿到的。
- **物品圖**：約 40 種內建物品各有自己畫的圖（布丁、飯糰、草莓、紅蘿蔔、野花、沙發、盆栽…）；你的作品用你畫的圖。
- **點一格**：大圖、說明、有幾個、來源（帳本最後一筆）。依種類可以：
  - 給誰吃；
  - 擺到家裡（直接進佈置模式，並選好那件）；
  - 放上市集攤位；
  - 放到公共角落。
- 上方捷徑：帳本、壁紙地板音樂、擺家具、圖鑑。

### 5. 彈窗與動態（計畫 C-4、C-5）
- 半屏底單可以捲動：環境面板和長清單都是（R1 已有）。
- **畫面轉場**：
  - 往前：從右邊滑入 24dp＋淡入，240ms；
  - 返回：從左邊；
  - 切換底部入口：交叉淡化，180ms；
  - 減少動態模式：全部改成 120ms 淡入，不滑動。

### 6. 存檔 v9（`Migrate` 8 → 9）
- 新增 `Life.env`：
  - 每一天你選的天氣；
  - 鎖定的季節；
  - 暫停；
  - 改變紀錄。
- 舊存檔：跟著日期走，沒有暫停。
- 測試檔：`world-v8.json`。

## 驗證
- **`EnvTest`**（3 個）：
  - 天氣與季節：雪只在冬天、雷雨算下雨、有人注意到打雷、可以回到自然、存讀檔後一樣；
  - 暫停與撥時間：暫停時時間不動、撥到 18 點、現實時間不能撥；
  - 確定性：同樣的改變跑兩次，時間線一字不差。
- **`WorldTest`**：v8 存檔升級。
- **UI 測試 `navigationEnvironmentAndStorage`**：
  - 環境面板：選花瓣雨、定在冬天、暫停（時間真的停）、取消暫停，每一步都有紀錄；
  - 收納：格子、點布丁 → 給誰吃 → 少一個、分頁只顯示家具；
  - 底部入口：住民、紀錄、回家，畫面堆疊不會越疊越深；
  - 帳本一致。
- 舊的 UI 測試改成走新的入口（例如「信箱」改成 紀錄 → 時間線與信箱）。
- 截圖全部看過後重新記錄；新截圖在 `deliverables/r2/`。
- APK：`deliverables/apk/oc-shimeji-1.2.0-debug.apk`。
  - `verifyDebugApk` 通過：versionCode 109。

## 和計畫不同的地方、沒做的
- **拖曳**：計畫寫「從收納拖到家裡擺放、拖到角色身上給他」，這版還沒做拖曳，是用「點一格 → 擺到家裡／給誰吃」。拖曳和環狀選單一起在 R3 做。
- **吐司**：沒有移到上方，也還不能點掉，仍在下方。
- **數字滾動、「得到東西飛進收納」的動畫**：沒做，放到 R5 和美術一起做。
- **UI 測試情境**：目前 18 個大情境，裡面有 40 多個檢查；計畫目標的 30 個情境還沒到，R3 繼續補。
- **人物卡**：還是一頁。分成三頁要在 R3 和環狀選單一起做。

## 只能在手機上驗證
- 底部導覽在有手勢列、或有三顆按鈕的手機上的位置與高度（安全區）。
- 轉場是否順、會不會有一瞬間點錯位置（轉場中的點擊區在動畫結束後才完全對齊）。
- 特殊天象（流星、極光、花瓣、雷雨閃光）在中低階手機上的速度；雷雨閃光會不會太刺眼。
- 收納格子的捲動手感。

## 請你在手機上試
1. 打開舊存檔：家的上方只剩返回、時間膠囊、觀察鈕、錢包；下方是 5 個入口。
2. 點時間膠囊：
   - 試試暫停、撥到傍晚（先切到遊戲時間）；
   - 選流星雨、雷雨、花瓣雨、極光；
   - 定在冬天後選下雪。
3. 收納：
   - 點一個食物 → 給誰吃；
   - 點一件家具 → 擺到家裡；
   - 換分頁。
4. 住民：
   - 有煩惱的人會標紅；
   - 點一個人看人物卡；
   - 關係圖。
5. 紀錄 → 時間線與信箱、回憶。
6. 在不同入口之間切換幾次，再按返回：應該都回到家。
7. 打開「減少動態」，再切換畫面：沒有滑動，只有短短的淡入。
