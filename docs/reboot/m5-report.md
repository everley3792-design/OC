# M5（0.6.0-reboot）創作套件

依據：`docs/reboot/reboot-plan.md` 12.6、12.11 的 M5（繪圖工坊、動畫工作室、自訂物品編輯器、壁紙地板、音樂與聲音匯入、`.ocitem`、空間使用頁），以及 13.9 加進 M5 的項目：事件積木編輯器、文字劇本格式、劇本包匯入、標籤編輯器、網格變形。

**驗收（計畫）**：
- 復原／重做、草稿、離開提醒——**有，測試通過**；
- 匯入驗證的測試素材集——**有**（壞掉的草稿、不是 ZIP 的物品檔、看不懂的聲音、太長的聲音、壞掉的劇本包、看不懂的劇本行，都有測試，而且都會說出原因）。
- 手機上畫畫的手感、觸控筆筆壓、大畫布的速度、聲音播放——**這個環境沒有實機，還沒驗證**。

## 做了什麼

### 1. 繪圖工坊（`core:save/paint`＋`ui/PaintUi`）
- **畫布範本**：角色 1024、物品 512、壁紙 256、地板 256、貼紙 256、表情 512。
  - 壁紙和地板是**無縫拼接**的：筆刷畫到邊緣會從另一邊接回來，畫面上也會淡淡顯示旁邊的重複；
  - 存成壁紙前會檢查接縫，接不起來會提醒。
- **8 種筆刷**＋**4 種工具**：
  - 筆刷：鉛筆、沾水筆、馬克筆、噴槍、水彩、橡皮擦、填色、漸層；
  - 工具：滴管、選取。
- 每一筆先畫在遮罩上，再疊到筆畫開始前的圖層：
  - 同一筆來回塗，馬克筆不會越塗越深；
  - 一筆＝一步復原。
- **筆壓**：觸控筆的壓力會改變沾水筆的粗細，以及鉛筆、噴槍、水彩的濃淡。手指沒有筆壓，一律當成 1。
- **防手震**（關／輕／中／強）。
- **對稱**：左右、放射（份數可調）。
- **選取**：
  - 框選後可以移動、放大縮小、轉 90°、左右翻轉，都是一步復原；
  - 復原時，選取框也會回到原來的位置。
- **填色**：有容許範圍；無縫畫布會跨邊緣填色。
- **漸層**：顏色到透明，或兩種顏色。
- **滴管**取所有看得見的圖層。
- **調色盤**：24 色原創調色盤；可以存自己的色票；還有色相條和飽和／亮度方塊。
- **圖層**：最多 12 個。
  - 新增、刪除、排序、顯示／隱藏、不透明度、向下合併；
  - 可以把圖片匯入成新圖層；
  - **描圖底稿**：淡淡顯示，永遠不會被匯出。
- **復原／重做 100 步**：只記錄改到的範圍，總量超過 160 MB 時，丟掉最舊的步驟。
- **畫布操作**：
  - 一指畫；兩指平移、縮放、旋轉；
  - 第二根手指緊接著放下時，會取消剛開始的那一筆，不留復原步驟。
- **草稿**：
  - 每 20 秒自動存一次；
  - 用無損壓縮存每個圖層的像素，不需要手機的解碼器，打開時和存的時候一模一樣；
  - 有未存的變更就離開時，會問你：「存成草稿再離開」或「不要了」。
- **畫完可以**：
  - 匯出 PNG；
  - 存成新角色（自動找腳的位置）；
  - 存成某個角色的表情差分；
  - 做成物品的圖；
  - 存成壁紙或地板。

### 2. 動畫工作室（`ui/AnimStudio`＋`Studio`）
- **動作**：選 29 個動作之一；每個動作可以切換「用我的動畫／用系統的動作」。
- **時間軸**：
  - 每格各自的停留時間（20–5000 ms）；
  - 新增、複製、刪除、往前、往後；
  - 播放方式：循環、播一次、**來回**（兩端不重複）。
- **畫這格**：用同一套繪圖工坊畫。
  - **洋蔥皮**：前一格和後一格以淡淡的描圖層顯示，存的時候不會留在這一格裡。
- **腳底**：每一格有自己的腳底位置；「自動對齊腳底」會一次算出整個動作。
- **影格事件**：在某一格放腳步聲、匯入的音效，或特效（愛心、汗滴、怒氣、閃亮…）。在家裡播放到那一格就會發生。
- **整個動作**：
  - 左右鏡像；
  - 從別的動作複製；
  - **批次匯入**：一次選很多檔，依檔名分到各個動作，其他動作保留不動。
- **程序動作層**（呼吸、彈跳、擺盪）：可以個別關掉，家裡和桌寵都照這個設定。
- **預覽**：
  - 試播舞台，和「桌面預覽」（手機桌面底部的示意畫面）；
  - 在家裡的樣子，回家就看得到。
- **狀態機檢視**：列出每個動作現在用的是自己的動畫、借用哪一個，或是系統的程序動作。
- 換動作、離開時，還沒儲存會先問。
- 內建角色不能改，要先複製一份（和收藏庫的規則一樣）。

### 3. 網格變形（13.3，`Gfx.imageMesh`＋`Warp`）
- **對象**：只有一張圖的角色。
- **怎麼動**：有標「耳朵」「尾巴」「頭」的部位會各自動：
  - 耳朵偶爾抖一下；
  - 尾巴擺動，開心或被摸時擺得更快；
  - 頭輕輕歪向一邊，發呆和看東西時歪得多一點。
- **畫法**：
  - 手機上用 Canvas 的 `drawBitmapMesh`；
  - 測試用的 Java2D 把每一格用仿射轉換畫上去。
- 這不是骨架，只推動部位附近的網格點，其他地方不動。

### 4. 自訂物品（`Studio`＋`ui/ItemEditor`）
- **11 種**：家具、裝飾、食物、飲料、禮物、玩具、壁紙、地板、地毯、植物、貼紙。
- **圖**：正面（必要）、背面、側面，都可以畫或匯入。
- **依種類**：
  - 家具：佔地格子、互動位子（點格子輪流設定坐、躺、站）、提供的活動、系列；
  - 食物：口味、冷熱、飽足；
  - 禮物：喜歡它的人的喜好詞；
  - 共通：價格、說明。
- **存檔前驗證**：
  - 擋下的錯誤：沒名字、沒圖、口味不對、位子在格子外…；
  - 提醒：可以睡卻沒有躺的位子、有提供活動卻沒有位子、禮物沒寫誰會喜歡。
- **這一版真的用得到的**：
  - 食物和飲料會出現在人物卡的「給點心」裡，口味照角色喜好算；
  - 禮物會被角色挑來送給彼此；
  - 壁紙和地板可以貼在家裡的房間；
  - 家具的擺放要等佈置（**M6**），現在存在收藏庫，畫面上有寫明。
- **`.ocitem`**：匯出和匯入（ZIP：`item.json`＋圖片），壞檔會說原因。
- 還貼在某個家的壁紙或地板不能刪，會說貼在哪裡。

### 5. 佈置：壁紙、地板、音樂（家的畫面左邊的圖片按鈕）
- 每個房間可以換牆和地板（原本的，或你畫的），以 base dp 平鋪。
- **家裡的音樂**：從匯入的音樂裡選一首，打開這個家的時候循環播放，離開就停。

### 6. 聲音（`Sounds`＋`SoundsPage`）
- **格式**：WAV、OGG、MP3、M4A，從檔頭判斷。
- **限制**：最大 8 MB。
  - 時間上限：角色聲音 4 秒、音效 10 秒、音樂 5 分鐘；
  - WAV 和 OGG 會讀出長度；MP3、M4A 讀不出來，就不擋長度。
- **用途**：
  - 角色的聲音：設給角色後，牠說話時播你的錄音，取代合成的喃喃聲；
  - 音效：放在影格事件裡；
  - 音樂：當作家裡的音樂。
- 還有角色在用的聲音不能刪。

### 7. 標籤編輯器（13.9，`CustomTag`）
- 自己定義一個標籤的效果：
  - 16 種活動的加減分（0.2–3 倍）；
  - 沒事時會說的台詞、聊天話題、話題碰撞用的概念；
  - 會在意的情況（怕黑、怕吵、怕孤單、怕光、怕高、容易暈）。
- **怎麼生效**：
  - 角色的標籤裡寫上同樣的名字就生效；
  - 規則和內建標籤一樣，都經過 `Catalog.effects`；
  - 不能和內建的標籤或特質同名。

### 8. 劇本（13.3，`core:sim/script`＋`ui/ScriptUi`）
- **積木編輯器**，設定有：
  - 角色 A／B：任何人、某標籤、某特質、某個角色；
  - 時間、機率；
  - A 對 B 的好感範圍；
  - 需要和不能有的旗標；
  - A 的心情；
  - 特寫、冷卻天數、啟用。
- **積木**：
  - 台詞、動作、特效；
  - 結果：好感、信任、衝突、心動、心情小卡、記憶（恩情或記仇）、旗標；
  - **問你一個問題**：2–4 個選項，每個選項有自己的積木。
- **文字劇本格式**：
  - 例：`# 標題：…`、`[A] 台詞`、`@A 開心`、`!B 愛心`、`= 好感 B→A +3`、`? 問題`、`- 選項`；
  - 和積木互轉（測試確認轉來轉去內容不變）；
  - 也可以存成 JSON；
  - 寫錯會說**是第幾行**、哪裡看不懂，也會列出可以用的詞。
- **在生活裡**：
  - 符合條件的兩個人會像其他事件一樣走過去演出；
  - 結果經過同一套關係規則；
  - 旗標可以把好幾個劇本串成故事；
  - 有問題的劇本先在信箱和泡泡裡問你，2 小時沒回答就選第一個；你不在時直接用第一個。
- **規則**：
  - 劇本裡沒有任何可以執行的程式；
  - 和戀愛有關的劇本（有心動，或台詞裡有戀愛的詞），只會發生在兩位成年角色之間，而且那個世界要打開戀愛（有測試）。
- **`.ocmod` 劇本包**：
  - 匯出你的劇本（文字格式）和標籤；
  - 匯入前列出內容和需要的角色；
  - 你沒有的角色條件，可以改成「任何人」或你的某個角色。

### 9. 空間使用（P-16）
- 依角色、草稿、物品、聲音、備份、存檔列出大小。
- 可以清掉沒用到的檔案：
  - 刪掉的角色和物品留下的圖；
  - 被替換掉的影格；
  - 刪掉的聲音。
- 也可以刪除匯入時保留的原圖，工作圖會保留。

### 10. 其他
- **把創作帶進世界**：
  - 打開世界時，收藏庫的食物、飲料、禮物、標籤、劇本會複製一份到那個世界（`Studio.syncWorld`）；
  - 世界自己存一份，所以同一個存檔，結果還是相同。
- **存檔格式 v5**：`Migrate` 加了 4→5 的步驟（舊世界沒有任何創作），附 v4 測試檔。
- **入口**：
  - 收藏庫右上的「創作」；
  - 每個角色的選單裡有「動畫工作室」；
  - 家裡左邊的圖片按鈕是佈置。
- **介面**：
  - 長的選單會分頁（例如 29 個動作的狀態機），不會超出畫面；
  - 新增圖示：匯入、音符、眼睛、信封…，都是畫出來的形狀，不是字型符號。
- 版本 **0.6.0-reboot／versionCode 105**。

## 驗證
`gradle -PcoreOnly=true test`：**96 項全部通過**（模擬 51、存檔 31、介面 14）。

  - 畫的角色 → 動畫工作室：新增一格（有洋蔥皮）、畫、來回、影格事件、儲存、狀態機；

## 和計畫不同的地方、沒做的
- **選取**只有矩形，沒有套索；**漸層**只有線性。
- **動作分段**（13.3 的起手、循環、收尾）和**走路的情緒疊加**：不在 M5 的清單裡，排在 1.0。
- **預覽「在家裡」**：沒有另外做預覽畫面，回家就看得到；「桌面預覽」是示意圖，真正的桌寵要帶到桌面上才看得到。
- **工坊**（委託製作、市集攤位、作品集）、**價格與商店**、**家具擺放**：都需要小鎮和佈置，排在 **M6**。價格欄位已經可以填，物品編輯器有寫明。
- **其他編輯器**（12.6 的自訂台詞、自訂怪癖、自訂節日、房型編輯器）：不在 M5 的清單裡。標籤編輯器可以加台詞，部分代替自訂台詞。
- **劇本**：
  - 最多兩個角色（三人以上在 1.0）；
  - 「運鏡、音效、等待」積木還沒有（運鏡在 M4 也還沒做）；
  - YAML 子集沒做（文字格式和 JSON 都有）。
- **聲音**：
  - MP3、M4A 的長度讀不出來，所以不擋長度；
  - 音樂只在家裡的畫面播放；依時段換音樂（N-03）在 M6；
  - 桌寵不播放匯入的聲音。
- **網格變形**只用在單張圖的角色；有自己影格的動作照原樣播放。
- 改了收藏庫的創作之後，**下次打開那個世界時才生效**（畫面上有寫）。

## 只能在手機上驗證（這個環境沒有模擬器或實機）
- **畫畫的速度**：1024×1024 的角色畫布，每一筆都要把目前的圖層重新送到畫面。中低階手機可能會卡，需要你試；如果太慢，我會改成只更新畫到的那一塊。
- **筆壓**：觸控筆的壓力是否正確；手指一律當 1。
- **手勢**：兩指平移、縮放、旋轉的手感；第二根手指取消筆畫的時機是否合適。
- **`drawBitmapMesh`**：網格變形在手機上的樣子與效能。
- **聲音播放**：`MediaPlayer` 播放匯入的聲音、家裡的音樂（循環、離開時停止）、多個短音同時播放。
- **檔案選擇**：選聲音、`.ocitem`、`.ocmod` 的系統選擇器；匯出檔案。
- **文字編輯**：劇本的「文字」模式用多行輸入框，長文字的編輯體驗。

## 請你在手機上試（M5）
1. 安裝 `deliverables/apk/oc-shimeji-0.6.0-reboot-debug.apk`（Debug 簽章，不是正式版）。舊的存檔會自動升級。
2. 收藏庫 → 右上「創作」→ 繪圖工坊 → 新畫布「角色」：
   - 畫一隻角色，試試各種筆刷、對稱、圖層、復原；
   - 用兩指縮放和旋轉；有觸控筆的話試筆壓；
   - 「⋯」→ 存成新角色。
3. 收藏庫 → 新角色的「⋯」→ 動畫工作室：
   - 做一個 3–4 格的走路動作，開洋蔥皮畫，選「來回」，在某一格放愛心特效；
   - 儲存後回家看牠走路。
4. 創作 → 繪圖工坊 → 新畫布「壁紙」→ 畫好後「⋯」→ 存成壁紙；回到家，左邊的圖片按鈕 → 貼到房間。
5. 創作 → 自訂物品：做一個食物，回家在人物卡「給點心」餵牠。
6. 創作 → 聲音：
   - 匯入一段短錄音當角色的聲音，設給一位角色，聽牠說話；
   - 匯入一首音樂，在佈置裡設成家裡的音樂。
7. 創作 → 劇本：從範例改一個，用「文字」模式試著改；回到那個世界放著看會不會演出。
8. 創作 → 標籤：做一個標籤，加到某個角色的標籤裡，看牠的行為和台詞。
9. 創作 → 空間使用：看看大小，試試清理。
