## 還是沒做、或和計畫不同的
- **材質依日夜各一份**：快取依「淺色／深色主題」各一份，不是依遊戲裡的白天黑夜。夜色仍然是畫在整個畫面上的一層。
- **細節 40 項**：做到約 32 項。剩下的是小鎮裡更細的東西，例如住民在店裡的互動動畫、招牌的季節裝飾。
- **小鎮住民**：還是小鎮的五個地點，路線沒有變長；住民走在路上的動作和家裡一樣。
- **配件只在收藏庫的角色上**：世界裡的住民用的是收藏庫那份的配件，不能在世界裡單獨改。原因：外觀只來自收藏庫（D1）。
- **口頭禪傳染**：學會的口頭禪只在世界裡，不會寫回收藏庫的原版。

## 只能在手機上驗證
- **效能**：
  - 家具快取在手機上是否真的讓畫面更順；
  - 放大縮小時重畫一張的那一下會不會卡；
  - 64 MB 在低記憶體手機上會不會太多。
- 小鎮的拖曳與兩指縮放手感；手指從商店上開始拖時，是平移而不是點進商店。
- 吐司在上方是否擋到時間膠囊；兩行的長度在小螢幕上夠不夠。
- 拖曳給東西：手指上方的食物圖會不會被手指擋住；放開的位置準不準。
- 配件的位置在各種角色圖上是否合理（是按圖的比例放的）。
- 換時區：搭飛機或手動改手機時區後，打開 App 的時間線紀錄是否正確。

## 請你在手機上試
1. 打開世界：
   - 拿到星幣時看數字滾動；
   - 收納 → 布丁 →「拿到家裡，拖給誰」→ 把布丁拖到住民身上。
2. 小鎮：
   - 用手指拖、兩指縮放；
   - 把遊戲時間調到晚上，看窗戶和路燈；
   - 把季節定在冬天看樹。
3. 操控模式選一個人、排 3 件事 → 點第 3 件 →「提前」。
4. 收藏庫 → 自己的角色 → 外觀：
   - 加一個蝴蝶結，調大小；
   - 回到家看看。
5. 開始畫面 → 房子圖示：
   - 有人搬進來；
   - 有人搬出去；
   - 搬家。
6. 點一盞燈 →「關燈」；點窗戶 →「拉窗簾」；地上有包裝紙時點那一格 →「撿起來」。
7. 把手機時區改一下再打開 App，看時間線怎麼寫。
