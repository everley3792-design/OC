# 15.1（0.15.1-alpha）逐頁重新設計（第一批）

計畫的第二個版本：把頁面從「一般清單」改成有個性的場景。參考的是幾款生活模擬遊戲的**設計原則**；所有形狀、圖示、版面都是原創。

## 做了什麼

| 頁面 | 之前 | 現在 |
|---|---|---|
| 角色 | 一張張橫條卡片的清單、長按拖曳排序 | **晴日公寓**：屋頂、每位角色一間房，窗戶裡看得到角色（晚上窗戶亮燈、不在島上的角色變淡），門牌號、名字、正在做什麼、標籤；操控中的那間有黃框；最後一間是「空房間」，點了就新增角色。排序改在選項裡「往前／往後」 |
| 角色檔案 | 一般卡片 | **島民護照**：綠色的護照抬頭、編號（由角色 id 算出，固定不變）、照片框加上「晴日」印章 |
| 我的家（佈置模式） | 只能擺家具 | **牆壁與地板**：佈置模式的提示列多了「牆壁與地板」，6 種牆面、6 種地板（木頭與格子磚）、恢復原樣。是油漆，不花錢、不是物品；換了會在淡出淡入中重建房間，角色繼續做自己的事 |
| 商店的購買畫面 | 物品小圖＋說明 | **試衣間**：上方是操控中的角色。買衣服時角色直接穿著這件（用副本畫，買下並穿上之前角色本身不會變）；其他東西擺在角色旁邊，看得出大小與顏色搭不搭 |
| 設定 | 一長串區塊 | 最上面是 7 個**區塊方格**（外觀、效能、世界、生活、操作、資料、聲音），點一下捲到那一區 |
| 創角第一步 | 小圖示的清單 | 大張的**貼紙卡片**，選中的有黃框與圓點 |
| 佈置模式的提示 | 小泡泡（加了按鈕後擠成很高的一團） | 一條橫的提示列 |

（工坊的工具方格在 14.1 就做了。）

## 修正
- 15.0 的防誤觸擋太多：選單剛打開的 0.35 秒內，點選單**外面**也不會關。現在外面的新手指一律關閉，只有選單裡的按鈕要等（v10 的回歸測試抓到的）。
