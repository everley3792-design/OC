# Design System — 晴日島 Sunny Isle（第二階段）

風格：**Premium Minimalism**（極簡、留白）＋ 動物森友會式的柔和圓潤、玩具感按鈕 ＋ 曠野之息式的清楚資訊層級。
所有原則只取方向，所有圖形、圖示、版面皆為原創。

**唯一真實來源：`game/css/tokens.css`**。元件（`game/css/app.css`）只能使用語意 token，禁止寫死色碼
（例外：繪圖畫布的白紙、物品貼圖、3D 世界——它們是「畫作」不是介面）。

## 1. 主題

| 模式 | 說明 |
|---|---|
| 淺色 Light | 奶油底、暖棕文字、珊瑚／青綠／向日葵強調色 |
| 深色 Dark | **重新設計**的深藍灰底（不是反轉濾鏡）、奶油色文字、粉彩強調色 |
| 跟隨系統 System | Android 由原生回報（`OCApp.onSystemTheme`），瀏覽器用 `prefers-color-scheme` |

- 切換方式：只改 `<html data-theme>`，顏色以 240ms 交叉淡化；**不重建 DOM、不重載材質、不重設 3D 場景**。
- 開機前就決定主題（`index.html` 內聯腳本 + 原生 `Theme.OC.Launch` / `values-night`），避免白色閃爍。
- 設定持久化：存檔 `settings.theme` + 原生 `Prefs.themeMode`（原生值為準，因為它也控制啟動畫面）。
- **UI 主題與島上白天黑夜完全獨立**：深色 UI 可以搭配中午的島。

## 3. 字體與字級

- 介面：jf open 粉圓 Huninn（OFL）；數字：Nunito 800/900（OFL，tabular）。字型隨 App 打包，離線可用。
- 字級：11 / 12 / 14（內文）/ 16 / 19（頁標）/ 24 / 30。行高 1.45。WebView `textZoom=100`（版面以 dp 設計）。

## 4. 間距、圓角、尺寸

- 間距 4 / 8 / 12 / 16 / 20 / 24 / 32。頁面左右邊距 16。
- 圓角 10（小）/ 16（磚）/ 22（卡片）/ 28（表單）/ 999（膠囊）。
- 觸控：最小 48×48（`--touch`）；視覺較小的元件用透明熱區補足。
- 安全區：`--sat/--sab/--sal/--sar`，Android 由原生 `OCApp.setInsets(t,r,b,l)` 寫入。

## 5. 動態

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | cubic-bezier(.22,1,.36,1) | 進場、頁面 |
| `--ease-in-out` | cubic-bezier(.65,0,.35,1) | 退場、淡出 |
| `--ease-pop` | cubic-bezier(.34,1.16,.64,1) | 開關、徽章、表情（過衝 ≤ 6%） |
| `--t-fast` / `--t-base` / `--t-slow` | 140 / 240 / 380ms | 按壓 / 切換 / 頁面與表單 |

規則：只動 `transform`/`opacity`（不觸發排版）；同一元件不重新觸發進場動畫；
「減少動態效果」設定（與系統 `prefers-reduced-motion`）把所有過場縮成 1ms，世界的風也減弱。
3D 世界的光線、天氣切換用 τ≈1.6s 的指數趨近，沒有閃光、沒有鏡頭晃動。

## 6. 版面骨架

```
世界層（3D 固定視角，全螢幕）
HUD（≤ 6 個常駐元件）：角色膠囊｜時間・天氣｜金幣｜佈置｜快速背包 FAB｜(搖桿，選用)
底部導覽：小島・角色・工坊・探索・更多
頁面層：分頁頁面（蓋住世界）→ 推入的子頁（蓋住導覽列，左上返回）→ 底部表單 / 對話 / 提示
```
- 每頁最多 1 個主要（實心珊瑚）按鈕；主要操作在下方拇指區。
- 返回鍵／Esc 依序關閉：對話 → 表單 → 子頁 → 回到小島分頁 → 離開 App。

## 7. 圖示

24 格線條圖示（2px、圓頭），定義在 `game/js/ui/ui.js` 的 `IC`，全部原創。物品貼圖是彩色插畫（不隨主題變色，像貼紙）。
