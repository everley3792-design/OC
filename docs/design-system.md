# Design System — 14.0「島日和」

> **14.0 起整個 App 只有這一種風格。** 10.0「晴空玩具」、12.0「雅緻」、13.0「樂園」都已移除（沒有風格切換）。
> 下面「14.0」這一節是現行規格；再往下的 10.0 內容只保留仍然有效的部分（貼紙圖示、動態、頁面骨架、世界調色），其中的顏色與「白瓷／長春花紫」描述已被本節取代。
> 參考的是溫暖的島嶼生活遊戲的**設計原則**；**沒有使用任何作品的角色、Logo、圖示、介面圖形、版面、圖樣或素材**，所有色值、形狀、圖示都是原創。

**唯一真實來源：`game/css/tokens.css`**（調色盤、字級、圓角、動態）；全域外觀在 `game/css/island.css`（最後載入）。

| 項目 | 規則 |

# Design System — 10.0「晴空玩具」

> 10.0 全面重做美術方向與介面。依據：你提供的參考圖（小島 HUD、俯視小屋、低多邊形世界、粉彩 App、寵物 App、大頭玩偶角色）＋
> 動物森友會／Tomodachi Life／曠野之息的**設計原則**（柔和圓潤、玩具感、直覺、情緒化的回饋、自然的世界動態）。
> **沒有使用任何作品的角色、Logo、圖示、介面圖形、地圖或素材**；所有圖示（貼紙）、配色、版面都是原創。

**唯一真實來源：`game/css/tokens.css`**。元件（`game/css/app.css`）只用語意 token；例外是「畫作」：物品圖、貼紙圖示、3D 世界、角色。

## 1. 美術方向（一句話）
**暖陽照著的小島（世界）＋ 白瓷玩具般的介面（UI）**：世界負責溫度（暖色主光、冷色天光、金色午後、藍色月光），
介面保持輕、白、安靜，用長春花紫（periwinkle）表示「可以按／已選取」，用珊瑚紅小圓點表示「有新東西」。

| 參考圖 | 吸收的原則 | 落實在哪裡 |
|---|---|---|
| 1 小島 HUD | 左上頭像＋名牌、天氣時間膠囊、右側工具列、任務卡、白色大導覽列、紅點 | `#hud`（§6）、`.tabbar` |
| 2 俯視小屋 | 粗圓的木頭、溫暖的光、半透明的觸控元件 | 世界打光（§8）、搖桿樣式 |
| 3、4 低多邊形世界 | 浮在世界上的名稱標籤、白色圓角物品卡、底部膠囊工具列 | 對話泡泡、`.tile`／`.slot`、佈置列 |
| 5 粉彩 App | 雲朵、圓形分類圖示、柔和紫色 | 頁首雲邊天空（§5）、`.chip-btn.cat` |
| 6 寵物 App | 大量留白、清楚分區、一致的圖示語言 | 卡片、清單、區塊標題 |
| 7、8 大頭角色 | 大頭小身、柔軟塑膠的體積感 | 角色看板的「玩具光影」（§8）；角色仍是 2D（不改方向 G） |

## 2. 主題
| 模式 | 說明 |
|---|---|
| 淺色 | 白瓷 `#FFFFFF` 卡片、淡紫白 `#F6F4FC` 底、深靛文字 `#3F3B5E`、長春花紫強調 |
| 深色 | 星空夜：深靛 `#17182B` 底、月光紫白文字、提亮的粉彩（不是反轉濾鏡） |
| 跟隨系統 | Android 原生回報；瀏覽器 `prefers-color-scheme` |

- 切換只改 `<html data-theme>`，不重建 DOM、不重載材質、不重設 3D 場景；UI 主題與世界晝夜獨立。
- Android 啟動畫面、桌寵泡泡、診斷畫面、小工具同步使用新色（`res/values*/colors.xml`、`PetPopups.kt`、`MainActivity.background`、`Diagnostics.kt`）。

## 4. 字體、間距、圓角
- 介面 jf open 粉圓 Huninn；數字 Nunito 800/900（tabular）。標題 800 粗。字級 11 / 12.5 / 14 / 16 / 19 / 23（頁標）/ 24 / 30。
- 間距 4 / 8 / 12 / 16 / 20 / 24 / 32；頁面左右 16。
- 圓角：12（小）/ 18（磚、清單）/ 24（卡片）/ 30（表單、對話、狀態卡）/ 膠囊。觸控 ≥ 48dp（`--touch`）。

## 5. 形狀語言（「玩具」）
- **白瓷表面**：`var(--hl)`（上緣 1.5px 白光）＋ `0 3px 0 var(--lip)`（下緣模具邊）＋ 柔和投影。按鈕、圓鈕、工具列、卡片、磚都用同一套。
- **按下＝下沉、放開＝彈回**：按下 90ms（`--t-press`）往下 2–3px、縮 3–8%；放開用 `--spring`（8% 過衝）彈回。
- **頁面**：頂部一條粉紫天空，下緣是兩排圓弧做成的雲邊（純 CSS），頁標左邊放這一頁的貼紙（白色圓角墊）。
- **分類**：圓形貼紙鈕＋標籤＋數量（背包、商店），選取時長春花紫外框並稍微浮起。
- **空狀態**：一個小小的、表情溫和的背包臉。

## 6. HUD（小島）

```
│ (頭像)[名字  星幣][♥ 心情條 做什麼]          (鈴)│  ← 頭像＝狀態卡；鈴只在有通知時出現
│ [☀ 晴朗 / 11/8 15:30]                 [背包] │  ← 天氣時間＝時間面板；右側工具列
│                                       [鏡頭] │
│                                       [佈置] │
│                 （世界）                      │
│                      [📋 今天的任務  進度 >] │  ← 任務卡→日常（點你的 OC＝環狀選單）
│ [ 小島 | 角色 | 工坊 | 探索 | 日常 ]           │  ← 白色大導覽列，選取的分頁有紫色墊子
└──────────────────────────────────────────┘
```
- 常駐操作元件 ≤ 6（名牌、天氣時間、工具列 3 個、任務卡），通知鈴只在有通知時出現；導覽列另計。沒有重複的入口：地圖與日常只在導覽列、設定在「日常 › 設定」、互動＝直接點你的 OC。
- 參考圖 1 還有齒輪與左下的互動手勢鈕；我們試做後拿掉了，因為它們和既有入口重複、超過「常駐 ≤ 6」的規則（第四階段測試 12 會檢查）。
- **沉浸**：拖曳／縮放看小島時，HUD 退到 22% 不透明，停手 1.1 秒後回來（`hudCalm()`）；演出時整個隱藏。
- 小動態：天氣貼紙微微搖擺、有通知時鈴鐺晃一下、可領取的任務卡有紅點與跳動的禮物；「減少動態」全部關閉。

## 7. 貼紙圖示 `OC.UI.sticker(name, cls)`
- 48 格原創插畫：底色＋右下陰影＋白色亮點（同一個光源方向：左上）。`game/js/ui/stickers.js`。
- 尺寸：`.s` 20、預設 28、`.m` 34、`.l` 42、`.xl` 58。深色主題只降一點亮度。
- 用在：導覽列（未選取時灰階）、HUD、頁標、環狀選單、分類鈕、任務／成就／回饋卡。小的行內符號仍用線條圖示 `OC.UI.icon`（清單列的線條圖示放在淡紫圓角墊上）。
- `OC.UI.stickerOr(name)`：有貼紙就用貼紙（含別名），沒有就退回線條圖示。

## 8. 世界與角色的畫面
- **打光**：白天暖色主光（#FFF0D6）對上偏藍的天光（#DAE5FF），陰影是柔和的藍紫；16–18 點金色午後；夜晚月光藍＋螢火蟲。（`env.js` KEYS）
- **調色**（效能「高／平衡」）：畫布 `saturate(1.2) contrast(1.06)`；「太陽光暈」以 soft-light 疊在右上，依時段變暖金／金橘／月光藍，雨天減弱。
- **景深**（只有「高」）：畫面上緣與下緣各一條 2.4px 的背景模糊漸層，像微縮模型（不模糊 HUD 與對話泡泡）。
- **角色的玩具光影**：程式繪製的角色看板加一層上亮下暗、背光側略暗的體積（只畫在角色本身的像素上）；**匯入或手繪的角色圖不加**，保持原作。
- **跳躍**：預備下蹲 0.1 秒 → 起跳拉長 → 落下微拉長 → 落地壓扁並回彈（`world.js`），減少動態時不預備。

- **11.0 世界觸控回饋**：點地面＝兩圈白色波紋＋一個長春花紫的圓點（`.tap-ripple`，`--accent`），圓點停到 OC 走到才消失（最多 12 秒），在點下去的當下就定位；點樹／灌木／花叢＝搖晃（衰減）＋淺綠／黃綠的葉片飄落（橢圓、帶一點自發光，才看得見）＋沙沙聲＋`tick` 觸覺；跑步與落地揚起奶油色小灰塵。粒子只有兩個池化的 InstancedMesh；省電模式與「減少動態效果」不產生粒子（樹仍會輕輕晃）。

## 9. 動態 token
| Token | 值 | 用途 |
|---|---|---|
| `--spring` | 計算出的阻尼彈簧（ζ=0.62，過衝 8%），`linear()` 曲線 | 按鈕放開、徽章、圖示、分類、泡泡、選單鈕 |
| `--spring-soft` | ζ=0.8，過衝 1.5% | 頁面、表單、導覽列墊子 |
| `--t-press` / `--t-fast` / `--t-base` / `--t-slow` / `--t-spring` | 90 / 140 / 240 / 380 / 560ms | 按下 / 切換 / 淡入 / 頁面 / 彈簧 |
| `--ease-in` | 加速 | 關閉、退場（表單、快速背包、提示） |

規則：只動 `transform`／`opacity`；頁面內容「依序落定」（每塊延遲 35–40ms，最多 180ms）；表單用 `--spring-soft` 打開、`--ease-in` 收起；
不支援 `linear()` 的 WebView 自動退回三次貝茲曲線；「減少動態效果」與系統設定把所有過場縮成 1ms。世界的天氣、時間仍用 τ≈1.6s 趨近。

## 11. 尚未做到（誠實標示）
- 3D 模型（建築、樹、家具）沒有重新建模；10.0 只改了光線、調色、景深與環境生物，11.0 只加了世界觸控回饋（波紋、搖樹落葉、揚塵）。嘗試過的卡通色階（toon ramp）讓整個世界變暗，已還原。
- 動畫工作室、繪畫工坊、角色編輯器沿用新元件樣式，但版面沒有重新設計。
- 角色仍是 2D 看板（依方向 G）；「大頭玩偶」只吸收比例與體積感，沒有改成 3D 模型。
- 實機（Android）上的模糊（backdrop-filter）與 `linear()` 效能需要實測；已在「省電」關閉調色與景深、「平衡」關閉景深。

## 12.0：「雅緻」風格（預設）與極簡 HUD

- `html[data-style="refined"]`（預設）覆寫 tokens：圓角縮小（8／12／16／20）、模具邊（`--lip`）透明、系統字體、降低彩度的淺色／深色色盤、彈簧動態不再過衝；`html[data-style="toy"]` 是原本的「晴空玩具」。設定 › 介面風格切換，只改 `<html data-style>`，不重建 DOM。
- 元件仍只用 tokens；新元件必須在兩種風格下都能用。貼紙圖示、白瓷表面的結構不變。
- HUD：常駐元件 ≤ 4（頭像名牌、時間、工具把手、有任務時的小膠囊）；導覽列只有圖示、標籤只在目前分頁；閒置幾秒淡出、一碰就回來；心情列移到狀態卡；長按頭像開操控模式面板。
