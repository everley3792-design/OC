# 15.3（0.15.3-alpha）視覺與動態打磨

計畫的最後一個版本：光影、季節色調、水面、轉場、音效與逐頁檢查。所有效果都是原創，也遵守 14.1／14.2 的效能規則（不在 3D 畫布上用 CSS 濾鏡、每個效果最多一個繪製呼叫、可以被效能模式關掉）。

## 一、季節
| | 說明 |
|---|---|
| 怎麼決定 | 依日期（3–5 月春、6–8 月夏、9–11 月秋、12–2 月冬），或在設定的「世界」區自己選。 |
| 樹葉與草地的顏色 | 著色器裡的一小段：只調「綠色明顯領先」的像素。春＝嫩黃綠、夏＝深綠、秋＝金黃、冬＝結霜的淺綠。**角色不套**（角色材質帶 `OC_CHAR`）。 |
| 飄落的東西 | 春天花瓣、秋天落葉、冬天雪花（夏天沒有）。在戶外、特效開著、不下大雨時才有；晚上會變暗。一個 InstancedMesh，一個繪製呼叫。 |
| 限制 | 顏色在**遊戲啟動時**套用（為了不在遊戲中重新編譯著色器），改了設定要下次開啟才會換；設定裡有寫清楚。 |

四季對照的截圖在 15.3 的檢視過程中看過（同一個角度：春亮、夏深、秋金、冬霜）。

## 二、水面
海面上有會閃爍的光點（白天暖白、晚上銀藍），只在有海的地點（晴日島、星砂海灘）、特效開著時出現；一個 InstancedMesh。

## 三、轉場
換地點時，九朵奶油色的雲從四周捲進來蓋滿畫面，中間是地點的貼紙與名稱，載入完再淡出；開了「減少動態」就是原本的淡出淡入。只在轉場的那一秒存在（不是常駐元素）。

## 四、光影
彩虹遊樂園的燈泡（摩天輪、旋轉木馬的燈、舞台的燈與燈串）接到和房屋窗戶同一套夜晚燈光，晚上會亮。摩天輪細細的骨架不再投下大片陰影（原本把半個廣場都蓋暗了）。

## 五、聲音
- 遊樂園白天會偶爾響起一小段音樂盒旋律（每次從五聲音階即時組出來的幾個音，原創）。
- 風車丘有風聲，偶爾有風車轉動的嘎吱聲。

## 六、逐頁檢查
用 `node game/tests/v14/shots.js <目錄> both` 把每個畫面（淺色＋深色，現在包括島報、相簿、風車丘、遊樂園、演唱會、套圈圈）拍下來逐張看，修了：
- 深色模式下島報的小標籤是深字配深底，看不清楚 → 改用 `--ink`。
- 遊樂園廣場被摩天輪的陰影蓋住大半 → 摩天輪的輪框與輻條不投影。
- 地圖的指北針蓋到風車丘 → 移到地圖下方中間（15.2 之後就做了）。

### 回歸中發現並修正的問題
- **長按被當成點一下**：手指按住的這段時間如果頁面一直在忙（計時器跑不了），放開時會被當成「點一下」，地面的長按選單就不會出現（v8 6c 之前偶爾失敗的原因）。現在用事件本身的時間戳記判斷按了多久：真的按超過 0.48 秒就是長按；快點一下仍然是點一下。修正後 v8 單獨重跑 3 次、完整回歸 46/46 都通過。
- **還沒查清楚的**：v15 1a（點一下長椅只出現動作卡、角色不會走過去）在修正後的完整回歸與一次單獨執行中各失敗一次（角色身上有路徑），之後單獨重跑 7 次都通過。測試已加上失敗時的輸入紀錄與角色狀態，下次失敗就能看到原因。**不能排除和這次的長按修正有關。**
