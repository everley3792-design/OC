# 15.0（0.15.0-alpha）互動模型與介面骨架

計畫（已確認）：保留 2D 角色；分 15.0 → 15.3 四個版本，每個版本先給 APK；新地點風車丘、遊樂園兩個都要（在 15.2）。
參考 Animal Crossing: New Horizons、Tomodachi Life: Living the Dream、The Sims 4、inZOI 的**設計原則**；沒有使用任何一款的角色、Logo、圖示、介面圖形、版面或音樂。

## 一、點擊誤觸（你回報的問題）

**原因**：單點一下物件就「走過去並立刻執行」，中間沒有確認。點到長椅就坐下、點到花圃就採花、點到樹就搖、點到掉落物就撿、點到「我的家」或路牌就**直接換地點**、點到商店就開商店頁。鏡頭平移、放開手指時誤點到物件，就像「自己選了一個互動」。

**修正：點選 ≠ 執行**
- 單點物件只會**選取**：物件上出現一個黃色圈，旁邊跳出一張奶油色的動作卡（名稱、一句說明、一個按鈕，例如「坐下」「進去」「撿起來」）。**按了按鈕才做**；點其他地方或按返回，卡片收起來，什麼都沒發生。
- 卡片、環狀選單、對話選項**剛出現的 0.35 秒內不接受按壓**，所以打開它的那一根手指（慢一幀、瀏覽器補發的點擊、不小心連點兩下）不可能順便按下去。
- 角色仍然是點了打開環狀選單，家具仍然是點了打開家具選單，空地仍然是點了走過去。
- 想要舊的「一點就做」：設定 › 操作 › 「點一下就做」（預設關）。

**驗證**：用**真實觸控事件**（不是程式呼叫）測試：點長椅只出現卡片、角色不動、等 1.5 秒也不會自己開始；點旁邊卡片收起、什麼都沒發生；卡片剛出現時按按鈕無效、0.35 秒後按才走過去坐；點「我的家」的門只出現「進去」、人還在晴日島；環狀選單與對話選項剛出現時按不到。

## 二、動作清單（Sims 式）
- 安排角色做事（環狀選單「安排」、點設施的動作卡）會排成清單：第一個馬上開始，後面最多 4 個依序等候。
- 清單顯示在左上時間下方：目前的那一個標 ▶，其餘標號碼；**每一項點一下就取消**（包括正在做的那一個）。
- 清單存在角色身上（重開遊戲還在）；每一項仍然經過生活引擎（位子預約、不可打斷的活動、保留），不會繞過規則。
- 操控中的角色頭頂有一個小水滴標記（原創形狀），顏色表示操控模式：黃＝手動、綠＝半自動、藍＝全自動。

## 三、口袋手機
「日常」分頁改成一支遊戲裡的手機：上面是狀態列（時間、日期、星幣），下面是 15 個 App 的主畫面（任務、請求、成就、圖鑑、拍照、相簿、地圖、背包、商店、帳本、小島目標、工坊商品、桌寵、提醒待辦、設定），有紅點數字。任務類 App 在手機下方直接打開；其他 App 打開自己的頁面。原本頁面下方那串「其他」清單拿掉了（都在主畫面上）。

## 四、拍照模式與相簿
- 從手機的「拍照」進入：HUD 與導覽列全部隱藏；照常用手指移動、縮放、旋轉鏡頭。
- 濾鏡 6 種（原色、暖陽、黃昏、底片、清晨、黑白）、相框 4 種（無、拍立得、郵票、圓角），日期（拍立得是日期＋地點）印在照片上。
- 照片存進素材庫（IndexedDB），存檔裡只有編號與標籤；相簿最多 40 張，滿了最舊的會被移除；可以儲存／分享（Android 走系統分享）或刪除。
- 拍照模式期間，畫面上會有濾鏡**預覽**——這是唯一一個在 3D 畫面上用 CSS 濾鏡的地方，只在拍照時、離開就拿掉（效能規則的例外，已寫進 CLAUDE.md）。
